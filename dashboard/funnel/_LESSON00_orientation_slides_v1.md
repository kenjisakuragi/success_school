**狙い:** 「買ってよかった」を初日に確信させ、圧倒されず、**最初の小さな行動(クイックウィン)**まで完了させる(=完走率の起点)

**S1 ようこそ** ─ 「桜木式引き寄せメソッド本科へ、ようこそ。」サブ:この90日で、あなたの毎日が静かに変わり始めます

**S2 まず、おめでとうございます** ─ 一歩踏み出せた時点で、もう多くの人と違う。肯定起点で迎える

**S3 この90日で起こること(Before→After)**
```
Before(今)              →     90日後
─ 頑張っても報われない感覚   →  努力が"自然な行動"に変わる
─ 三日坊主で自分を責める     →  AI桜木と毎日、続けられている
─ 心がざわついて眠れない     →  整えて、すっと眠りにつける
```
※変化には個人差があります／治療を目的とするものではありません

**S4 メソッドの全体像(3つの柱)** ─ ①理想を設計する ②感情筆記で整える ③自律訓練法で体に落とす / 図解で1枚

**S5 大事な前提** ─ 変えるのは"性格"ではなく「脳の使い方」。だから誰でも、今日から

**S6 90日チャレンジの歩き方** ─ 入会日が起点。毎日5分。週ごとにモジュールが開く(ドリップ)。マイルストーンで達成感

**S7 一人にしません ─ AI桜木があなたの専属コーチ** ─ ①毎日のスケジュール管理 ②24時間いつでも質問 ③今日のワークを届ける

**S8 AI桜木の使い方(実演)** ─ LINEで「今日のワーク」が届く→やったら報告→次が開く。質問は24時間OK(例の画面)

**S9 仲間と、月1ライブ** ─ コミュニティで宣言・相互応援/月1で桜木に直接質問できるライブ(録画あり)

**S10 つまずいても大丈夫** ─ 完璧主義はいらない。1日サボってもAI桜木が戻してくれる(安心設計)

**S11【最初の一歩・クイックウィン】今ここで1つだけ** ─ 「半年後どうなっていたい?」を3つ書く → 1つに丸 → AI桜木に送ってみる

**S12 なぜ"3つ"なのか(一言)** ─ 10個書くと逆効果。3つに絞ると脳が拾い始める(科学の小ネタで腹落ち)

**S13 今日のゴール** ─ ①このあとAI桜木に理想を送る ②コミュニティで自己紹介 ③Module 1を1本観る

**S14 宣言してみましょう** ─ コミュニティに「90日、続けます」と書く(公的宣言=継続率↑)

**S15 最後に** ─ あなたの望みは、もう目の前にあるのに見えていないだけ。明日からではなく、今日から。ようこそ、もう一度
