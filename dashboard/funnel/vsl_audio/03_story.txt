少しだけ、私自身の話をさせてください。

…

私は、東京大学を卒業し、日系企業で20年勤めています。

と言うと、多くの方は、こうおっしゃいます。もともと優秀だったんでしょう?

…

違います。

…

1991年、ある冬の夜のことでした。

11歳の私は、リビングのソファーで、テレビを見ていました。

画面の中に、一人のオリンピックメダリストがいました。

彼女は、トレーニングについて、こう語っていました。

スタートラインに立つ前、ゴールを切る瞬間、表彰台に上がる瞬間。すべて、頭の中で、何千回もやっています。

11歳の私の胸の奥で、何かが小さく音を立てました。

頭の中で? 体を動かさずに? それでオリンピック選手になれる?

意味は、まだよくわかりませんでした。でも、その言葉は、奇妙にはっきりと耳に残ったのです。

…

翌年、彼女は、冬季オリンピックの舞台で、メダルを獲得しました。

11歳で耳にしたものが、現実になった。

…

これが、私の人生を変えた、最初の出来事でした。

…

それから私は、関連書を読み漁りました。

スポーツ心理学、自己啓発、潜在意識、成功哲学。書店で関連書を見つけると、ポケットの小遣いをはたいて買い集めました。

セリグマンの、学習性無力感。

クーエの、意識的自己暗示。

マーフィーの、眠りながら成功する。

ナポレオン・ヒルの、思考は現実化する。

…

正直に言えば、読んだ内容の3割もわかっていなかったと思います。

でも、ひとつだけ、私の中にはっきりと刻まれた事実がありました。

人間の脳には、使い方がある。

…

ただ、ここからが、私自身の物語の本領です。

中学受験で進学校に合格した後、私は、中学3年まで、下から数えた方が早い成績の、落ちこぼれでした。

…

教科書を開いても眠くなる。塾の授業に出ても、頭に入らない。模試の結果は、いつも下から数えて何番目。

お前は、無理だな。周りからは、よく言われました。

そして自分自身も、心のどこかで、俺は、無理だな、と思っていました。

これを、心理学では、セルフイメージと呼びます。

…

転換点は、高校1年の春でした。

あることをきっかけに。詳しくは、また別の機会にお話ししますが。私は、11歳で耳にした、頭の中で、何千回もやる、を、本気で実践し始めました。

…

朝起きたら、ノートに、私は東京大学に合格する、と書く。

寝る前に、東京大学のキャンパスを歩いている自分の姿を、五感をすべて使って、思い描く。

ささやかに、でも、毎日。

…

最初の3週間は、何も変わりませんでした。

それどころか、頭の中の声は、毎日反論してきました。

いやいや、お前は落ちこぼれだろう。東大なんて、上位数%しか入れない。無理だってわかってるくせに。

…

ところが、3ヶ月続けたあたりから、奇妙な変化が起き始めました。

教科書を開いても、以前ほど眠くならなくなった。

同じ問題集を解いても、これ、東大の二次に出そうだ、と勝手に脳が反応するようになった。

友人の中で、勉強の話ができる相手と、自然に時間を共有するようになった。

模試の点数が、目に見えて伸び始めた。

…

何が起きていたのか、当時の私にはわかりませんでした。

ただ、結果だけは出ました。

それから2年で、私は校内トップ層に入り、高校3年の冬、東京大学に現役合格しました。

…

その後、20年。

会社員として勤めながら、副業で本業の年収を超え、本を出し、理想の妻と出会い、2人の娘を授かりました。

…

はっきり言わせてください。

魔法ではありません。運でもありません。

中学3年まで落ちこぼれだった一人の人間が、脳の使い方を変えただけです。それ以上でも、それ以下でもないのです。

…

そして今、40代の父として、私は、この技術を娘たちに伝えています。

同時に、日本マニフェスティング協会の代表として、同じものを必要としている、より多くの人に届けたい。そう思っています。

…

ここから先、私が20年かけて体系化した、3つの空白を全て埋めるメソッドを、お見せします。
