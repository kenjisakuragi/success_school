## 推奨ワークフロー

### Step 1:声のクローン作成(初回のみ)

1. **ElevenLabs**(https://elevenlabs.io)にアカウント登録(Starter Plan $5/月〜で十分)
2. **Voice Lab → Instant Voice Cloning** で、桜木自身の声を1分間録音してアップロード
3. クローン声の名前を `Sakuragi Kenji` に設定

**iPhone録音のコツ:**
- 静かな部屋で
- マイクから20-30cm離す
- 通常の話し方で 1分(約400-500字)朗読
- 例文:書籍プロローグの冒頭1分を朗読

### Step 2:音声生成

1. ElevenLabsで「Text to Speech」を開く
2. 声:作成した `Sakuragi Kenji` を選択
3. **設定推奨値:**
   - Stability:**50-65**(自然さ重視)
   - Similarity:**75-85**(声のクローン精度)
   - Style:**0**(誇張なし、淡々と)
   - Speaker Boost:**ON**
   - **Model:Eleven Multilingual v2**(日本語対応)
4. `01_hook.txt` の内容をコピー → ペースト → Generate
5. 生成された音声を `01_hook.mp3` としてダウンロード
6. 同様に `02_problem.txt` 〜 `06_cta.txt` まで生成

### Step 3:結合・編集

1. 6つのMP3ファイルを、お好みの動画編集ソフト(iMovie / Premiere / CapCut 等)に並べる
2. ファイル間に 1-2秒の無音を挟む(自然な区切り)
3. スライド画像と合わせて動画化
4. BGMを薄く乗せる(任意)

## 文字制限について

- ElevenLabs **Starter** プラン:1リクエスト最大 **5,000文字**
- ElevenLabs **Creator** プラン以上:1リクエスト最大 **10,000文字**

本フォルダの各ファイルは Starter プランの 5,000文字制限以内に収まるよう分割しています。`00_full.txt` は Creator プラン以上で使用してください。

## 「…」の扱い

テキスト中の `…`(三点リーダー)は、ElevenLabs が自動的に短い間(0.3-0.5秒)として読み上げます。長い間が欲しい箇所は、空白行を挟んでいるので、自然に1-2秒のポーズが入ります。
