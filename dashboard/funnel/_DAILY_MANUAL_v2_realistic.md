# 🌞 平日昼間 ― TBSスキマ時間(20-40分・スマホメイン)

## ⏱️ 想定時間帯

- 通勤電車(往復30分×2 = 1時間)
- 昼休み(30分)
- TBS内の隙間(10-30分 × 数回)

## 📱 スマホで完結する5つのタスク

### 🎯 タスクA:Gmail で重要メールだけ確認(5-10分)

```
1. Gmail アプリを開く
2. 検索バーで:「重要」OR「from:utage」OR「from:stripe」
3. ヒットしたものだけ確認
4. 緊急性高い → 夜の作業時間まで取り置き(スターを付ける)
5. 緊急 → 後述AIプロンプトで即返信
```

### 🎯 タスクB:LINE Manager で重要メッセージ確認(5分)

```
1. LINE Manager アプリ(なければChromeで manager.line.biz)
2. 未読の中で「ピン留め」「重要マーク付き」のみ確認
3. Manifest AI™ 自動応答済みなら → スルー
4. 個別対応必要 → 夜の作業時間まで取り置き
```

### 🎯 タスクC:UTAGE 売上ひと目(2分)

```
1. ブラウザで UTAGE管理画面
2. ダッシュボードの「本日の数値」を3秒で見るだけ
   ・売上(¥)
   ・新規購入(件)
   ・オプトイン(件)
3. 通常通り → 閉じる
4. 異常値あり → 夜にチェック
```

### 🎯 タスクD:Meta広告マネージャー数値ひと目(2-5分)

```
1. ブラウザで business.facebook.com
2. 今日のCPC平均だけ確認
3. ¥250超のクリエイティブがあれば → 一時停止(タップ2回で可能)
4. それ以外 → 閉じる
```

### 🎯 タスクE:SNS反応の重要なものだけリプライ(5-10分)

```
1. X (@mindlab_jp) を開く
2. メンション・引用元・リプライを確認
3. 重要なものに30秒以内で短い返信
4. AI下書き使う場合は:
   ChatGPT/Claudeアプリでプロンプト「↓のリプライに桜木の口調で短く返信して」
```

- **火曜:** 月曜の週次レポートで見えた数値を踏まえた改善実装日

### 19:00 - 19:30:メール返信バッチ処理(30分)

```

4. プロンプト①(↑)を使って高速返信
5. 1メール平均3分・10通捌く

```

```
1. 月曜朝の週次レポートメールを開く

   - マスター講座 CVR
   - Upsell CVR

   プロンプト:
   「以下は今週のファネル数値です。
```
