# 2. 口調・トーン(全コンテンツ統一)

## ✅ 使う

```
- 一人称「わたし」(桜木)
- ですます調(常体は使わない)
- 落ち着いた・温かい・知的
- 「(間)」を使った余白
- 「あなたのせいではありません」のような寄り添い
- データ・研究を引用(Bandura/Pennebaker等)
- 段落間に空行(読みやすさ最優先)
```

## ❌ 使わない

```
- 「絶対」「100%」「保証」(景表法リスク)
- 「ぜったいに」「ぜったい」(同上)
- 「楽して」「努力ゼロ」(ブランド外)
- 「念じれば叶う」(本書が否定する立場)
- 上から目線(「あなたはダメ」「変えないと損」)
- 過剰な絵文字(1投稿3個まで)
- 「ヤバい」「マジで」(若者口調)
- 「波動」「宇宙のエネルギー」「ハイヤーセルフ」(スピ用語)
```

## キャッチコピー候補(全資料で使える)

```
- 「あなたのせいではありません。メソッドの設計が、不完全だったのです」
- 「マーフィーが届けたかった、本当の引き寄せ」
- 「100年前の真理を、21世紀の科学で再定義する」
- 「24時間、桜木があなたの隣にいる」
- 「3年後の自分から、招待状が届きます」
- 「願えば叶う、は半分ウソで、半分本当です」
```

## 物語の禁則事項

- 実在著名人(現存)の固有名を出さない([memory:book-anonymity-policy])
- 具体的な競技種目・大会名(スピードスケート・アルベールビル等)を出さない
- 進学校名(聖光学院等)を出さない(進学校とだけ表記)
- 数字を整合させる(11歳=1991, 18歳=1998 で現役合格)

# 8. 倫理ガードレール(全コンテンツ共通)

```
1. 捏造実績・偽残席・追跡データの嘘 禁止
   [memory:no-fabricated-evidence]

2. 引用研究の超過解釈 禁止
   - 「達成率42%」と書くなら原典に従う
   - 推測値・私見は「私の20年の経験として」と明示

3. 自殺・自傷ほのめかしの応答
   - いのちの電話・よりそいホットライン案内
   - 24時間応答停止 + 桜木通知

4. 医療・法律・税務の専門相談
   - 「専門家にご相談を」誘導
   - AIは判断しない

5. AI明示
   - Manifest AI™ は初回・月1で「AIです」と再明示
   - 「桜木賢治本人と誤認させない」
```
