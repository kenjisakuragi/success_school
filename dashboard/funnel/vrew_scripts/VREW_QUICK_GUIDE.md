**1本5-10分で完成**するための最短マニュアル。

---

# 🎯 たった4ステップ

## Step 1:Vrew で音声インポート(30秒)

```
1. Vrew 起動 → 「桜木式VSL」テンプレ呼出
2. メディア追加 → 該当WAVファイル選択
   例:vsl_audio/final_01_hook_Algieba_088.wav
3. タイムラインに自動配置される
```

## Step 2:自動字幕生成(1-2分)

```
1. 「字幕自動生成」をクリック
2. 待つ(Vrewが音声から全文を書き起こす)
3. 字幕が完成
```

## Step 3:固有名詞チェック(3-5分)

Ctrl+F で以下を順に検索・修正:

```
□ 桜木賢治       (サクラギケンジになっていないか)
□ マニフェスティング  (マニュフェスティング)
□ Manifest AI    (マニフェスト・エーアイの表記)
□ バンデューラ
□ ペネベイカー
□ マシューズ
□ ヘルツェル
□ エッティンゲン
□ ザッカーロ
□ ゴルウィッツァー
□ 628億回 / 530億 / 70億 / 28億
□ d=0.5〜0.8
□ 33ポイント
□ 海馬5%増加
```

リファレンス:`vrew_scripts/VSL_full_marked.md`

## Step 4:オープニング+エンディング追加→書き出し(2-3分)

```
1. 先頭にオープニング・テンプレ追加(5秒)
2. 末尾にエンディング・テンプレ追加(15秒)
3. 「書き出し」→ 1080p MP4
4. バックグラウンド処理中、次の動画作業へ
```

# 🚀 並列処理で土曜2hで16本

```
1本目 編集中(3分) → 書き出し開始 → 2本目 編集 ...
1本あたり 編集3分 + 書き出し中に次へ
→ 実質 5-7分/本 × 16本 = 約80-110分

土曜午前 7:00-9:00 で16本完成
```

# ⚠️ 全文書き起こし方式の注意点

| 注意 | 対策 |
|---|---|
| Vrew が固有名詞を間違える可能性 | Ctrl+F チェック必須 |
| 強調したいキーフレーズが目立たない | 仕様(統一スタイル優先) |
| 動画ごとの個性が出にくい | サムネ・タイトルで差別化 |
| 字幕が単調 | OK(声に集中させる設計) |

---

# 📝 強調表示を一切しない理由

```
1. 「判断ゼロ」で量産優先
2. 桜木の声(Algieba 0.88)で十分メリハリがついている
3. 字幕の役割は「補助」(音声主役)
4. 強調があるとカット選定の判断が必要 → 工数増
5. YouTube視聴者の多くは音声で聴いている

→ 字幕は「あれば読める」程度で十分
```
