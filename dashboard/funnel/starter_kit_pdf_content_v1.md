# ワーク1: 過去形で書く ― 五感のチェックリスト(P.4-7)

```
■ P.4 ― 「過去形で書く」とは何か


引き寄せの本で、よく「過去形で書け」と言われますが、
具体的に、どう違うのでしょうか。

──────────

❌ 未来形:「2029年に、月収50万円になりますように」

❌ 現在形:「私は今、月収50万円です」(嘘っぽくて続かない)

✅ 過去形:「2029年5月、私は副業で月収52万円に到達していました」

──────────

過去形で書くと、脳は「すでに起きた出来事」として処理し始めます。

これが、脳科学者の言う「予期的な記憶の刷り込み」です。
未来の自分を、過去の記憶として、脳に登録するのです。
```

```
■ P.5 ― 五感のチェックリスト


「3年後の朝、何が見えますか?」 と聞かれて、即答できる人は、いません。

でも、こうやって順に質問されると、答えられます。

──────────

🎯 視覚 ― 朝起きて最初に見えるものは何ですか?
   例:「窓のカーテン越しの朝陽が、ベランダの観葉植物に当たっている」

🎯 聴覚 ― 周囲から何が聞こえてきますか?
   例:「ドリップコーヒーの音、夫が朝の家事をしている気配」

🎯 触覚 ― 体に感じる感覚は?
   例:「肩こりがなく、軽く、深く息ができる感覚」

🎯 嗅覚 ― どんな匂いがしますか?
   例:「コーヒー豆の苦みのある香り、観葉植物の青い匂い」

🎯 味覚 ― 朝食には何を食べていますか?
   例:「自家製パンと、トマトの甘み」

──────────

5つの感覚を順に書き出すと、未来は「絵」になり、「映像」になります。
```

# WOOPフォーマット入門(P.16-17)

```
■ P.16 ― 「願うだけ」では叶わない、という不都合な真実


ここで、ひとつ重要な事実をお伝えします。

ニューヨーク大学のガブリエル・エッティンゲン博士は、
20年以上の研究で、こう結論づけました。

「叶った姿を、ポジティブにイメージするだけ」の人は、
何もしなかった人よりも、達成率が「むしろ下がる」。

────────────────────────────────────

理由は、シンプルです。

願うだけだと、脳が「もう叶った」と達成感を前借りし、
行動エネルギーが、枯渇してしまうのです。

────────────────────────────────────

その処方箋が、WOOP法 です。
```

```
■ P.17 ― WOOP法 4ステップ


P.14 で書いた「未来からの手紙」を見ながら、以下を書いてみてください。

────────────────────────────────────

W ― Wish(願望)
あなたの3年後の願望を、1行で。

_________________________________________________


O ― Outcome(成果)
それが叶った状態の、五感での詳細を、3行で。

_________________________________________________
_________________________________________________
_________________________________________________


O ― Obstacle(障害)
過去、この目標に向かおうとして、止まってしまった経験はありますか?
そのとき、あなたの「内側」にあった、最大の障害は何でしたか?

_________________________________________________


P ― Plan(計画)
「もし【その障害】が出てきたら、私は【何】をする」 ―
この一文を、書いてください。

「もし _________________________ が出てきたら、
 私は _________________________ をする」

────────────────────────────────────

これで、WOOPが完成します。

毎日のWOOPを習慣化すると、目標達成率が一貫して向上することが、
心理学研究で繰り返し示されています。
```
