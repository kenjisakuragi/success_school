> **位置づけ:** Claude Project等のAIにこのMDを渡せば、¥1,000セミナーのMarpスライド一式が自動生成される「設計仕様書」
> **目的:** Kenjiの手間を介さず、AI主導でセミナースライドを量産・再生成可能にする
> **適用ブランド:** 桜木賢治 / 引き寄せ博士 / MindLab / 将来のJV先 ― 全て差し替え可能
> **作成日:** 2026-05-21
> **使用先:** Claude Project「桜木の声」/「Kenjiの声」内蔵テンプレ

# 🚀 使い方(3ステップ)

## Step 1: 下の §3「入力変数」 を埋める

ブランド名・講師プロフィール・価格などを差し替える。

## Step 2: Claude Project または ChatGPT-4 に投げるプロンプト

```
あなたは情報商材・高額バックエンド設計の専門家です。
添付の「¥1,000セミナースライド ジェネレーター仕様書」に厳密に従って、
Marp形式のMarkdownスライド一式(50-56枚)を出力してください。

【入力変数(§3を参照)】
ブランド名: {BRAND_NAME}
講師名: {INSTRUCTOR_NAME}
講師プロフィール骨子: {INSTRUCTOR_PROFILE}
ターゲット: {TARGET_PERSONA}
バックエンド商品: {BACKEND_PRODUCT}
価格: {PRICE_STANDARD} / {PRICE_VIP}
分割払い: {INSTALLMENT_PRICE}/月
著者著書: {BOOK_TITLE}
セミナー時間: {DURATION}(例:2時間)

【厳守事項】
- §5 のタブー・トーンガイドを絶対遵守
- §6 の心理テクニックを全てのオファースライドに適用
- §7 の Marp フォーマット仕様に従う
- §4 の構造(4 PART)に沿う

【出力】
完全な .md ファイルの内容(Marp frontmatter含む)
```

## Step 3: 出力された.mdを `_build_pptx.py` に通す

```bash
python _build_pptx.py
```

→ .pptxファイルが自動生成。

# 🚫 §4 タブー・トーンガイド(絶対遵守)

## §4-1 絶対NGワード

❌ 「必ず叶います」「絶対」「100%」(誇大表現)
❌ 「魔法」「奇跡」(非科学感)
❌ 「誰でも」(ターゲットぼやけ)
❌ 「他のメソッドは間違い」(他社批判)
❌ 「楽して稼ぐ」「努力ゼロ」(煽り)
❌ 「波動」「宇宙」「エネルギー」「チャクラ」(スピ系・MindLab厳禁)
❌ 「ハイヤーセルフ」「アセンション」「ツインレイ」「エンジェルナンバー」

## §4-2 絶対NGテーマ

❌ 個別占い・タロット・チャネリング
❌ 教祖型(「私を信じれば叶う」)
❌ コントロール型恋愛術(「彼を惚れさせる」)
❌ ジェンダー固定表現

## §4-3 採用する語彙

🌸 「叶える」「響かせる」「満たす」「整える」「育てる」「設計する」
🌸 「100年前の知恵」「現代の脳科学」
🌸 「あなた自身のために」(主目的) / 「家族への波及」(副産物)
🌸 「あなたのせいでは、ありません」(共感救済型)
🌸 「思い出す」(主体性回復)
🌸 「再現できる」「実証された」「データが示す」

## §4-4 ナレーション規範

- やさしい、落ち着いた、聴き手中心
- 講師の自己開示OK(妻・家族との実体験)
- 他者を貶めない
- 「先輩として伝える」スタンス(教祖化禁止)
