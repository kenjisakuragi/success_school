# 3本柱

## ① 理想状態の設定(少数・具体・鮮明)
- **コツ:10個書かない。3つで止める。**具体的・鮮明に。
- 科学的裏打ち:キング理想未来(ミズーリ)＋エッティンゲンWOOP(障害も対比)＋**シュワルツの理由列挙の逆説(イェール第3講:3つ◎/10個は逆効果)**
- AI桜木:願いを3つに絞り、具体・鮮明化を対話で支援

## ② 感情筆記(感情と行動を書き出す)
- **公開名=「感情筆記」** / 科学的裏打ち=ペネベイカーの筆記開示(エクスプレッシブ・ライティング)＋ゴルウィッツァー実装意図
- やること:感情を紙に書き出して外に出す＋「いつ・どこで・何をするか」の行動を書く
- AI桜木:書く問いを出し、感情の言語化と実装意図化を伴走

## ③ 自律訓練法(理想状態を身体に定着)
- **公開名=「自律訓練法」**(自己暗示の科学版)。※「自己催眠」は不採用(スピ寄り・科学薄・誇大リスク)
- やること:リラックス状態で理想の状態を自分に暗示し、身体・神経に臨場感として落とす
- 科学的裏打ち:自律訓練法(シュルツ)＋呼吸法(ザッカーロ)
- AI桜木:音声/テキストで自律訓練の手順を伴走

# 🎓 提供形式(2026-05-30 確定:エバーグリーン＋月1ライブ＋AI桜木)

```
本体 = 録画講義(3本柱)＋AI桜木の毎日伴走(自己ペース・即入会即開始・常時販売)
締切 = 入会日起点の21/90日チャレンジ(各人のカレンダーで締切=締切効果)
仲間 = コミュニティ(LINEオープンチャット等)＋宣言で社会的証明
人の熱 = 月1の集団ライブQ&A/コーチング会(録画提供・"その月の在籍者なら誰でも参加"=ローリング)
```
- **純コホート(期区切り)は採らない**(常時販売=月利300万・週4h運用と矛盾するため)。ライブは「月1定例会・誰でも参加可」=期を区切る必要なし。

## AI桜木の3役割
1. **スケジュール管理・毎日伴走**:入会日起点で21/90日チャレンジを自動設計、今日のワーク・締切・進捗を毎日プッシュ
2. **24時間 質問し放題**:メソッド範囲で即回答。深い/個別は月1ライブで桜木(人)が回答(ハイブリッド)
3. **コミュニティ運営補助**:宣言促し・社会的証明の可視化・不適切投稿検知

## 🚨 AI桜木 ガードレール(実装前提・生命線)
- **非臨床/医療回避**(薬機法・医師法):診断・治療・薬の助言NG。危機ワード検知→専門相談窓口案内＋人間通知
- **捏造禁止**([[no-fabricated-evidence]]):回答はカリキュラム＋9研究の範囲(RAG)。不明は「月1ライブで桜木が回答」と正直に
- **ペルソナ固定**:AI桜木のトーン固定/NGワード(波動・絶対・必ず)を出させない
- **過剰約束しない**:効果保証はしない・免責明示
- **個人情報配慮**:悩み開示のログ管理・プライバシー保護

LINE(IF)＋Claude API＋RAG(カリキュラム/メソッド/9研究/会員の目標・進捗)＋Make.com(リマインド)＋Supabase(会員DB)＋危機検知。
