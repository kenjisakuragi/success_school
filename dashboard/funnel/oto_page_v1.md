- タイマータイプ:**Evergreen 30分**(訪問者ごとに30分カウントダウン開始)

これを**確実に実装**してください。タイマーが見せかけだけだと景表法上問題があります。

### 2-b. ページビルダーで上記コピーを配置

## ⚖️ 法令遵守チェックリスト

- [ ] 「97%は3日後に開かない」 → **これは私見・研究データではないため、表現を柔らかく**
- [ ] **30分タイマーは UTAGE Evergreen機能で本当に閉じる実装**(見せかけは景表法違反)
- [ ] **タイマー切れ後にリダイレクト先(`/oto-expired`)を必ず用意**(クリックしても買えない状態を作る)
- [ ] 「先着〇名」「残り〇個」の文言は使用しない(本設計には含めていない)
- [ ] 価格表記は税込で統一
- [ ] 30日返金保証の条件・連絡先を明記
- [ ] 特定商取引法に基づく表記へのリンク必須(別ページ)
- [ ] プライバシーポリシーへのリンク必須

⚠️ **「97%は3日後に開かない」は私見ベース**なので、以下のいずれかに修正推奨:

- 案A:「**多くの方が**、3日後にはPDFを開かなくなります」(柔らかい一般論)
- 案B:「**私が引き寄せ業界20年で見てきた感覚としては**、ほとんどの方が3日後にはPDFを開きません」(個人の観察と明示)

→ **案Bを推奨**(誠実・体験ベース)

⚠️ **30分タイマーの法的取り扱い:**

景表法・特商法上、「期間限定」は**実態を伴えば適法**です。具体的には:
- 本当に30分後にページが期限切れになる(Evergreen Timerで実装)
- 期限後はそのリードに対して、本ページの価格でのアクセスが本当にできない
- 「期間限定」と表記しつつ実際は常時販売、は違法(優良誤認)

UTAGEのEvergreen Timer機能は、まさに**訪問者ごとにタイマーを管理し、期限後は実際にアクセス不能にする**ものなので、適法に実装できます。実装時に必ず動作確認してください。
