### D2. Manifest AI™ リスクフラグ確認 ― 80% 自動化(2分/日)

**従来の手動作業:**
- 全ユーザー対話を目視チェック(100名で平均10分以上)
- 自殺ほのめかし・精神不調検出

**自動化後の流れ:**
```
Make.com Scenario(リスク検出):
  IF Claude応答内のメッセージに死/消える/自殺/うつ などのトリガーキーワード含む
  THEN:
    1. Supabase users.risk_flag を "high_risk" に更新
    2. Kenji の Slack/メールに即時通知(15分以内)
    3. ユーザーには即時専門窓口を案内する応答送信
    4. 通常応答を24時間停止
```

**Kenjiの介入:** **緊急時のみ**(Slack通知が来たらすぐ確認・必要に応じて本人連絡)

**品質劣化リスク:** ❌**ゼロ許容**(命に関わる)・100% AI検出 + 100% Kenji確認の二重チェック

```

Upsell      ¥88,000 × 2件/月  = ¥176K

```

自動化で 100名運営 →
  満足度高(NPS 9-10):60名 → 完全自動でOK
