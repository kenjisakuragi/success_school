# 🤖 私(AI)が事前に用意するもの(土曜朝までに完成)

## 1. Vrew向けマークアップ台本テキスト

```
通常台本(VSL台本):
  「あなたは今までに、引き寄せの本を、何冊、読みましたか?」

私が変換する Vrew用フォーマット:
  「あなたは今までに、
   引き寄せの本を、
   何冊、読みましたか?
   
   ## 強調 ##
   ★★★何冊?★★★」

ルール:
  - 読点(、)で改行 → 自然な字幕分割
  - ★★★で囲まれた部分は強調表示
  - ## 強調 ## で次のフレーズが強調になる
  - 空行は1秒の間
```

私がこの形式で**事前に台本を全動画分まとめて生成**しておきます。

## 2. サムネイル画像(完全固定テンプレ + 差替要素のみ)

  ・下半分:桜の枝のシルエット
  ・右下:小さく「桜木賢治 / マニフェスティング研究所」

可変要素(動画ごとに変える):
  ・キーフレーズ(2-3行・60-80字以内)
  ・アクセントカラー(金 or 赤 or 白)
  ・絵文字 1個(数字 or アイコン)

# 📅 Vrew操作マニュアル(完全ステップバイステップ)

## 事前準備(初回のみ・30分)

```
Step 0-1: Vrew をインストール(https://vrew.voyagerx.com/)
Step 0-2: 桜木テンプレ作成(以下を1度だけ設定)
  - 字幕フォント:游ゴシック Bold
  - 字幕色:白 + 黒縁取り
  - 強調色:金 #FFC857
  - 解像度:1920×1080
  - 背景動画:VREW中小パーティクル(桜の花びら)を読込

Step 0-3: テンプレを「桜木式VSL」として保存
Step 0-4: オープニング(5秒)・エンディング(15秒)テンプレを別途保存
```

これで初回設定終わり。以降は毎回これを呼び出すだけ。

## 動画1本の制作フロー(12-15分)

### Step 1:Vrew 起動・テンプレ呼出(30秒)

```
1. Vrew を開く
2. 「新規プロジェクト」→ テンプレ「桜木式VSL」を選択
3. 1920×1080 を確認
```

### Step 2:台本テキストをペースト(30秒)

```
1. Google Drive から今週の台本ファイル(Markdown)を開く
2. 全文コピー
3. Vrew の「テキストインポート」にペースト
4. ★★★マーク部分が自動で強調字幕になる
```

### Step 3:音声WAVをインポート(1分)

```
1. 「メディア追加」 → WAV ファイル選択
   例:vsl_audio/final_01_hook_Algieba_088.wav
2. Vrew が自動的にタイムラインに配置
3. 「字幕自動生成」をクリック
4. 1分以内に全字幕が自動生成される
```

### Step 4:固有名詞だけチェック(5-7分)

```
1. Ctrl+F で以下を検索・確認:
   - 桜木賢治(正しく出ているか)
   - マニフェスティング
   - Manifest AI
   - マシューズ・ペネベイカー・ヘルツェル・エッティンゲン
   - 628億回
   - 32%・42%・95%・10% などの数字

2. 間違いがあれば、その場でテキスト修正
3. 全体を流し見(2倍速で1分)
4. OK ならStep 5へ
```

### Step 5:オープニング・エンディング追加(30秒)

```
1. 「シーン追加」→ 先頭にオープニング・テンプレを追加
   ・「マニフェスティング研究所(引き寄せの科学)」
   ・動画タイトル
   ・5秒

2. 「シーン追加」→ 末尾にエンディング・テンプレを追加
   ・「無料スターターキット → bit.ly/xxx」
   ・「チャンネル登録」「次の動画」
   ・15秒
```

### Step 6:MP4書き出し(3-5分・バックグラウンド)

```
1. 「書き出し」→ 1080p H.264
2. 出力先:Google Drive「YouTube_出力」フォルダ
3. 書き出し中、Kenji は次の動画の作業へ
```

### Step 7:YouTube アップロード(2-3分)

```
1. 書き出し完了後、YouTube Studio を開く
2. 「動画をアップロード」→ MP4 ファイル選択
3. 別タブの Google Docs から:
   ・タイトル をコピペ
   ・概要欄 をコピペ
   ・タグ をコピペ
4. サムネイル設定(Google Driveから選んでアップ)
5. 終了画面・カードはテンプレで自動適用
6. 公開予約(火曜 or 金曜 7:00)
7. 完了
```
