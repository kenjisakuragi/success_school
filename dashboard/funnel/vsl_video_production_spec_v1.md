# 🎬 VSL映像 制作仕様書 v1 ― ループ+テロップ型

**確定日:** 2026-05-23
**位置づけ:** ループ映像 + 音声(桜木の声) + テロップ(キーフレーズ)で構成する、音声主軸のVSL
**制作工数:** 4-6時間(1日以内)
**コスト:** ¥0(全て無料ツール:CapCut / Pexels)
**動画長:** 30分

# 🎯 設計思想

## 「音声が主役」のミニマル設計

このVSLの心臓は **桜木の声** と **科学的メッセージ**。

過剰な視覚は、それらの強さを薄めてしまう。
だからこそ ― **視覚は声を引き立てる脇役に徹する**。

具体的には:
- ループする1本の映像が背景で静かに動き続ける
- テロップは「キーフレーズが発声された瞬間」だけ浮かび上がる
- BGM は入れない(声と間に集中)
- カットは最小限(視聴者の脳をリセットしない)

これは、Russell Brunson、Sam Ovens、Frank Kern等が高単価ファネルで使う王道フォーマットでもある。

# 🎨 ループ映像の仕様

## 確定:桜の花びらが夜空に舞う

### なぜこのループか

- **ブランド名「桜木」と視覚的に直結**(桜)
- **夜=静謐、内省、自分と向き合う時間**
- **花びらの動きは催眠的でリラックス誘発**
- **顔出しなしポリシーと完全整合**(人物が映らない)
- **30分通して見ても疲れない**(動きが穏やか)

### 入手先

[Pexels.com](https://pexels.com)(完全無料・商用利用可)で以下のキーワード検索:

| キーワード | 期待される映像 |
|---|---|
| `cherry blossom night` | 桜+夜空 |
| `sakura petals falling slow motion` | スローモーションで舞う花びら |
| `pink petals dark background` | 暗背景に花びら |
| `floating particles night sky` | 夜空+パーティクル |

### 選定基準

| 基準 | 詳細 |
|---|---|
| **長さ** | 10-30秒(ループ用) |
| **解像度** | 1080p以上(できれば4K) |
| **動きの速度** | 非常に遅い(ASMR的・催眠的) |
| **色調** | ダーク(背景が暗い・テロップが読みやすい) |
| **シームレスループ** | 始点と終点が違和感なくつながる |

### 代替案(桜が見つからない場合)

| 案 | キーワード |
|---|---|
| 抽象パーティクル | `dark particles slow motion` |
| 月光の海面 | `moonlight ocean calm` |
| 星空 | `starry night slow` |

# 📝 テロップ設計(全35-40カット)

## 基本ルール

- **全文字起こしはしない**(視聴者が読むのに疲れる)
- **キーフレーズだけストロボ的に表示**
- **重要数字は巨大に表示**(628億・33ポイント・95% など)
- **「強調=ゴールド」「数字=コーラル」「通常=白」**で色分け

## スタイル指定

```css
/* フォント */
通常:Yu Gothic Bold
数字:Roboto Bold

/* カラー */
通常テロップ:#ffffff(白)
強調キーフレーズ:#ffc857(ゴールド)
数字:#ff6b6b(コーラル)
CTAリンク:#00d4ff(シアン)

/* サイズ(1080p想定) */
タイトル:80pt
大字(強調):60pt
通常:42pt
キャプション(下部):28pt

/* 配置 */
基本中央寄せ
重要キーフレーズは画面中央
下部キャプションは画面下20%

/* アニメーション */
Fade in:0.3秒
表示時間:2-4秒(発声時間に同期)
Fade out:0.3秒
強調文字:Scale-in(0.8倍 → 1.0倍 で拡大しながら表示)
```

# 🛠️ 制作手順(CapCutで4-6時間)

## Step 1: ループ映像の入手(30分)

1. [Pexels.com](https://pexels.com) にアクセス
2. 検索:`cherry blossom night slow motion`
3. 1080p以上・10-30秒の動画を3-5本ダウンロード
4. 候補から最も「静謐・遅い・暗背景」なものを1本選定

## Step 2: 音声の準備(15分)

1. 既に生成済みの WAV(`vsl_audio/v3_*.wav` から本命選定)
2. 全6ブロック(`01_hook` 〜 `06_cta`)を順に並べる
3. ブロック間に1-2秒の無音を挟む
4. 全体30分の連続音声ファイル(WAV)として書き出し

## Step 3: CapCutでベース映像作成(1時間)

1. CapCut起動 → 新規プロジェクト
2. ループ映像を読み込み → タイムラインに配置
3. **30分連続再生**になるようループ複製(例:20秒の動画なら90回ループ)
4. 音声ファイル(全30分)を同期配置
5. 音量バランス確認(声がクリアに聞こえる)

## Step 4: テロップ配置(2-3時間)

1. 上記スクリプトに従って35-40カットを配置
2. 各テロップは音声の「キーフレーズ発声タイミング+0.2秒」に表示
3. スタイル統一(フォント・カラー・サイズ・アニメーション)
4. 重要キーフレーズだけ拡大表示(Scale-in アニメ)

## Step 5: CTAパートの静止背景化(15分)

1. 27:00 でループ映像のフェードアウト
2. 27:10-30:00 は **桜の花びらの静止画**(同じ Pexels の静止画版)
3. 中央にスターターキットのプレビュー画像
4. 下部にオプトインフォーム(UI要素として後でUTAGEに埋め込む)

## Step 6: 最終調整・書き出し(30分)

1. 全体プレビュー(30分通しで視聴)
2. テロップタイミング微調整
3. 音量正規化(-1dB 程度)
4. MP4 / 1080p / H.264 で書き出し
5. ファイル名:`vsl_v1_final.mp4`

# 🎬 撮影/録音の有無

**録音:すでに完了**(Google Cloud TTS WAV版で生成済)
