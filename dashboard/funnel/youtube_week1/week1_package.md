## 1本あたり 12-15分(並列処理で実質 8-10分)

```
□ Vrew で「桜木式VSL」テンプレを開く
□ ★★★マーク版台本をペースト(vrew_scripts/VSL_full_marked.md から該当ブロック)

□ 自動字幕生成
□ 固有名詞チェック(上記リスト)
□ オープニング + エンディング追加
□ MP4書き出し開始
□ 次の動画に取りかかる
□ 書き出し完了 → YouTube Studio へ
□ メタデータコピペ(本ファイルから)
□ サムネアップ(事前に Canva or DALL-E生成済)
□ 公開予約(指定日時)
□ 完了
```

