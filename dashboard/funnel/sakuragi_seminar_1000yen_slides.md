## 📊 3ヶ月、本科で取り組むと

本書のメソッドが依拠する**実在の研究**が、それぞれ示している変化の方向性です。

| 領域 | 研究で示されている方向性 |
|---|---|
| **自己効力感**(Bandura) | 達成体験・代理体験を積むほど向上(行動継続性に強く影響) |
| **目標の達成率**(Matthews) | 書き出し+共有+進捗報告で、考えるだけの群より有意に高い |
| **心理的健康・免疫機能**(Pennebaker) | 表出筆記の継続で、複数指標が広範に改善 |
| **行動の実行率**(Gollwitzer) | 実装意図(「もしXならY」)で2〜3倍に上昇 |
| **不安・反芻**(Hölzel / Zaccaro) | マインドフルネス瞑想+呼吸法で低下 |
| **願望の達成**(Oettingen) | Mental Contrastingで「願うだけ」を行動に変換 |

> これらの変化は、**毎日のプロトコルを継続した方々**に、それぞれの研究で確認されています。
