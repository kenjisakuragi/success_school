# 🎯 鉄則

**専門用語を本文で初めて出す時は、必ず直後にやさしい翻訳を併記する。**

例:
- ❌ NG「メタ分析で繰り返し確認されています」(専門用語のみ)
- ✅ OK「メタ分析 ─ つまり、何十年もの研究結果を集めた信頼性の高い分析 ─ で繰り返し確認されています」
- ✅ OK「過去30年の研究を集めた信頼性の高い分析(専門用語でメタ分析と言います)で繰り返し確認されています」

# 📚 翻訳辞書

## A. ブランド/メソッド用語

| 専門用語 | やさしい翻訳 |
|---|---|
| **マニフェスティング** | 日本で言う「引き寄せ」のことです。ただ、海外ではすでに科学として研究され始めています |
| **AIマニフェス** | AIを伴走者にして引き寄せを実践する、新しい方法のことです |
| **桜木式 AIマニフェスティング®** | 引き寄せを5つの層(信念・書く・身体・障害分析・AI伴走)で統合した、現代版のメソッドです |
| **スクリプティング** | ノートに願いを書き出す実践のこと |
| **シフティング** | 身体感覚や呼吸を使って、自分の状態を切り替えること |

## B. 心理学用語

| 専門用語 | やさしい翻訳 |
|---|---|
| **メタ分析** | 何十年もの研究結果を集めた、信頼性の高い分析 |
| **効果量** | その実践がどれくらい強く効くかを示す数値(0.5以上で「しっかり効く」とされます) |
| **自己効力感** | 「自分にはこれができる」と感じる、内側の力 |
| **言語的説得** | 言葉で「あなたならできる」と励まされること |
| **達成体験** | 実際に何かを成し遂げた経験 |
| **代理体験** | 他の人の成功を見て「自分にもできる」と感じる経験 |
| **生理的状態** | 心と体の調子が整っているかどうか |
| **実装意図** | 「いつ・どこで・何をするか」を、あらかじめ具体的に決めておくこと |
| **表出筆記法** | 自分の思っていることや感じていることを、ありのまま紙に書き出す実践 |
| **Mental Contrasting** | 願いと一緒に、それを邪魔する現実の障害も書き出すこと |
| **WOOP法** | 願い・結果・障害・計画の4ステップで書く方法 |
| **自己知覚理論** | 人は自分の行動を観察して、自分がどんな人間かを判断する、という心理学の考え方 |
| **セルフ・ディスタンシング** | 自分を一歩離れた場所から、第三者として見つめること |
| **記憶の固定化** | 寝ている間に、その日の出来事や考えごとを脳が整理・強化する仕組み |
| **認知的不協和** | 自分の信じていることと、実際の行動がズレた時に生まれる心の違和感 |

## C. 数字インパクトの「自分ごと化」3段フロー

数字を出すときは、必ずこの3段で展開:

```
❶ 世界では〇〇(衝撃的な数字)
   例:「2024年、世界中で628億回再生されたハッシュタグがあります」

❷ ところが日本ではまだ一部しか知られていません
   例:「ところが日本では、まだ一部の方しか、この大きな流れを知りません」

❸ だから今ここにいるあなたは、すでに先を見ています
   例:「だから今この動画を最後まで聴いてくださっているあなたは、
       すでに、何年も先のことを見ている、ということになります」
```

## D. 肯定起点フレーズ集(冒頭で必ず使う)

```
✅ 推奨フレーズ:
   ・「あなたが何年も大切にしてきた引き寄せの実践は、間違いではありません」
   ・「むしろ海外の最新科学が、それをひとつひとつ裏付け始めています」
   ・「あなたの直感は、正しかったのです」
   ・「やっと、それが言葉になりはじめた時代に、私たちはいます」
   ・「今日はそこに、もう一歩だけ深い視点を、ご一緒します」

❌ 避けるフレーズ(50-60代スピ女性に拒否反応):
   ・「〇〇は嘘でした」
   ・「あなたが信じてきたことは、間違っていました」
   ・「9割は3週間で挫折します」(自己評価を下げる)
   ・「全くのデタラメ」「効果ゼロ」(全否定)
```

## E. 不完全燃焼設計のフレーズ

```
✅ 体験会・無料コンテンツの終盤で使う:
   ・「今日はここまでお伝えできました。続きは別の場所で、もっと深く一緒に進めていきます」
   ・「入口だけ、一緒に開きました。ここから先の歩き方は、いくつもあります」
   ・「ひとつだけ、お伝えしきれなかったことがあります。それは、また別の機会に」

❌ 避けるフレーズ(満足完了感を与えてしまう):
   ・「今日で完結です」
   ・「これだけで全てが分かります」
   ・「もう、これ以上は必要ありません」
```

# 🔧 制作チェックリスト

各コンテンツ仕上げ時に確認:

```
□ 「マニフェスティング」初出時に「引き寄せ」と定義したか
□ 「メタ分析」「効果量」等の専門用語を、やさしい翻訳付きで出したか
□ 数字インパクトを出した時、「自分ごと化」3段フローで展開したか
□ 冒頭に「肯定起点フレーズ」を入れたか(Type A 検証配信を除く)
□ 体験会・無料PDFは「不完全燃焼設計」になっているか
□ ターゲット(50-60代スピ女性)が読んで「やっと言葉になった」と感じるか
□ NGフレーズ(全否定・自己評価下げ)を使っていないか
```
