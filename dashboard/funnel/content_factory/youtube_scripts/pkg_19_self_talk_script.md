# 【ここから下を Vrew にコピペ】

「口ぐせを変えれば、人生が変わる」

昔からよく言われてきた、この言葉。

もしあなたが前向きな言葉を大切に使ってきたなら、その習慣は間違いではありません。ただ、その口ぐせを「本当に効かせる」には、ひとつだけ大切なコツがありました。今日の動画は最後まで聴いてみてください。

最新の心理学は、言葉の力をはっきりと裏付け始めています。今日はそのコツを、ご一緒にひもといていきます。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

まず、良いお知らせからお話しします。

言葉が人の心と行動に影響することは、心理学でも確かに認められています。

スタンフォード大学のバンデューラ博士は、人が自信を持つための源泉のひとつに「言語的説得」を挙げました。

「あなたならできる」という言葉が人の力を引き出す。これは確かな事実です。

ですから「私はできる」「うまくいく」という前向きな口ぐせには、ちゃんと意味があります。

ところが、ここに見落とされがちな点があります。

バンデューラ博士は、同時にこうも示しているのです。

言葉による励まし ─ 言語的説得は、4つある自信の源泉のうち、もっとも効果が弱く、もっとも崩れやすい。

なぜなら言葉だけの自信は、現実が少しでも反証すると、すぐに揺らいでしまうからです。

「私は豊かです」と毎朝唱えても、財布を見てため息が出る。

「うまくいく」と言っても、失敗が続くと「やっぱりダメだ」に戻ってしまう。

これが、口ぐせを変えても人生が変わらなかった人の、本当の理由です。

では、口ぐせを「本当に効かせる」たった1つのコツとは何か。

それは口ぐせの後ろに、必ず「小さな行動」をくっつけることです。

言葉だけで終わらせない。言葉の直後に、その言葉を裏付けるちいさな行動をひとつする。

たとえば、こうです。

「私は健康になる」と言ったら、その直後にコップ一杯の水を飲む。

「私は豊かになる」と言ったら、その直後に財布の中を整える。

「私は人とうまくやれる」と言ったら、その直後に誰かにひとこと感謝を伝える。

たった、これだけです。

なぜこれが効くのか。

ニューヨーク大学のゴルウィッツァー博士の、実装意図という研究があります。

言葉に具体的な行動をくっつけると、その行動の実行率が2倍から3倍に上がる。

そしてその小さな行動を実際にやると ─ 脳の中で「言葉」と「行動の証拠」がセットになります。

すると口ぐせは、ただの願望ではなく「現実に裏付けられた事実」として、脳に刻まれていくのです。

言葉だけだと崩れやすい。

ですが言葉のあとにちいさな行動が伴うと ─ その口ぐせは確かな力を持ち始めます。

これが、「口ぐせを変えれば人生が変わる」を科学的に正しく使う、たった1つのコツでした。

それでは今夜から始められる形に、まとめます。

あなたが変えたい口ぐせを、ひとつ決めてください。

「私は◯◯になる」「私は◯◯できる」

そしてその言葉を口にしたら、必ずその直後に、それを裏付けるいちばん小さな行動をひとつする。

水を飲む。背筋を伸ばす。財布を整える。メッセージを送る。

なんでも構いません。小さいほど続きます。

言葉と行動をセットにする。

それだけで、あなたの口ぐせは人生を動かす力に変わっていきます。

ここまでお聴きいただきありがとうございました。
