# 【ここから下を Vrew にコピペ】

「赤い車がほしい」と思った途端、街中で赤い車ばかりが目につくようになった。そんな経験はありませんか。

もしあなたが引き寄せを実践してきたなら、今日の動画は最後まで聴いてみてください。脳科学が、そのしくみをはっきり説明できるのです。

あなたのその実感は、間違いではありません。今日は引き寄せが起こる「脳の正体」を、ご一緒に解き明かしていきます。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

私たちの脳には、とても優秀な「フィルター」が備わっています。

その名を網様体賦活系 ─ 略して「ラス」と呼びます。

脳の奥深く、脳幹という場所にある神経の集まりです。

このラスが何をしているか。

実は私たちの目や耳には、毎瞬ものすごい量の情報が飛び込んできています。

その全部をいちいち意識していたら、脳はパンクしてしまいます。

そこでラスが、フィルターの役目を果たします。

膨大な情報の中から「自分にとって重要なもの」だけを選んで、意識に上げてくれるのです。

逆に言えば「自分には関係ない」と脳が判断したものは、目の前にあっても見えていない。

ここに引き寄せの、科学的な正体があります。

たとえば、あなたが「赤い車がほしい」と強く思ったとします。

するとラスは「赤い車はこの人にとって重要だ」と判断します。

その瞬間から、これまで気にも留めていなかった街中の赤い車が、次々と目に飛び込んでくるようになる。

赤い車の数が増えたわけではありません。

あなたの脳のフィルターが変わったから、見えるようになっただけなのです。

これは心理学で「カラーバス効果」とも呼ばれる、よく知られた現象です。

そしてこれこそが、引き寄せが「起こったように感じる」しくみの正体です。

「こうなりたい」と明確に願う。

すると脳のラスが、その願いに関係する情報・チャンス・人を、現実の中から拾い上げ始める。

これまで素通りしていた求人情報。聞き流していた誰かの一言。気づかなかった目の前のチャンス。

それらが急に「見える」ようになる。

引き寄せとは、何かが運ばれてくる魔法ではなく ─ あなたの脳が願いに沿って、世界の見え方を変える科学的なしくみだったのです。

では、このラスを意図的に味方につけるには、どうすればいいのか。

答えはシンプルです。

「何がほしいのか」を、脳にはっきりと伝えること。

ぼんやり「幸せになりたい」では、ラスは何を拾えばいいか分かりません。

「来年の春までに、家で月5万円の収入を得たい」

このくらい具体的にすると、ラスは「家でできる仕事の情報」を拾い始めます。

そしてここに、ニューヨーク大学のゴルウィッツァー博士の実装意図を組み合わせます。

「いつ、どこで、何をするか」を具体的に決めておくと、行動の実行率が2倍から3倍に上がる。

ラスが拾い上げたチャンスを、実際の行動につなげる仕組みです。

つまり具体的に願って、脳のフィルターを設定し、拾ったチャンスを行動に移す。

これが、脳科学的に正しい引き寄せの起こし方でした。

それでは今夜から始められる形に、まとめます。

これが、拾ったチャンスを現実につなげる実装意図です。
