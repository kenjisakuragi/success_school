# 【ここから下を Vrew にコピペ】

「どうせ、私なんて」 ─ それが口ぐせになっていませんか。

もしあなたが今、自分をなかなか好きになれずにいるなら、今日の動画は最後まで聴いてください。

これまで自分を変えようと頑張ってきたあなたの努力は、間違いではありません。ただ、もしかしたら自分を好きになるための、ひとつの順番があったのかもしれません。

今日お話しするのは、ずっと自分を好きになれなかった女性が、たった3週間で少しずつ変わっていった、小さな習慣の物語です。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

主人公の名前をYさんとしておきます。

50代の女性。まわりからはしっかり者だと思われていました。

ですがYさんの心の中は、いつも「どうせ私なんて」でいっぱいでした。

誰かが褒めてくれても「お世辞でしょう」と受け取れない。

何かに挑戦しようとしても「私にはどうせ無理」と、最初の一歩が出ない。

Yさんは引き寄せの本で「自分を愛しましょう」「私は素晴らしいと唱えましょう」と読んで、鏡の前で何度も唱えてみました。

ですが唱えれば唱えるほど、心の奥で「嘘っぽい」という声がして、かえって苦しくなっていったのです。

実はこの苦しさには、はっきりとした理由がありました。

心理学者ベム博士の自己知覚理論です。

この理論はこう示しています。

人は自分が「どんな人間か」を、口で唱えた言葉ではなく、実際にとった行動を見て判断している ─

つまり「私は素晴らしい」と何百回唱えても、行動の証拠がなければ脳はそれを信じない。

むしろ「言葉と現実が違うじゃないか」と、自己評価を下げてしまうことさえあるのです。

Yさんに必要だったのは、言葉ではなくちいさな「行動の証拠」でした。

ある夜、Yさんは一冊のノートを開いてこう書いてみました。

「今日、自分ができたことを、ひとつだけ書く」

たったそれだけのルールです。

1週目。

最初は書くことが見つかりませんでした。

ですがよく一日を振り返ると、ちゃんとありました。

「朝、ちゃんと起きた」「家族にご飯を作った」「近所の人に笑顔で挨拶した」

どんなに小さくても、できたことをひとつ書く。

書き終えるとほんの少しだけ、自分のことを認められた気がしたそうです。

2週目。

毎晩ひとつずつ書きためていきました。

するとノートには、自分が「できたこと」が14個並んでいました。

これはスタンフォード大学のバンデューラ博士の言う、自己効力感の源泉、達成体験そのものです。

ちいさな「できた」を積み重ねると、「私はできる人間だ」という感覚が、言葉ではなく証拠の上に育っていきます。

3週目。

Yさんはノートを見返して気づきました。

「私、こんなにいろんなことを、ちゃんとやってたんだ」

そしてある朝、誰かに褒められたとき ─ 初めて「ありがとう」と素直に受け取れたそうです。

「どうせ私なんて」が「私、けっこうがんばってるかも」に変わっていた瞬間でした。

ここで大切なことをお伝えします。

Yさんは無理にポジティブになろうとしたわけではありません。

「私は素晴らしい」と唱えたわけでもありません。

Yさんがやったのは、たったひとつ。

毎晩その日「できたこと」をひとつだけ書いて、ちいさな証拠を積み重ねたことです。

自己肯定感は、言葉で無理に上げるものではなかった。

ちいさな行動の証拠を、自分で積み重ねていくものだったのです。

それでは、あなたが今夜から始められる習慣をご紹介します。

ノートを1冊、用意してください。

寝る前に、今日「できたこと」をひとつだけ書きます。

どんなに小さくても構いません。むしろ小さいほどいいのです。

「ちゃんと起きた」「ご飯を食べた」「この動画を最後まで見た」

それでも立派な「できたこと」です。

3週間続けるとノートには、21個の「できた」が並びます。

その21個が、何よりも確かな、あなたが自分を好きになるための証拠になります。

ここまでお聴きいただきありがとうございました。
