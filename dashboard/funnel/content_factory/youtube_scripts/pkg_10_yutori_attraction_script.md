# 【ここから下を Vrew にコピペ】

「念じれば叶う」と信じて、何年も唱え続けてきた。

それでも現実が動かなかった ─ そんなあなたへ。

もしいまそう感じているなら、今日の動画は必ず最後まで聴いてください。

引き寄せを大切に実践してきたあなたの信じる気持ちは、間違いではありません。

むしろ最近、海外の心理学が30年かけて積み上げてきた研究が、伝統的な引き寄せの実践をひとつひとつ裏付け始めています。

そして今日ご紹介したいのは、ユーチューブで29万回再生されているある動画です。

タイトルは『ゆとりくんが語る引き寄せの法則の真実』。

この動画のコメント欄には、こんな声がたくさん寄せられていました。

「今まで引き寄せを間違ったふうに捉えていた」
「念じれば叶うと思って、叶わないから辛かった」
「目の前の不安に勇気を持って向き合うことだった」

ゆとりくんが語った内容を、現代の心理学とつなぎながらわかりやすくお届けします。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

ゆとりくんは、ユーチューブで引き寄せや自己実現について発信している方です。

その動画の核心は、3つの真実に集約されていました。

ひとつ目の真実。

「念じれば叶う」は、半分しか合っていないということ。

これを聞いて、これまで何年もアファメーションを続けてきた方は、少し驚かれるかもしれません。

ですが、ゆとりくんはこう語ります。

ふわふわとした感覚で「願えば叶う」と思ってしまうと、目の前の現実から目を逸らすことになる。結果、何年経っても何も動かない ─

これは、ニューヨーク大学のガブリエル・エッティンゲン博士が20年以上かけて行ってきた研究と見事に重なります。

博士の研究が示しているのは、こうです。

叶った姿をポジティブにイメージするだけの群は、何もしなかった群と比べて達成率がむしろ低下する。

ウープ法と呼ばれるこの博士の研究の結論は、ゆとりくんの動画と同じことを語っていたのです。

「願う」だけでは足りない。「願う + 向き合う + 動く」がセットで初めて引き寄せは効き始める。

ふたつ目の真実。

ゆとりくんが何度も強調していたのが、「行動を最大化する原理」というキーワードでした。

コメント欄でもっとも反響が大きかったのが、この一節です。

「目の前の不安に勇気を持って向き合って、自責の範囲を最大にして行動を最大化するための原理」

これも、ニューヨーク大学のピーター・ゴルウィッツァー博士の研究とぴったり重なります。

博士の「実装意図」と呼ばれる研究では、「いつ・どこで・何をするか」をあらかじめ具体的に決めておくと、行動の実行率が2倍から3倍に跳ね上がると報告されています。

ゆとりくんが「行動最大化」と呼んでいたものは、心理学では「実装意図」として20年以上前から再現性が確認されてきた事実だったのです。

そしてもう一つ ─ 「目の前の不安に勇気を持って向き合う」というフレーズも、心理学の研究と繋がります。

テキサス大学のジェームズ・ペネベイカー博士が30年以上研究してきた「表出筆記法」。

200以上の追試で繰り返し確認されてきたのは、自分の不安や感情を紙に書き出すことで、心身の健康・免疫機能・目標達成率のすべてが有意に向上するという事実です。

不安は、避けるのではなく、紙の上で言葉にしたとき初めて整理される ─ ゆとりくんが直感で語っていたことが、すでに30年の科学に裏付けられていたのです。

みっつ目の真実。

これは、コメント欄でいちばん多くの人が「深く刺さりました」と書いていた言葉です。

「真の自立とは、依存先がたくさんあること」

ゆとりくんがこう語った瞬間、画面の向こうの多くの方がハッとなったそうです。

長年、自立とは「ひとりで何でもできること」だと信じて自分を追い詰めてきた人にとって、これは大きな救いの言葉でした。

ひとつの依存先しかないと、それを失った瞬間、人は不安定になります。

でも、家族・友人・仕事仲間・趣味の場・ノートとペン ─ 依存できる場所が10個あれば、ひとつ揺らいでも残り9つが支えてくれる。

ゆとりくんの言う「心の状態を整える」という言葉は、一見スピリチュアルな表現に聞こえるかもしれませんが、その本質は ─ 自分が安心して頼れる、温かい関係や場所をいくつも持っている状態のことだったのです。

これは、心理学の社会的支援ネットワークの研究でも繰り返し確認されてきたことと一致します。

頼れる先が多い人ほどストレス耐性が高く、望む現実を実現できる確率も有意に上がる ─。

それでは、ゆとりくんが語った『3つの真実』を、今夜から実践する3ステップにまとめます。

ひとつ目のステップ。

ノートを1冊用意して、いま叶えたい願いを一行書きます。

ふたつ目のステップ。

その下に「目の前にある、向き合いたくないこと」を一行書きます。

「貯金がないのに、家計簿を見るのが怖い」
「相手の気持ちを聞くのが怖くて、ずっと避けてきた」
「健康診断の結果を、まだ開けていない」

これがエッティンゲン博士のウープ法の「障害」 ─ 不安を直視することです。

みっつ目のステップ。

そのさらに下に、明日の朝、自分が取れる「ちいさな勇気の行動」を一行書きます。

「明日の朝7時、家計簿アプリを1分だけ開く」
「明日、信頼できる友人ひとりに、心を打ち明けるメッセージを送る」
「明日の昼休み、健康診断の封筒を机に出すだけ」

これがゴルウィッツァー博士の実装意図。

そして翌日、それを実行できたら、ノートの隅にちいさな丸印をひとつ。

3週間続けてみてください。

ノートには、不安と向き合った記録と、ちいさな勇気の丸印が、ぎっしりと並んでいるはずです。

その記録こそが、ゆとりくんの言う「心を整える」の正体です。

自分の中の不安を見ないふりをするのではなく、ひとつずつ言葉にして、ひとつずつ向き合った積み重ね ─ それが、引き寄せが本当に効き始める原理でした。
