# 【ここから下を Vrew にコピペ】

お金のことを、考えない日は、ない。

それなのに、追いかければ追いかけるほど、なぜか遠ざかっていく ─ もしあなたが今、そんなお金との関係に疲れているなら、今日の動画は必ず最後まで聴いてください。

あなたがこれまで一生懸命、お金と向き合ってきたことは、間違いではありません。

ただ、もしかしたら「頑張る」とは逆の、ひとつの方法があったのかもしれません。

今日お話しするのは、お金を追いかけるのをやめた瞬間に流れが変わった、ある女性の物語です。

動画の最後には無料プレゼントの案内もあります。それでは、本編をどうぞ。

主人公の名前を、エスさん、としておきます。

50代の女性。ずっとお金の不安と共に生きてきました。

「もっと稼がなきゃ」「もっと貯めなきゃ」「このままじゃ、老後が不安」

朝起きた瞬間から夜眠るまで、頭の中はお金のことでいっぱいでした。

引き寄せの本も、たくさん読みました。

「お金が入ってくる姿を、毎日イメージしましょう」と書かれていたので、エスさんは通帳の残高が増える様子を、毎晩、必死に思い描きました。

ですが、現実は何も変わらなかったのです。

それどころか、イメージすればするほど、現実とのギャップに心が苦しくなっていきました。

実は、この苦しさには、はっきりとした理由がありました。

ニューヨーク大学のエッティンゲン博士の研究です。

博士は20年以上の研究で、こう示しています。

「叶った姿を、ただ強く思い描くだけ」だと、脳はそれを「もう手に入れた」と錯覚してしまう。

すると、満足してしまい、行動する力が逆に抜けていく ─

お金を強く追い求め、イメージすればするほど、かえって動けなくなる。

エスさんは、まさにその状態にいたのです。

ある夜、エスさんは疲れ果てて、こう思いました。

「もう、お金のことを考えるのをやめたい」

そして、その気持ちをノートに書き出してみることにしました。

ペネベイカー博士の表出筆記法という、テキサス大学が30年研究してきた方法です。

紙に自分の本当の気持ちを書き出すと、ぐるぐるしていた思考が整理され、心の負担が確かに軽くなる ─ 200以上の研究で確認されてきた事実です。

エスさんは15分間、ただ書き続けました。

「お金がこわい」「失うのがこわい」「人と比べて、焦っている」

書き終えたとき、ふと、こんな言葉がこぼれ落ちたそうです。

「私は、お金そのものがほしかったんじゃない。ただ、安心して眠りたかっただけだ」

その瞬間、エスさんの中で、何かがふっとゆるみました。

「お金を追いかけるの、いったん、やめてみよう」

これが、エスさんの言う「手放した瞬間」でした。

手放す、とは、諦めることではありません。

お金をぎゅっと握りしめていた手を、いったん開くことです。

翌朝、エスさんは不思議と頭が軽くなっていました。

そして、ずっと不安で見られなかった家計簿を、初めて落ち着いて開くことができたのです。

すると、見えてきました。

毎月の、使っていない固定費。なんとなく続けていた、ムダな出費。

エスさんは、ひとつずつ整理していきました。

お金を「追いかける」のではなく、いま手元にあるお金と「向き合う」 ─

そうしているうちに、エスさんは心に余裕が生まれ、ふと「家でできる小さな仕事を始めてみようかな」と思えたそうです。

お金が魔法で増えたわけではありません。

ですが、握りしめていた手を開いたことで、お金との関係そのものが変わり始めたのです。

ここで、大切なことを、お伝えします。

エスさんを変えたのは、3つのことでした。

ひとつ、お金への執着を、いったん手放したこと。

ふたつ、本当の気持ちを紙に書き出して整理したこと。

みっつ、追いかけるのをやめて、いま手元にあるお金と向き合ったこと。

手放す、書く、向き合う。

この3つが、何年も止まっていたお金の流れを動かし始めたのです。

それでは、あなたが今夜から始められるステップを、ご紹介します。
