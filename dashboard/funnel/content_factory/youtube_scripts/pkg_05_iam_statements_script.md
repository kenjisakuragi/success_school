# 【ここから下を Vrew にコピペ】

「私は豊かです」と毎日ノートに書いても、現実が何ひとつ動かない。

もしあなたがいまそう感じているなら、今日の動画は最後まで聴いてください。その苦しさの原因は、あなたの信念不足ではないからです。

朝起きたらまず声に出して唱えた。寝る前にも書いた。ボイスメモに録音して通勤中に聴いた。

それでも3ヶ月、半年、1年経っても現実は何ひとつ動かない。

むしろ書けば書くほど現実とのギャップに心が苦しくなる。

「自分は信じ切れていないのかもしれない」
「もしかしたら自分には引き寄せのセンスがないのかもしれない」

そう自分を責めてしまう方は、決してあなただけではありません。

「『私は豊かです』と書けば叶う」というメッセージそのものに、致命的な見落としがひとつ隠れています。

そしてその見落としは20年以上前にスタンフォード大学の心理学者によってすでに明確に指摘されていました。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

近年、海外の引き寄せ系の動画では必ずと言っていいほどある書き方が紹介されています。

「私は」で始まる宣言文を書く、という方法です。

やり方はこう説明されています。

ノートを開いて、未来形ではなく今すでにそうである姿で書く。

「私は豊かになりたい」ではなく「私は豊かです」と書く。
「お金が欲しい」ではなく「私はお金に愛されています」と書く。
「愛されたい」ではなく「私はすでに深く愛されています」と書く。

これを毎日、声に出して読み、ノートに書き、寝る前に唱える。

3ステップで潜在意識を書き換え、現実が動き出す ─ そう語られています。

人気動画のコメント欄には、こんな成功体験も並んでいます。

「6日後に、まさに書いた通りのチャンスが向こうからやって来た」
「ボイスメモで聴き続けたら、現実が動き出した」

ここまで聞くと、確かに効果があるように見えます。

ですが、ここに見落とされている事実があります。

こうした成功体験の影で、3ヶ月続けても何も起こらず静かに辞めていく人がその何十倍もいるのです。

そして実は、その「叶わなかった人たち」の挫折を心理学はずっと前に予測していました。

その答えを出したのが、20世紀を代表する心理学者、スタンフォード大学のアルバート・バンデューラ博士です。

博士は「自己効力感」 ─ セルフ・エフィカシー ─ という概念を世界で初めて提唱しました。

自己効力感とは、ひとことで言えば「自分はこれができる」と信じる内側の力のことです。

そしてこの力が高い人ほど実際の達成率が高くなる ─ これは過去30年以上のメタ分析で繰り返し確認されてきました。

ここまで聞くと、こう思えます。

「やはり『私は豊かです』と毎日書くのは正しいのではないか」

「アイデンティティを宣言することで自己効力感が高まり、現実が動くのだ」と。

ところがバンデューラ博士は、もうひとつ決定的なことを発見していました。

自己効力感を育てる源泉はひとつではない、ということです。

博士はその源泉を4つに分類しました。

ひとつ目は達成体験。実際に何かを成し遂げた経験です。

ふたつ目は代理体験。他人の成功を見て、自分にもできると感じる経験です。

みっつ目は言語的説得。「あなたならできる」と言葉で励まされる経験です。

よっつ目は生理的状態。心身の調子が整っていることです。

「私は豊かです」と書く実践が使っているのは、このうちの3番目「言語的説得」だけです。

そしてバンデューラ博士の研究は明確に示しています。

4つの源泉のうち、もっとも効果が弱くもっとも崩れやすいのが「言語的説得」だったのです。

ここに、もうひとつ重要な心理学の知見があります。

「自己知覚理論」と呼ばれる、ベム博士の研究です。

この理論はこう示しています。

人は自分が「どんな人間か」を、自分の言葉ではなく自分の行動の積み重ねを観察して結論づける ─。

つまり、いくら「私は豊かです」と書いても、書くだけで終わっているなら脳は逆にこう判断します。

「私はノートに豊かと書いている人だ。実際の生活では毎月の支払いに不安を感じている人だ」と。

書けば書くほど現実とのギャップが脳に記録され、自己効力感はむしろ削られていく ─

これが「『私は』の宣言を書くだけ」で多くの人が陥っている、本当の落とし穴です。

では、どうすれば「私は豊かです」が本当に効くようになるのでしょうか。

答えはシンプルです。

書くだけで終わらせず、その下に「明日の小さな証拠」を1行書き足すことです。

たとえば、こう書きます。

ノートの一行目に「私は豊かです」と書く。

その下の行に「そのために明日の朝、家計簿アプリを開いて1週間の支出を1分だけ確認する」と書き足す。

「私は愛されています」と書いたなら、その下に「明日、友人ひとりに3行のメッセージを送る」と書く。

「私はすでに成功しています」と書いたなら、その下に「明日の朝、興味のある分野の動画を1本だけ観る」と書く。

行動は何でも構いません。

ちいさければちいさいほど続きます。

そして翌日、それを必ず実行する。

実行できたら、ノートの隅にちいさな丸印をひとつつける。

これは、ニューヨーク大学のゴルウィッツァー博士が研究してきた「実装意図」と呼ばれる手法です。

「いつ・どこで・何をするか」をあらかじめ具体的に決めておくと、行動の実行率は2倍から3倍に跳ね上がると報告されています。

そして翌日、丸印がひとつ増える。

これでベム博士の自己知覚理論が、ようやく逆向きに働き始めます。

「私はノートに書いたことを、実際に行動した人だ」

「私は自分との約束を、ひとつ守れた人だ」

脳がこう自分を認識し直したとき、自己効力感は言葉ではなく「行動の証拠」の上に、着実に育っていきます。

3週間後にノートを見返してみてください。

そこには、ちいさな丸印がぎっしりと並んでいるはずです。

その丸印の重みが、何よりも強い「私は豊かです」の証拠になっています。

このとき初めて、ノートに書いた「私は」の宣言が現実を動かし始めます。

逆に言えば「明日の証拠」が書かれていない「私は」の宣言文は、何百回書いても現実を動かす力を持てなかったのです。
