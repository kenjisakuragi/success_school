# 【ここから下を Vrew にコピペ】

1937年に書かれた一冊の本が、いまも世界中で読まれ続けています。タイトルは『思考は現実化する』。

もしあなたが「願えば叶う」の本当のしくみを知りたいなら、今日の動画は最後まで聴いてください。

引き寄せを長く大切にしてきたあなたの実践は、間違いではありません。今日はその源流にいる一人の人物の物語と、彼の発見が現代の心理学とどう繋がるのかをお話しします。

動画の最後には無料プレゼントの案内もあります。それでは本編をどうぞ。

この本が生まれたのは世界恐慌のまっただ中。多くの人が希望を失っていた時代でした。

著者の名はナポレオン・ヒル。もともと貧しい家に生まれた新聞記者でした。

20代のころ彼は、ある大富豪に取材をする機会を得ます。

その人物の名はアンドリュー・カーネギー。当時、世界一の鉄鋼王と呼ばれた人です。

カーネギーは若きヒルにこう言いました。

「成功には法則がある。それを私が知る成功者たちに会って、20年かけて調べ上げてみないか」

報酬はありません。紹介状を渡すだけ。

ですがヒルは、その無謀な依頼を引き受けました。

それから20年。

ヒルは発明王エジソン、自動車王フォードをはじめ、500人を超える成功者に直接会い、その思考と習慣を調べ続けました。

そしてついに、全員に共通するたった1つのことを見つけ出したのです。

それはお金でも才能でも、生まれた環境でもありませんでした。

成功者たちに共通していたのは「明確な願望を紙に書き、毎日それを見て、行動に移していた」ことでした。

ただぼんやり「成功したい」と願っていたのではありません。

「いつまでに、何を、どうやって手に入れるか」をはっきりと紙に書き、毎日声に出して読み、そして必ず行動していた。

ヒルはこれを「願望の明確化」と呼びました。

そしてここからが今日の本題です。

ヒルが100年近く前に直感と観察で見つけたこの法則は、現代の心理学が3つの研究で裏付けています。

ひとつ目。スタンフォード大学のバンデューラ博士の自己効力感です。

「自分はできる」と信じる力が高い人ほど達成率が高い。成功者たちが持っていた、揺るがない自己信頼そのものです。

ふたつ目。ドミニカン大学のマシューズ博士の研究です。

目標を紙に書き出した人は、書かなかった人より達成率が33ポイント高かった。ヒルの「紙に書く」が数字で裏付けられました。

みっつ目。ニューヨーク大学のゴルウィッツァー博士の実装意図です。

「いつ、どこで、何をするか」を具体的に決めると行動率が2倍から3倍に上がる。ヒルの「必ず行動する」の正体です。

つまりナポレオン・ヒルが500人の成功者から見つけた「たった1つの共通点」は ─

「願いを明確に紙に書き、毎日見て、具体的に行動する」こと。

そしてそれは、現代の心理学が3つの研究で裏付けた、再現性のある方法だったのです。

100年近く前の知恵が、最新の科学とぴたりと重なる。

これが『思考は現実化する』がいまも世界中で読まれ続けている、本当の理由です。

それではヒルの発見を、今夜から実践する形にまとめます。

ノートを1冊、用意してください。

ひとつ、「いつまでに、何を手に入れたいか」をできるだけ具体的に一行書く。

ふたつ、それが叶ったらどんな気持ちか、を書く。

みっつ、「そのために明日、何をするか」をひとつだけ具体的に書く。

そして毎朝それを声に出して読み、書いた行動を実際にやってみてください。

ぼんやり願うのではなく、明確に書いて、毎日見て、行動する。

500人の成功者がやっていたことを、あなたも今夜から始められます。

ここまでお聴きいただきありがとうございました。

最後に、ひとつだけお願いがあります。

もし今日の話が少しでも心に響いたなら ─ 高評価を押して、コメント欄に「明確に書いて、行動します」と書いてみてください。

実は人は、心に決めたことを言葉にして宣言すると、行動の実行率がぐっと上がることが分かっています。

あなたのその一言が、明日のあなたの背中をそっと押してくれます。

そして同じ一歩を踏み出す仲間の声も、きっとあなたの力になります。
