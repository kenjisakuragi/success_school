# 🚨 薬機法・景表法:臨床語の安全な言い換え(競合実例ベース)

| NG(臨床語/効果断定) | ⭕ 安全な言い換え |
|---|---|
| 不安を治す/治療する | 不安が**和らぐ/軽くなる/ふっと楽になる** |
| うつを改善する | **心が疲れたときの過ごし方/休め方** |
| パニック障害を緩和 | **気持ちが落ち着く/心が穏やかになる**(疾患名を出さない) |
| 自己肯定感を高める(効果断定) | **自分を大切にする/自分の味方になる/自分を受け入れる** |
| 必ず効く/100%治る | **〜な人が手放していること/〜が楽になった人たち** |
| メンタルを強化(医療的) | **図太いメンタル/折れない心の習慣** |
| トラウマを治療 | **過去の重さを手放す/もう自分を責めなくていい** |
| 病気/症状/診断 | **生きづらさ/しんどさ/心が重い** |

運用原則:①効能を断定せず「気づき・考え方・習慣・言葉」として提示 ②疾患名は入口の共感まで・解決パートで医療を示唆しない ③「楽になる/軽くなる/穏やかになる」など主観的・可逆的表現 ④「科学的に正しい」は引き寄せ手法の根拠であって、不安・うつへの治療効果の文脈には使わない。
