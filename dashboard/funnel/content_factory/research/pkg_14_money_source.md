# 🔬 科学的基盤(8研究リストから・pkg_11と同じ3本で台本型固定)

```
❶ ペネベイカー表出筆記(テキサス)→ お金への不安を書き出す
❷ ゴルウィッツァー実装意図(NYU)→ お金の小さな行動を決める
❸ バンデューラ自己効力感(スタンフォード)→ 行動の達成積み重ね
```

## ⚠️ 捏造防止の重要注記

```
「お金の流れが変わった」は、魔法でお金が増えた話にしない。
  ・お金と向き合えるようになった(不安の整理)
  ・無駄な固定費に気づいた(行動)
  ・副収入の一歩を踏み出した(行動)
→ 「行動が変わった結果、現実が動いた」という範囲で描く
```

# 📖 ストーリーアーク(pkg_11と同型・主人公だけ差し替え)

```
主人公:Tさん(50代女性・パート主婦・仮名)
状況:
  ・お金がいつも不安・貯金がほとんどない
  ・通帳を見るのが怖くて、ずっと避けてきた
  ・引き寄せ本で「お金は豊かさ」と読んだが、不安は消えない

Week 1:お金への不安を15分書く(表出筆記)
  ・「老後どうしよう」「夫に言えない」「見るのが怖い」
  ・書ききると、少しだけ冷静になれた

Week 2:本当はどうしたいかが見える
  ・「贅沢したいんじゃない。ただ、安心して眠りたいだけ」

Week 3:明日の小さな行動を1つ
  ・「明日、家計簿アプリを開いて、固定費を1つだけ見直す」
  ・実行 → 使っていないサブスクを発見・解約
  ・小さな"お金が残る"成功体験 → 次の行動へ

結果:お金が魔法で増えたのではなく、
     お金と向き合い、行動が変わり、流れが動き始めた
```
