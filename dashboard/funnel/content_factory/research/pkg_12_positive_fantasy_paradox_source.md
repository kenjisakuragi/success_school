
## 核心となる発見(検証済み)

```
「期待(expectation)」と「空想(fantasy)」は、
未来の成功に対してまったく逆の影響を持つ。

ポジティブな空想(=願うだけ・叶った姿を思い描くだけ)は、
実際の努力と成功を「むしろ下げる」。

→ 現在と未来の対比(Mental Contrasting)を行うことで、
  初めて認知・感情・行動が変化する。
```

# 🧠 なぜ「望むほど叶わない」のか(メカニズム)

```
ポジティブな空想を生々しく思い描く
  ↓
脳は「すでに達成した」と錯覚する
  ↓
達成感・満足感を、先に味わってしまう
  ↓
身体がリラックスし、エネルギー(血圧等)が下がる
  ↓
実際に行動するための活力が「放電」される
  ↓
結果、現実では何も起こらない

※ エッティンゲン博士は、水分を絶った被験者の実験で、
  ポジティブ空想群は血圧(=行動エネルギーの指標)が
  下がることも示している。
```

---

# ✅ 解決策:WOOP(願うこと自体は無駄ではない)

```
願う(Wish)ことは、出発点として必要。
ただし「願うだけ」で止めず、4ステップで完結させる。

W:Wish     ─ 願い(叶えたいこと)
O:Outcome  ─ 結果(叶った最高の状態を思い描く)
O:Obstacle ─ 障害(自分の内側にある妨げ)
P:Plan     ─ 計画(障害が起きたら何をするか・if-then)

→ 願い+障害の「対比」が、脳に「まだ達成していない」と
  認識させ、行動エネルギーを保つ。
→ ゴルウィッツァー博士の実装意図(行動率2-3倍)と統合された手法。
```
