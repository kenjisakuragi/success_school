# 📖 ストーリーアーク

## 主人公:Kさん(60代女性・仮名)

```
状況:
  ・夫が1年前に定年退職
  ・家に夫がいるのに、会話がほとんどない
  ・何を話しかけても「ああ」「うん」だけ
  ・「このまま二人で老後を過ごすのか」と気が重い
  ・引き寄せ本で「感謝すれば関係が変わる」と読んだが、できなかった
```

## 3週間の経過

```
Week 1:不満を書く
  ・ノートに、夫への不満を15分書く
  ・「なぜ何も話してくれないの」「私ばかり気を遣っている」
  ・書くうちに涙・でも少しスッキリ(表出筆記の効果)

Week 2:不満の奥が見えてくる
  ・書き続けるうちに気づく
  ・「本当は、夫が健康で家にいてくれること自体、ありがたい」
  ・「私は、ただ、もう一度、笑い合いたいだけだった」

Week 3:小さな行動を決める
  ・「明日の朝、コーヒーを淹れるとき、ひとこと感謝を言ってみよう」
  ・実際に「いつもありがとうね」と言ってみた
  ・夫が、驚いた顔のあと、少し照れて笑った
  ・その日の夕食、久しぶりに会話が生まれた
```

## 学び

```
関係を変えるのは「相手を変えること」ではなく、
「自分の中の不満を整理し、ひとつの小さな言葉を実際に口にすること」だった。
```
