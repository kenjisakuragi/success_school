# 🔄 全体フロー

```
[Step 1] リサーチ
  YouTube/海外ブログ/X で "scripting" "manifesting" 検索
  ↓
  人気動画を書き起こし → research/ フォルダに保存
  ↓
[Step 2] 切り口設計(AI)
  「桜木式に翻訳」+「興味を引くタイトル」
  ↓
[Step 3] 同時生産(1ネタ→3媒体)
  ┌────────────┬────────────┬────────────┐
  │ YouTube台本 │ note記事    │ SNS投稿     │
  │ (Vrew用)    │ (完成原稿)   │ (X/IG)     │
  └────────────┴────────────┴────────────┘
  ↓
[Step 4] 制作
  YouTube: Vrew全文書き起こし → アップ
  note:    コピペ投稿 + YouTube埋め込み
  SNS:     コピペ投稿 + note/YouTubeリンク
  ↓
[Step 5] 相互送客の回路完成
```

# 🎯 1ネタ = 3媒体パッケージの単位

```
パッケージID: pkg_NN_キーワード(例: pkg_01_lucky_girl)

各パッケージに必ず含むもの:
  ✅ research/pkg_NN_source.md  ─ 元ネタ書き起こし+引用元
  ✅ youtube_scripts/pkg_NN_script.md  ─ Vrewにコピペするだけの全文
  ✅ note_articles/pkg_NN_note.md  ─ note入稿用本文(タイトル/タグ含む)
  ✅ sns_posts/pkg_NN_x.md  ─ X投稿(YouTube公開後/note公開後の2種)
```

# 📝 制作ルール

## YouTube台本

- **ト書きなし・効果音指示なし・カメラ指示なし**
- 桜木が話す言葉だけを上から順に書く
- Vrewにコピペ → 自動字幕生成 → 5-10分で動画化
- 1本目標:5-8分(800-1,200字)

## note記事

- **コピペで完成・タイトル/タグ/見出し全て含む**
- 冒頭にYouTube埋め込み用URL欄(後で差し替え)
- 本文2,500-4,000字
- 末尾にVSL誘導(無料スターターキット)

## SNS投稿

- 140字以内×複数パターン
- A:YouTube公開告知 / B:note公開告知 / C:翌週リマインド
