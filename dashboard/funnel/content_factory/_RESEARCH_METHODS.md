# 1️⃣ データ取得手法 ─ 検証結果まとめ

## ✅ 機能する手法(採用)

| 手法 | 取得できるもの | 信頼度 |
|---|---|---|
| **r.jina.ai + YouTube watch ページ** | 動画タイトル・説明欄・コメント欄・章立て・チャンネル情報 | ◎ 高 |
| **r.jina.ai + summarize.tech** | 動画内容の要約(成功時)・章立て | ○ 中(失敗あり) |
| **r.jina.ai + YouTube検索結果** | 競合動画の一覧・タイトル・再生数 | ◎ 高 |
| **r.jina.ai + Wikipedia** | 学術知識・研究者情報・正確な事実 | ◎ 高 |

## ❌ 機能しない手法(回避)

| 手法 | 失敗理由 |
|---|---|
| yt-dlp(直接) | サンドボックスSSL証明書ブロック+権限拒否 |
| youtube-transcript-api(直接) | SSL証明書ブロック |
| youtubetotranscript.com | 403 Forbidden(Bot対策・CAPTCHA) |
| kome.ai / downsub | ランディングページのみ・実トランスクリプト出ない |
| Google/DuckDuckGo/Bing検索 | JS未レンダリングで結果取れず |

## 🎯 確定したリサーチ標準フロー

```
[1] r.jina.ai + YouTube検索結果   → 競合・トレンド調査(再生数で人気テーマ把握)
[2] r.jina.ai + 対象動画watchページ → 説明欄・コメント欄・章立て取得
[3] r.jina.ai + summarize.tech     → 内容要約(取れれば)
[4] r.jina.ai + Wikipedia等        → 引用研究の正確な事実確認
[5] 上記を統合 → research/pkg_NN_source.md にまとめる

※ 完全な逐語トランスクリプトは現状取得不可。
   「説明欄 + コメント欄 + 要約 + 章立て」で実質的に内容を再構成する。
   どうしても逐語が必要な場合のみ、Kenjiがローカルで字幕取得。
```
