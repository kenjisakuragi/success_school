# 🎯 鉄則1:Layer 0「肯定起点」(2026-05-25 必須化)

**冒頭で必ず「あなたの実践は間違いじゃなかった」と肯定する。**

50-60代スピ女性層は「否定で入ると拒否反応」を起こす(「私が信じてきたことは間違いだったの?」)。これを避けるため、痛みフックや常識破壊の前に、**Layer 0:肯定共鳴**を必ず挿入する。

```
[Layer 0:肯定共鳴・必ず最初の1-2文]
✅ 推奨フレーズ(いずれか):
   ・「もしあなたが何年も引き寄せを大切にしてきたなら、その実践は間違いではありません」
   ・「あなたの直感は、正しかったのです」
   ・「やっと、それが言葉になりはじめた時代に、私たちはいます」
   ・「むしろ海外の最新科学が、それをひとつひとつ裏付け始めています」
```

**Type A 否定形批判は Type A'(肯定起点型)に書き換えて運用する。**
従来の Type A(「〇〇は嘘でした」)は男性向けチャネル・検証配信のみで使用。

---

# 🎯 鉄則2:6秒ルール

**冒頭6秒以内(=2行以内)で「もしそう感じているなら、今日の動画は必ず最後まで聴いてください」相当の呼びかけまで到達させる。**

理由:
- YouTube視聴維持率の山場は冒頭6-10秒
- ここで視聴者が「これは自分のための動画」と判断
- 痛みの3並列等の詳細描写は、呼びかけの「後」に展開

---

# 🚫 共通NGパターン

```
❌ 自分(桜木)語りから入る
   悪い例:「こんにちは、桜木賢治です」
   良い例:いきなり視聴者の痛み・興味・知的好奇心から入る

❌ 痛みの3並列を冒頭で展開しすぎる
   悪い例:30秒かけて痛みを描写してから呼びかけ
   良い例:1-2行に凝縮 → 即呼びかけ → その後に痛みを膨らます

❌ Type A(否定形批判)ばかり連発する
   悪い例:5本連続で「〜は嘘でした」
   良い例:A・B・C・Dを混在させる(40/25/20/10/5の比率)
```

# 📊 タイプ自動選定の判断基準(AI用)

```
リサーチ動画の内容が:
  ・海外スピ系の主張で科学的根拠が弱い  → Type A
  ・科学的根拠のあるメソッドを紹介      → Type B or D
  ・特定の研究者・著者にフォーカス      → Type C
  ・1つの研究を深掘りする内容          → Type E
  ・実装手順が中心の動画                → Type D
```

直近のpkg配分を確認して、連続して同じTypeにならないようバランスを取る。

例:
- pkg_06 まで A連発の場合 → pkg_07 は B or C を強く推奨
- A 3連続したら次は B/C/D いずれか必須
