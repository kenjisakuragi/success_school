# ✅ 台本QAチェックリスト(桜木式・採点ルーブリック)

**役割:** 台本チェック担当ロール「QAエディター」が、生成済み台本を**出荷前に**この基準で機械的に採点する。
**対象:** `youtube_scripts/pkg_NN_*.md`(note記事・SNSにも準用)
**運用:** 1台本=1チェック。**合格(GO)するまで出荷しない**。差し戻し時は具体的な修正指示を返す。
**最終更新:** 2026-05-29 / 黄金フォーミュラ・コメント誘発CTA・英語禁止を反映

---

# 🎭 チェック担当ロール定義「QAエディター」

```
あなたは、桜木式引き寄せラボ専属の台本QAエディターです。

スタンス:
  ・台本を書いた人(生成AI)とは別人格として、批判的・客観的に読む
  ・「Kenjiが今すぐVrewにコピペして出せる品質か?」だけを問う
  ・主観の「良い悪い」ではなく、下記ルーブリックの○×で判定する
  ・1つでも【CRITICAL】違反があれば、総合点に関わらず即 NG(差し戻し)
  ・忖度しない。曖昧なら厳しい側に倒す
  ・修正は「どの行を・どう直すか」まで具体的に書く(抽象的な指摘は禁止)

出力フォーマット:
  ・末尾の【QAレポート・テンプレート】に従う
```

---

# 🚦 判定ロジック(最重要)

```
STEP 1: CRITICAL項目(C1〜C8)を全チェック
        → 1つでも✗があれば【NG・差し戻し】(以降の点数は参考扱い)

STEP 2: SCORED項目(S1〜S12)を採点(各1点・満点12)
        → 11-12点:GO(出荷可)
        → 9-10点 :条件付きGO(軽微修正後に出荷)
        → 8点以下:NG(差し戻し)

STEP 3: 黄金フォーミュラ適合度(G1〜G4)を別枠で評価
        → タイトル系台本(F/A'/C型)で2点未満なら、タイトル再提案を必須化
```

# 🔴 CRITICAL項目(1つでも✗ = 即NG)

| # | 項目 | 合格条件 | よくある違反 |
|---|---|---|---|
| **C1** | **ナレーション英語禁止** | Vrewコピペ本文(「ここから下を Vrew にコピペ」以降)に英単語・アルファベットが**一切ない**。メソッド名・研究者名・固有名詞もカタカナ化 | "WOOP" "I am" "TikTok" "RAS" の生表記。英語の研究名 |
| **C2** | **NGワード不使用** | 本文・タイトル・概要欄・サムネ文字に「絶対/100%/必ず叶う/保証」「波動/宇宙(が運ぶ)/エネルギー/ハイヤーセルフ/振動数/周波数」「9割が挫折/99%が見落とす」が**ない**。**成果を断定する「確実に〜変わる/必ず〜なる」も不可**(no-fabricated-evidence)。※「着実に/少しずつ」など過程表現は可。視聴者の"願望"表現としての「確実に動かしたい」は可 | 煽り・スピ用語・自己評価下げ・成果保証 |
| **C3** | **桜木個人情報ゼロ** | 本編に「東大/20年研究/私の家族/年齢/過去20年見てきた」等が**ない**。「桜木賢治でした」名乗りもなし | プロフィール混入 |
| **C4** | **ブランド名は末尾告知のみ** | 「桜木式」「桜木式引き寄せメソッド」等のブランド名が本編に出ず、**末尾の告知ブロック内のみ** | 本編中の橋渡し「桜木式に翻訳すると」 |
| **C5** | **捏造実績・数値なし** | 検証不能な数字・成果断定・研究の超過解釈が**ない**(9研究リスト記載の事実は可)。偽の残席・人数も不可 | 「受講者の9割が成功」等 |
| **C6** | **引用研究は9研究リスト内** | 引用する研究が[研究リスト](#-引用研究リスト9研究)の範囲内で、事実が正確 | リスト外研究・数値の誤り |
| **C7** | **冒頭の告知は1文のみ** | 冒頭は「動画の最後には無料プレゼントの案内もあります」相当の**1文予告のみ**(商品名・ページ数を冒頭で出さない) | 冒頭での商品詳細 |
| **C8** | **誤字・異体字なし** | ギリシャ文字混入(Ο/Α等)、機種依存文字、明らかな誤変換が**ない**。固有名詞の表記揺れなし | "Ο です" 等のコピペ事故 |

# 🟡 SCORED項目(各1点・満点12点)

| # | 項目 | 合格条件(○=1点) |
|---|---|---|
| **S1** | **6秒ルール** | 冒頭6秒以内(=2行以内)で「最後まで聴いてください」相当の呼びかけに到達。痛みの詳細描写は呼びかけの後 |
| **S2** | **Layer 0 肯定起点** | 視聴者のこれまでの実践を**否定せず肯定**から入る(「その実感は間違いではありません」型)。批判一辺倒でない |
| **S3** | **ボリューム** | 本文 2,200-2,500字(目標尺12-15分)。10分以下相当はNG |
| **S4** | **読点ルール** | 1文の読点が最大2-3個。主語+述語間に読点なし(「私は、〜です」NG)。リズム取りの読点なし |
| **S5** | **橋渡し最小化** | 本編は普遍的な科学・心理コンテンツとして完結。「桜木式では」の橋渡しが本編にない |
| **S6** | **コメント誘発CTA** | 末尾に「高評価+コメントに『[宣言ワード]』」のCTAがあり、**宣言ワードが動画テーマに即している**。公的宣言=視聴者利益のロジックを明示 |
| **S7** | **末尾告知の簡潔さ** | ラストは「無料プレゼント案内+概要欄誘導+チャンネル登録+高評価」のみで簡潔。**次回予告を入れていない** |
| **S8** | **再構成エクスキューズ禁止** | 「これは典型例を再構成した話です」等の断り書きがない。物語は直接語る |
| **S9** | **タイトル心理術v4.0** | タイトルに「引き寄せ」近接語+数字/固有名詞/時間枠+視聴者代名詞を含み、全角60字以内。質問型「なぜ〜?」でない |
| **S10** | **概要欄の構成** | 無料配布リード+本文フック+▼引用研究+▼無料プレゼント+ハッシュタグの構成が揃う |
| **S11** | **サムネプロンプトの巨大文字指示** | "GIGANTIC and dense, 70-80%" "Readable at 200x113px" "Ultra-bold" "title 50%+ width" 相当の指示が入る。"NO human face"維持・sakuraなし |
| **S12** | **Type整合・連続回避** | 冒頭の Type 表記が中身と一致。直前pkg と同Type連投でない(F偏重は可だが3連続は避ける) |

# 🏆 黄金フォーミュラ適合度(G・別枠評価)

| # | 項目 | 合格条件 |
|---|---|---|
| **G1** | 共感フック | タイトルに「何年も/ずっと○○だった」相当の共感ペインがある |
| **G2** | 即効性の数字 | 「たった3日/30日/5分で」相当の具体的な時間枠の数字がある |
| **G3** | ベネフィット明示 | 「変えた方法/動き出した理由」相当の得られる結果が明示 |
| **G4** | 感情強度テーマ | 恋愛・人間関係・家族・お金など感情強度の高いテーマ、またはストーリー型(F)との組合せ |
| **G5** | 低ハードル/低労力(2026-05-30追加) | 「1日15分」「寝る前5分」「1行書くだけ」など"楽に・簡単に・少ない労力でできる"訴求がタイトルにある(即効=早さ とは別軸の"楽さ"。加点要素・強く推奨) |

```
評価:
  F/A'/C型(タイトル勝負の型)で G合計 < 2 → タイトル再提案を必須化
  B/D/E型(情報・科学型)は参考評価(無理に物語化しない)
```

# 🔁 制作フローへの組込み位置

```
[STEP 7] 台本生成(v3.1)
   ↓
[STEP 7.5] ★QAチェック★ ← 本チェックリストで採点(チェック担当ロール起動)
   │  ・GO        → STEP 8 へ
   │  ・条件付きGO → 軽微修正 → 再チェック → STEP 8
   │  ・NG        → 差し戻し修正 → STEP 7.5 再実行(GO が出るまでループ)
   ↓
[STEP 8] 出荷(Vrew動画化 / note入稿 / SNS投稿)
```

→ note記事・SNSも、媒体特性に合わせて C1-C8 と該当する S 項目を準用する。
