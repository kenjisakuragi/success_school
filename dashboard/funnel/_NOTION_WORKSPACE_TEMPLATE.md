```

│  📊 今週の主要KPI                          │

│  売上:¥XXX,XXX (前週比 +X%)             │
│  オプトイン:XX件                          │

│                                            │

│  □ リスクユーザー対応(0件)                │
│  □ Notion動画承認待ち(2件)                │

│                                            │

## Notion 設定

- **タイプ:** Page
- **ブロック:**
  - Embed: UTAGE ダッシュボードURL
  - Linked Database: 今日のタスク(他DBから抽出)
  - Embed: Make.com の数値レポートURL
- **更新:** Make.com Webhook 経由で自動更新

# 🎬 ② YouTube動画 台本DB

**役割:** AI(私)が事前生成した台本を、Kenji が承認→Vrew制作 する流れの管理

## DBプロパティ

| プロパティ名 | タイプ | 例 |
|---|---|---|
| タイトル | Title | 「中3まで落ちこぼれだった私が東大に合格した話」 |
| ステータス | Select | 下書き / レビュー待ち / 承認済 / 制作中 / 公開予約 / 公開済 / 修正依頼 |
| 公開予定日 | Date | 2026-06-05 7:00 |
| 動画長(分) | Number | 12 |
| ソース | Multi-select | VSL / 書籍ch1 / 書籍ch3 / 海外動向 / Q&A |
| ★★★マーク済台本 | Text(長文) | (全文) |
| 音声ファイル | URL | Google Drive リンク |
| サムネ案A | Files | (画像) |
| サムネ案B | Files | (画像) |
| サムネ案C | Files | (画像) |
| 採用サムネ | Select | A / B / C |
| タイトル候補 | Text | 3案を/区切り |
| 採用タイトル | Text | 確定タイトル |
| 概要欄 | Text(長文) | (テキスト) |
| タグ | Multi-select | 引き寄せ・マニフェスティング・etc |
| Kenjiレビュー | Checkbox | □ |
| 動画URL | URL | (公開後・YouTubeリンク) |
| 視聴回数(48h) | Number | (公開3日後・手動更新 or 自動) |
| CTR | Number | (公開3日後) |

## ビュー

### A. 「今週承認すべき動画」ビュー
- フィルター:ステータス=「レビュー待ち」+ 公開予定日が今週
- 並び順:公開予定日 昇順

### B. 「制作待ち」ビュー
- フィルター:ステータス=「承認済」or「制作中」

### C. 「公開済み一覧」ビュー(分析用)
- フィルター:ステータス=「公開済」
- カードビュー:サムネ表示

## 自動化

```
Make.com Webhook:
  ・私(AI)が毎週金曜夜に7-8本の新規レコードを自動作成
  ・ステータスは「レビュー待ち」で投入
  ・Kenjiが土曜午前に承認したら「承認済」に変更
  ・YouTube公開後、自動で「公開済」に
```

# 🐦 ③ X 投稿テーマDB

**役割:** 毎日朝8時の自動投稿のソース(完全自動 or 半自動運用)

## DBプロパティ

| プロパティ名 | タイプ | 例 |
|---|---|---|
| 投稿日 | Date | 2026-05-30 8:00 |
| 投稿内容(140字以内) | Text | (本文) |
| テーマカテゴリ | Select | 科学エビデンス / 桜木の物語 / メソッド解説 / 海外動向 / 書籍引用 / Manifest AI™ / 励まし |
| ステータス | Select | 自動生成済 / 承認待ち / 予約済 / 投稿済 / スキップ |
| Buffer投稿ID | Text | (Buffer連携時) |
| 反応数(48h後) | Number | いいね/RT合計 |
| インプレッション | Number | (X分析から) |
| Kenjiコメント | Text | (改善メモ) |

## ビュー

### A. 「今週の投稿予定」ビュー
- 7日分のカレンダー表示
- ステータスごとに色分け

### B. 「反応が高かった投稿」ビュー
- ソート:反応数 降順
- 月次傾向分析用

## 自動化

```
Make.com Scenario(毎週土曜午前9時):
  1. 私が翌週分7本の投稿を生成 → DBに自動追加
  2. ステータス「自動生成済」で投入
  3. ガードレールチェック(NGワード・桜木式準拠)
  4. 自動投稿可能なら「予約済」へ → Buffer連携
  5. ガードレール NGなら「承認待ち」→ Kenjiに通知
```

# 💡 Kenji の使い方(平日昼の30秒運用)

```

```
1. Notion アプリ起動

```

→ **1日合計5-10分で運営の中核タスクが完結**
