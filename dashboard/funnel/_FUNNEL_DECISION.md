# 🧭 確定動線(統合型)

```
YouTube概要欄(リンクは1本に集中・1行目)
   ↓ 無料プレゼントLP
LP → 申込フォーム(LINE主＋メール従の二重取得 / サンクコスト=情報入力)
   ↓ ★サンキューページで無料ウェビナーを"即視聴"(視聴期限つき)
🆓 無料ウェビナー動画(教育＋動機づけ＋ミニ体験1つ)
   ↓ 視聴完了で → コンテンツプレゼント(PDF/テンプレ)を解禁
   ↓ ウェビナー末で → バックエンド案内(期間限定オファー)
   ├─ (任意)少額 order bump ¥1,980〜(=購入者リスト化)
   ↓
📦 ¥98,000 本科(=ここで"体験"を解禁)
   ↓
🌹 ¥298,000 1on1 VIP

※未視聴者は LINE/メールで3回リドライブ(前日/当日/期限前)
```

**設計思想の核(分離型→統合型に変更した理由):**
- 工程間の脱落(LINE→別途セミナー登録→show)を消し、**感情が一番熱い"登録直後"に売る**。
- 無料プレゼント(特典)と無料セミナー(ウェビナー)を**1本に統合**。バンドルで登録率↑・リーク減・視聴を最大化。
- シミュレーション(LP流入10,000):統合型 ≈ 本科売上¥5.14M・リスト3,000 > 分離型 ¥4.41M・2,500。

# 🎯 視聴率を作る5つのギミック(統合型の生命線)

```
1. サンキューページで"今すぐ視聴"(登録の勢いのまま再生)
2. 視聴期限(例:48時間で見られなくなります=緊急性)
3. 特典は"視聴完了で解禁"(コンテンツプレゼントを動画の後ろに置き最後まで引っ張る)
4. 未視聴者を LINE/メールで3回リドライブ(前日/当日/期限前)
5. 申込フォーム(サンクコスト)は維持し質を担保
```

# 🎬 無料ウェビナー(フロントの中身)と「体験はバックエンドに」の線引き

| 段階 | 役割 | 出すもの / 取っておくもの |
|---|---|---|
| 無料ウェビナー(フロント) | "なぜ効くか"の腹落ち＋**ミニ体験1つ(味見)**＋特典(PDF/テンプレ) | 誘導ワーク・伴走・実践=**深い体験は出さない** |
| ¥98,000 本科 | **体験そのもの**(誘導ワーク・実践・伴走) | ここで初めて"やって変わる"を解禁 |

- 特典(コンテンツプレゼント)は**リードマグネット級のコンテンツ**であって"体験"ではない。
- PDFは**事前配布しない**(満足して動画を見ない恐れ)→ **視聴後の特典に回す**(視聴率を守る)。
