> **位置づけ:** 「信頼獲得 × 快楽提供 × バックエンドアップセル」を完全統合したセミナー設計
> **ターゲット:** 50-60代女性・引き寄せ層(主軸)

# 🎯 3大目的の同時達成スコア設計

```
A: 信頼獲得(セミナー全体で形成)
　→ 学長と「引き寄せ博士」ブランドへの信頼

B: 快楽提供(セミナー中に体験)
　→ 「学べた」「変わる予感」「心が動いた」体験
　→ ¥1,000以上の価値超過を、参加者が実感

C: バックエンドアップセル(「もっと」を生む)
　→ 「今日だけでもこれだけ変わるなら、本科3ヶ月はどうなる?」
　　　スクスレート迫り上げ
```

**重要原則:** この3つは順番ではなく、同時進行。信頼獲得しながら快楽を提供し、快楽提供しながらアップセルへの誘いを埋め込む。

# 🌸 フェーズ1詳細(信頼構築)

## B1: オープニング・共感提起(10分)

### 設計意図
- **「この人は私のことをわかっている」**と思わせる
- 参加者の心を「聴く体勢」にする

### スクリプト指針
- 静かに、やさしく始める
- 5つの「あるある」を提示:
  - 「本を何冊も読んだのに」
  - 「毎朝アファメーションしているのに」
  - 「『願えば叶う』と聞くたびに焦る」
  - 「50代になり『もう遅い』と感じる」
  - 「ずっと家族のために生きてきた」
- 参加者のうなずきを促す

### CTAをここに初提示(ソフト)
- 「今夜、もし聴いて『もう一つ深く学びたい』と感じられたら、最後に、本格的な次のステップもご紹介します」
- **アップセルを「隔てる」と逆効果。最初から「ある」と伝えることで警戒心が解ける**

## B2: 学長ストーリー(15分)

### 設計意図
- **「この人は本当にメソッドを実証している」**と思わせる
- ストーリーで心を動かす

### スクリプト骨子
```
1991年、わたしは11歳でした。
  ↓
テレビで橋本聖子選手のイメージトレーニングの話を見た
  ↓
マーフィー博士の本を読んだ(体験の原点)
  ↓
聖光学院で中3まで「下から数えた方が早い」成績
  ↓
高1で「思い出した」→ 東大現役合格
  ↓
30年で、妻・娘・住まい・体験、すべてを同じ仕組みで叶えた
  ↓
そして今、会社員と並走しながら、これをあなたに伝えている
```

### 信頼構築のポイント
- **譸らない**: 思い出し、という表現で「何も特別じゃない」と伝える
- **反証不可能な事実**: 東大現役、妻、娘、会社員、すべて検証可
- **「あなたと同じ」感**: 「会社員と並走しながら」を強調

## B3: パラダイムシフト(5分)

### 設計意図
- **「この人は本物を知っている」**と確信させる
- 「願えば叶うはウソ」の重要メッセージ

### 伝えること
- 9割の人の願いが叶わない理由
- 顕在意識と10%、潜在意識と90%の話
- 「あなたは全力の10%しか使っていなかった」と心の銅を陸抱く

# 🌺 フェーズ2詳細(快楽提供)

## B4: メソッド完全解説(20分)

### 設計意図
- **「学ぶ」快楽**を体験させる
- 「ああ、だから叶わなかったのか」という「キャッチ」体験

### 伝える内容
1. マーフィー博士の3ルール・肯定形
2. クーエ博士の3ルール・現在形
3. ネヴィル・ゴダードの3ルール・五感
4. 現代脳科学のRAS(網様体賦活系)
5. 「もう叶った状態」をイメージすることの重要性

### 採り入れる「快楽設計」
- 5分ごとに「やさしい闓」を作る
- 3つの「推聖」ルールはスライドで1枚ずつに表示
- 参加者に「メモしたい」と思わせる(能動参加)

## B5: ライブワーク①(20分)

### 設計意図
- **「今体験した」快楽**
- 「今、心が動いた」という生体験
- これがアップセルの最大トリガー

### ワーク内容: 「もう叶っている私」イメージング

```
Step 1 (5分):
  参加者に「今一番叶えたいこと」を1つ選んでもらう
  紙に書いてもらう

Step 2 (10分):
  目を閉じて、学長の誘導で「実際に叶ったとき」のシーンをイメージ
  六感(視覚・聴覚・嗅覚・味覚・触覚・感情)をひとつずつて丁寧に誘導

Step 3 (5分):
  快楽と安心を胸に感じたまま、メモを取る
  「どう感じたか」を3つ書く
```

### 効果
- **参加者は心の中で「叶っている体験」をもう一度している**
- これが「もう一度体験したい」という思いを生む
- アップセルの台地

## B6: ライブワーク②(20分)

### 設計意図
- **「私にもできそう」快楽**
- 長期実践の「イメージ」を体験
- 30日後の自分を想像させる

### ワーク内容: 「30日間の計画シート」記入

```
Step 1 (5分):
  学長が、「30日間、毎朝朝6寝る前6唱える」ルーチンを説明

Step 2 (10分):
  参加者の言葉を肯定形・現在形で言語化するワーク
  学長が個別に1-2人サンプルとしてチェック

Step 3 (5分):
  参加者同士で「これを毎日唯えたら」という代本やり
  同期感を作る(人と人のつながり体験)
```

### ポイント
- **「30日だけでもこんなに変わる」と体感させる**
- 「もし、3ヶ月伴走してもらえたらどうなる?」と自然に思わせる
- **これがアップセルへの橋渡し**
