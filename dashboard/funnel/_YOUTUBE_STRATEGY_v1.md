# 🎯 戦略の3層構造

## 層1:検索SEO流入(長期・複利型)

「引き寄せ」「マニフェスティング」「スクリプティング」「未来からの手紙」「願いを叶える」「自己効力感」「WOOP法」等の**Google/YouTube検索**で上位表示を狙う。

→ Month 6以降、検索からの自然流入で**月5,000-20,000視聴**を見込む。

## 層2:VSL/書籍へのファネル誘導(中期収益)

各動画の概要欄・カード・終了画面に、無料スターターキット(VSL末尾オプトイン)へのリンクを設置。

→ 月20-50名がVSL経由でファネル流入。月¥100-300Kの売上貢献。

## 層3:AdSense収益化(長期収益)

登録者1,000名 + 総再生時間4,000時間を達成後、AdSenseが稼働。

→ Month 6-12で月¥50-500Kの広告収益。

# 🎨 動画制作の標準フォーマット

## 共通スタイル(VSLと同じ)

| 要素 | 仕様 |
|---|---|
| **背景** | VREWの中小パーティクル(夜空・桜の花びら系) |
| **音声** | Algieba 0.88 / Google Chirp3-HD / WAV |
| **テロップ** | Yu Gothic Bold・白色基調・キーフレーズは金色(#ffc857) |
| **長さ** | 10-30分(SEO的に最適) |
| **オープニング** | 10秒(チャンネル名 + 動画タイトル) |
| **アウトロ** | 30秒(無料スターターキットへの誘導 + チャンネル登録) |
| **BGM** | なし(声に集中) |

| 要素 | 仕様 |
|---|---|

# ⚠️ YouTube運営の注意点

| 項目 | 注意 |
|---|---|
| **匿名化ポリシー** | 実在著名人の固有名(現存)は使わない([book-anonymity-policy](memory:book-anonymity-policy)) |
| **捏造禁止** | 受講生の声・数字は実態のあるもののみ([no-fabricated-evidence](memory:no-fabricated-evidence)) |
| **著作権** | ループ映像はVREW/Pexelsの著作権フリーのみ使用 |
| **YouTubeポリシー** | スピリチュアル系コンテンツは規制注意・科学エビデンスベースで安全 |
| **コメント対応** | 月1回30分のまとめ対応で十分(炎上時は別) |
| **ライブ配信** | 当面なし(顔出しなし運用との相性悪)・Month 6以降検討 |
