```

```
1. youtube.com にログイン → 右上アバター → 「チャンネルを作成」
2. ブランドチャンネルを選択
3. 名前を「引き寄せラボ」に設定

## STEP 3:基本情報の入力

```
1. チャンネル設定 → 概要 → 説明文を上記コピペ
2. リンク追加:LP・X・note
3. 連絡先メールを設定
4. キーワード(タグ)を入力
```

## STEP 4:ビジュアル設定

```
1. チャンネルアイコン:800×800px の月+金線ロゴを設定
2. バナー:2048×1152px のデザインを設定
3. 透かし(ブランドの透かし):アイコンの小サイズ版
```

## STEP 5:動画アップロード(最初の3本)

```
1. チャンネル予告動画(60秒)を最初にアップ
2. pkg_07(マーフィー)
3. pkg_08(ペネベイカー)
4. それぞれ概要欄・タグ・終了画面を設定
```

## STEP 6:プレイリスト作成

```
1. 5つのプレイリストを上記名前で作成
2. 各動画をプレイリストに追加
3. チャンネルホームに「セクション」として表示

## STEP 7:検証・公開

```
1. 全設定をプレビューで確認
2. 通知ベル設定
3. 公開・初投稿
4. SNS(X・公式LINE)で告知
