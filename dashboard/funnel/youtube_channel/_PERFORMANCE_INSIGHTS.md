## サムネ勝ち筋仮説(検証用)

```
❶ 文字占有率70%以上(イラストは小さく添える程度)
   → イラストを大きくすると文字が負ける(07/08/09が中位に沈んだ要因の可能性)
❷ 上下2段の色コントラスト(白→金)で視線誘導
❸ ビフォー(問題)→アフター(解決)の対比構造
❹ 数字をアイコンで視覚補強(例:3 Days)
❺ ネガ→ポジの転換を見せる(否定語で止めない)
```

## 🔬 第3回の核心インサイト

### ① pkg_11の独走は本物(383→932)・受け皿なしで漏れている【最重要】
```
932再生が流入しているのに、登録15・LP未公開=受け皿ゼロ。
→ 今まさに最大の機会損失。LP公開＋pkg_11概要欄リンクが最優先(漏れ止め)。
```

### ② 黄金フォーミュラの「再現テスト」は現状ブレイク再現せず
```
pkg_11は18時間で94回 → 1日383。
一方:
  pkg_13(夫婦)20時間で12回  ← pkg_11の同時間帯を大きく下回る
  pkg_14(お金) 8時間で15回   ← まだ若いが突出の兆候なし
→ 黄金フォーミュラは"必要条件"だが"十分条件"ではない。
```

### ③ pkg_11の「追加の勝因」仮説 = 汎用ペイン
```
pkg_11「何年も変わらなかった"現実"」= 誰にでも当てはまる汎用ペイン(最大リーチ)
pkg_13「夫婦」/ pkg_14「お金」= ニッチペイン(リーチが絞られる)
→ YouTubeのbrowse/suggestedは"広いペイン"ほど配信が伸びる仮説。
→ ニッチは検索/教育向き、汎用は新規リーチ向き、と使い分け。
```

### ④ pkg_05(科学的・長い説明タイトル)依然最下位=「科学をタイトルに乗せない」を再裏付け
