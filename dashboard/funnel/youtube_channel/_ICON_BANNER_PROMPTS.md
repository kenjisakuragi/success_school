# 🔧 制作手順(Kenji作業)

## ルートA:DALL-E 3 で直接生成

```
1. ChatGPT Plus にログイン
2. 上記プロンプトをそのままコピペ
3. 生成された画像を Canva で文字部分を上書き(日本語フォント差し替え)
4. 800x800 / 2048x1152 にエクスポート
```

## ルートB:Midjourney で生成

```
1. プロンプト末尾に " --ar 1:1 --v 6.0 --style raw" 追加(アイコン)
   " --ar 16:9 --v 6.0 --style raw" 追加(バナー)
2. 4枚の候補から選んでアップスケール
3. 日本語文字は Canva で別途追加
```

## ルートC:Canva のみ(プロンプト不要)

```
Canva検索キーワード:
  「YouTube アイコン エレガント」
  「YouTube バナー 月 夜空」
  「ボタニカル ロゴ 上品」
  「明朝 シンプル ロゴ」

→ 既存テンプレを「引き寄せラボ」「桜木賢治」に差し替え
→ 配色を #2B3A50 / #C9A961 / #FAF7F2 に統一
```
