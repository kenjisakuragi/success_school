# 👥 UX体験設計書 ― ユーザー目線のファネル体験

**作成日:** 2026-05-23
**位置づけ:** ファネルが「ユーザーにとってどんな体験になるか」を物語形式で記述する設計書
**読み方:** 開発・コンテンツ制作・LP/メール執筆時に、ここで定義した「ユーザー感情」と「期待値」を照らし合わせる

# 🎭 メインペルソナ ― 「Aさん」(45歳・営業職・既婚・子1人)

## プロフィール

- **性別/年齢:** 女性・45歳(±10歳)
- **職業:** 営業職(中規模企業)・年収550万円
- **家族:** 夫(会社員)・小学生の娘1人
- **居住:** 都市部マンション
- **生活ステージ:** 仕事と家庭が落ち着き、自分の人生を見直したい時期
- **デジタル習熟度:** スマホは普通に使う・LINEはヘビーユーザー・ChatGPTはたまに触る程度
- **過去の引き寄せ経験:** 引き寄せ系の本を5〜10冊読んだ経験あり・一時的にアファメーションをやってみたが続かなかった

## 内的状態(ファネル開始時)

- 「このまま定年まで同じ会社で終わるのか」という漠然とした不安
- 副業や転職を考えたが踏み出せない
- 子育てが落ち着いてきて、自分の時間が増えた
- 「もう一度、自分の人生を生きたい」という気持ち
- ただし、過去の自己啓発挫折経験から「また失敗するのでは」という警戒心

## ニーズ・課題

- **顕在ニーズ:** 「自分らしい人生を取り戻したい」
- **潜在ニーズ:** 「続けられる仕組みが欲しい」「自分を変える方法を、具体的に教えてほしい」
- **障害:** 時間不足・自信不足・過去のメソッド挫折経験

# 🌅 体験ストーリー(時系列)

## Day -1(広告との出会い)

### 21:30 - スマホでInstagramをスクロール中

Aさんは仕事から帰り、夕食と娘の宿題を見終え、ベッドで横になっている。スマホをだらだら触っている時間。

**心の声:**

無視できず、広告をタップ。

### 期待値(この段階)

- なんとなく面白そう・けど、また自己啓発の売り込みかもしれない
- 「すぐ閉じてもいい」というハードルの低い状態

### この段階での設計者の責任

- 広告の「痛みの掘り起こし」が**正直で・上から目線でない**こと
- クリックした人を裏切らない VSL を準備すること

```
感情の高さ
    │
    │                                                  ★ Day 90 卒業
    │                                    ★ Day 60 変化実感
    │                          ★ Day 30 桜木の個別添削
    │                     ★ Day 14 Q&Aで仲間に出会う

    │          ★ Day 0 Upsell決断(本気のコミット)
    │        ★ 決済時の高揚(マスター講座)

    │     ★ デモで欲望
    │   ★ 物語で涙
    │ ★ Hookで共感

    └─────────────────────────────────────────────→ 時間
       Day -1   Day 0(同日内3回ピーク)   Day 14    Day 30    Day 90
```

**設計の核心:** Day 0だけで**3回のピーク**(OTO決済→Upsell決断→LINE音声受信)を作る即時上昇曲線。その後3ヶ月にわたって追加のピークを5〜6回作る。「これを買ってよかった」を**累計10回以上感じる**設計。

# 🚧 想定される疑問・抵抗とその解消方法(全段階共通)

## 段階別の疑問・抵抗マップ

| 段階 | ユーザーの心の声 | 解消方法 |
|---|---|---|
| 広告 → VSL | 「また怪しい引き寄せ売り込み?」 | Hookで「あなたのせいではない」と即座に共感 |
| VSL Hook | 「30分は長いな」 | 最初3分で痛みと希望を提示し、続きを聴かせる |
| VSL ストーリー | 「桜木の自慢話?」 | 中3まで落ちこぼれだった話で対等性を作る |
| VSL 解決策 | 「結局商品売り込み?」 | 解決策を惜しみなく開示・知識として持ち帰れる |
| VSL CTA | 「メアド登録は面倒・怖い」 | 名前+メアドだけ・即時PDF配信・無料を強調 |
| OTO初見 | 「えっ、いきなり売り込み?」 | ブリッジで「ひとつだけ」と限定提示・無料テンプレは既に届いてると明示 |
| OTO検討 | 「¥19,800は高い?」 | 価値スタック¥74,400相当・30日返金保証・分割不可だが少額 |
| OTO検討 | 「タイマー本当?」 | 30分後に本当に閉じる(UTAGE機能)・誠実 |
| OTO決済 | 「カード情報入れて大丈夫?」 | Stripe決済の安全性表示・SSL強調 |
| 購入直後 | 「ちゃんと届くかな?」 | 3分以内に全コンテンツのメール到着・自動DLリンク |
| Day 1-3 | 「コンテンツ多すぎ、どこから?」 | メールで「まず Track 1 を」と道案内 |
| OTO決済直後 Upsellページ | 「えっ、まだ売り込み?」 | 「もう一段、深く伴走させてください」と丁寧に切り出す・スキップ可能 |
| Upsell検討 | 「¥98,000は高い」 | 割引適用で¥88,000・分割¥2,933/月・1日¥98 |
| Upsell検討 | 「3ヶ月で本当に変わる?」 | 30日返金保証で実質ノーリスク |
| Upsell検討 | 「決済直後にUpsellは押し売り?」 | スキップしても割引券失効するだけ・Day 7メールで再オファー機会あり |
| Upsell検討 | 「夫に相談したい」 | 30分タイマー切れ後はメールで再案内・無理強いしない設計 |
| Day 5(マスター講座のみの場合) | 「やっぱりAI伴走も気になる」 | Day 7再オファーで通常価格¥98,000で再提示 |
| Day 8(本科開始後) | 「ちゃんと続けられるか不安」 | 毎朝7時の声プッシュ+月1Q&A+カサネル原則 |
| Day 30+ | 「合わなかった、返金したい」 | 30日返金保証・無条件・メール1通で対応 |

# 🎬 設計の心臓部 ― 「桜木が一人ひとりに語りかけている」感

このファネル全体の核心は、**自動化されていながらも、ユーザーには「桜木さんが私のために語っている」と感じさせる**ことです。

そのために以下を徹底:

1. **VSL** ― 桜木の声で、視聴者の名前は呼ばないが、痛みは「あなた」と二人称で
2. **OTO** ― 桜木の追伸が手紙のような文体
3. **メールシーケンス** ― 桜木の一人称・「私が見てきた感覚として」と個人観察を共有
4. **バックエンド** ― 毎朝7時の音声プッシュで名前を呼ぶ(`{name}さん、おはようございます`)
5. **個別添削** ― 計4回、桜木が音声で個別フィードバック

**自動化と人格性の両立 ― これが、桜木式 AIマニフェスティング® の最大の差別化要因です。**
