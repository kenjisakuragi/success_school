# 🧭 シリーズ構造(発想D:ハイブリッド採用)

検討した4発想:
- A ペイン別(横展開) … 各巻=1ペイン。広告・検索に最強
- B 入門→深掘り(縦展開) … 各柱を深掘り。リピート向きだが広告ターゲット弱い
- C 型別(メソッド/偉人/物語) … ブランドに弱い
- **D ハイブリッド(採用)** … 「総論1冊(母艦)」＋「ペイン別シリーズ」。ブランドと広告ターゲットの両取り

```
【母艦】総論:メソッド全体像(汎用ペイン=「現実が変わらない」)
   └ ブランドの旗艦。3本柱を体系的に。
【シリーズ】ペイン別(広告で回す主力)
   ├ Vol.1 お金
   ├ Vol.2 人間関係
   ├ Vol.3 自己肯定(どうせ私なんて)
   ├ Vol.4 不安・将来
   └ Vol.5 夫婦・パートナー
全巻 → 巻末で無料ウェビナー＆他巻を相互送客
```

# 🧩 共通テンプレート構成(=量産の鍵・約65%を翻訳で使い回す)

各ペイン巻は、この型で書く。**共通コア(序章＋3本柱の基礎)は母艦から翻訳流用**、テーマ固有部分だけ書き下ろす。

```
はじめに   … そのペイン特有の共感(お金なら通帳/人間関係なら職場・夫)
序 章      … なぜ叶わなかったか(脳の使い方=ラス/言葉だけは崩れる)※テーマに翻訳
第1章 理想設計 … そのテーマの理想を3つ(お金:月◯円/人間関係:こう在りたい)
第2章 感情筆記 … そのテーマの感情を書き出す
第3章 自律訓練法 … そのテーマの理想を体に落とす
第4章 テーマ固有の応用 … お金=巡りに気づく/人間関係=境界と期待/自己肯定=できたこと筆記
終 章＋おわりに … 無料ウェビナー＆他巻へ誘導
著者プロフィール(学習歴・安全表記)
```
- 共通:序章の脳の仕組み・3本柱の原理・研究引用(ペネベイカー/バンデューラ/ゴルウィッツァー/RAS/シュワルツ等)
- 固有:はじめにの共感事例・各章のテーマ適用例・第4章の応用・物語

# 🎯 Kindle×広告 運用方針

- **1テーマ集中・短め(2〜3万字)** … Kindle広告/KU(ページ読了)と相性◎。厚い1冊より回しやすい
- **シリーズ統一デザイン** … 薄ピンク×オーラの表紙テンプレ＋ナンバリングで認知。背表紙も統一
- **クロスプロモ** … 各巻末で「他のお悩みの方へ→他巻」＋「無料ウェビナー」。1人が複数巻を回遊
- **広告ターゲット** … お金広告→Vol.1、人間関係広告→Vol.2…とペイン一致で配信効率UP
- **全巻同一導線** … どの巻からでも 無料ウェビナー → ¥98,000本科。母艦は本科への信頼補強
- 法務:効果無断定・偽実績/偽レビューなし・非臨床語(不安/うつは「軽くなる/整う」)
