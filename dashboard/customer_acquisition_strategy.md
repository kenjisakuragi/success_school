## 0. 「勝手に集客」の本質

**「勝手に集客」= 以下4つの装置が連市して動く状態:**

```
【装置1】永続資産(書籍・動画・記事)
              ↓ 検索・推奨・口コミで自動流入
【装置2】集約点(LINE公式)
              ↓ リスト化(「見込み客の行列」=鉄則⑦)
【装置3】自動育成(ステップ配信・コンテンツ)
              ↓ 信頼形成
【装置4】出口商品(4ブランド)
```

**一番重要なのは装置1の「永続資産」** 。広告は「付けた間だけ集客できる」ぜいぜいストック不可　2ヶ月出した動画・記事・書籍が、あなたが寝ている間も見込み客を連れてくる状態を作る。

## 3. JV戦略 — 「頭を下げられて提携される」状態へ

### Phase 1(今〜5/21 JV-MTG): 自ら動く

### Phase 2(2026/06-09): 取り込みひたすら

狙うべきJV先カテゴリ:

| ターゲット | 事業 | 具体例(推定) | アプローチ方法 |
|---|---|---|---|
| 50-70代スピ女性 | 夢実現大学 | スピリチュアルサロン主嬰 / 中高年向けコーチングスクール | 見込んで寄与オファー(無料講義提供) |

| 40代受験親 | 中学受験 | 有名勉強やり系インフルエンサー / 中学受験会社規模外 | 「親講座」名目でゲストコラボ |
| 30代夫婦 | 姊活 | 不妊オンラインサロン / 出產補助NPO | 妻とともにストーリー提供 |

### Phase 3(2026/12-2027/06): 向こうから来る

- 書籍出版 → 帯推薦依頼が来る
- YouTube登録者数万人超 → コラボ依頼が来る
- メディア取材 → 他著者から推薦コメント依頼
- **「頭を下げられて売る」(鉄則⑯)を集客にも適用**

### JV関係性のデザイン(鉄則をもとに)

- **受講者データは必ず共同保有**(集客資産を守る)
- 分配は集客貢献に比例(JV先リスト依存なら多めに)
- 独占契約は原則結ばない(鉄則⑮「低い撤退障壁」)
- コンテンツ著作権は学長保有(メソッドIPは譲らない)

## 5. 「コンテンツ量量産」オペレーション

学長の時間を創造だけに集中させ、複製・転用をAIがやる仕組み:

```
[元コンテンツ] 学長が30分話す(録画・録音)
        ↓
[変換1] AIが YouTube 動画に編集(字幕・BGM付き)
[変換2] AIが Voicy サイズにトリミング
[変換3] AIが note 記事に文章化
[変換4] AIが X ポスト5本に要約
[変換5] AIが LINE ステップ配信原稿化
[変換6] AIが 書籍原稿の一部に単位化
```

**学長の1週間:**
- 録画・録音 × 2回(各2時間)
- AI生成後のチェック×販促 × 3時間
- = 合計週**7時間**で全チャネルを回せる

これが **「鉄則⑰ボトルネック不発生」を集客でも実現** する鍵。

## 6. 「勝手に集客」を加速する3つの上級テクニック

### テクニック1: 「口コミ装置」を長期啇めう

受講者が「人に話したくなる体験」を必ず設計に入れる:

- 卒業式(写真・動画でSNS拡散)
- 達成宣言(同期の前で公言 → 友人にも語りたくなる)
- AI生成記念ナラティブ(SNSシェアしたくなるコンテンツ)
- コミュニティ名名陰制度(受講者同士の接点增加)

→ 受講者が **歩く広告** になる

### テクニック2: 「記念日装置」に乗る

- 年鄑1回 「学長の生日フェス」(学長の人生を振り返るオンラインフェス)
- システムとしてSNS拡散仕掛けを仕込む

### テクニック3: 「ストーリーオブストーリー」を使う

受講者のストーリーをシステム的に収集・公開:
- 入学時の動画インタビュー(不協和スタート点)
- 卒業時のインタビュー(達成点)
- 1年後のインタビュー(維持点)

→ **「受講生のストーリー」がコンテンツになり、それが新規受講生を集める**という自動サイクル
