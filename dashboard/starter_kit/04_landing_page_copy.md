# 📋 STUDIO実装手順

## Step 1: 新規プロジェクト作成
```
STUDIO → 新規 → "Blank" → プロジェクト名「sakuragi-lp」
```

## Step 2: テンプレ流用(任意・時短)
```
STUDIO テンプレート > "Landing Page" カテゴリから
ピンク系の上品なテンプレを選択
```

## Step 3: セクションごとに上記コピーをペースト

各セクションは独立した「セクションブロック」として配置。
レスポンシブ(スマホ対応)を必ず確認。

## Step 4: ボタンリンクを設定

CTAボタン全てに、**LINE登録URL**を設定:
```
https://lin.ee/[LINE公式アカウントID]
```

## Step 5: SEO設定

タイトル:
```
科学的引き寄せ10の方法|無料PDF|桜木賢治
```

説明:
```
東大卒・引き寄せ研究家の桜木賢治が、ハーバード・スタンフォード等の
科学的根拠に基づく「願いを叶える10の方法」を無料配布。
LINE登録だけで即受け取れます。
```

## Step 6: 公開

無料プランの場合、ドメイン: `sakuragi-lp.studio.site`(仮)
カスタムドメイン契約後: `sakuragi-pdf.com` 等(M2以降)
