# 🎨 リッチメニュー設計

## メニュー全体像(下部に常時表示)

```
┌────────┬────────┬────────┐
│ 🎁     │ 🎤     │ 📕     │
│ 無料PDF │ セミナー│ 本科   │
├────────┼────────┼────────┤
│ ❓     │ 📱     │ ✉️     │
│ 質問   │ SNS    │ 配信   │
│ する   │ フォロー│ 解除   │
└────────┴────────┴────────┘
```

## Canvaでリッチメニュー画像を作成

`リッチメニュー → 新規作成`

- サイズ: 大(2500×1686px)
- テンプレ: Canva「LINE Rich Menu」検索
- 配色: 桜木ピンク基調

### ボタン6つのアクション設定

**ボタン1: 🎁 無料PDF**
- アクション: テキスト送信
- ユーザーがタップすると「PDFをもう一度欲しい」と送信される
- → Botが自動でPDFリンクを返す

**ボタン2: 🎤 セミナー**
- アクション: URLリンク
- リンク先: STUDIOで作るセミナー申込LP
- ボタン文言: 「次回セミナーを見る」

**ボタン3: 📕 本科プログラム**
- アクション: テキスト送信「本科について教えて」
- → Botが本科の詳細を返す + 個別相談予約リンク

**ボタン4: ❓ 質問する**
- アクション: テキスト送信「質問があります」
- → Botが「ご質問内容をお送りください」と促す

**ボタン5: 📱 SNSフォロー**
- アクション: URLリンク
- リンク先: X / YouTube / note のまとめページ(Linktree等)

**ボタン6: ✉️ 配信解除**
- アクション: テキスト送信「配信解除」
- → Botが解除手順を返す(ブロック方法案内)

# 🔗 BrevoとLINEの連携(M1 W3で実装)

## 目的
LINE登録時に、メアドも取得 → Brevoのステップメール(05_step_email_7days.md)を起動

## 方法A: LINE標準フォーム機能(無料)

`設定 → メッセージ機能 → リッチメッセージ → カードタイプメッセージ`

1. 友達追加直後に、入力フォームを表示
2. 「無料PDFを受け取るために、メアドをお教えください」
3. 取得したメアドをBrevoの「LINE登録者」リストに自動追加

## 方法B: Manychat連携(¥2,000/月)

Manychatを使えば、より柔軟な自動応答+Brevo連携可能。
M2以降に検討。

# 🚨 注意事項

## 配信制限

LINE公式の無料プランは月1,000通制限。
登録者数が増えたら、Light(月15,000通)プランへ。

| 登録者数 | 推奨プラン |
|---|---|
| 〜100名 | 無料 |
| 100-500名 | Light ¥5,000/月 |
| 500-3,000名 | Standard ¥15,000/月 |
| 3,000名以上 | カスタム |

## 配信タイミング

- 一斉配信は **週1回まで**(火曜 or 金曜の19時推奨)
- 個別自動応答は無制限OK
- 連投NG(ブロック率激増)

## やってはいけないこと

❌ 友達追加直後に売り込み
❌ 1日複数回の一斉配信
❌ 過度な絵文字・派手な装飾
❌ 個人情報の不適切な収集
