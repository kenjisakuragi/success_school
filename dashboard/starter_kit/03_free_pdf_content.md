# 📘 P.4-5 方法 1. 「願う」前に、「書き出す」

## 左ページ(P.4・解説)

```
【方法 1】
「願う」前に、「書き出す」

― ペンシルバニア大学が証明した、最強の準備運動 ―

世の中の引き寄せ本は、「願え」と言います。
ですが、それでは9割の人が失敗します。

なぜか。
脳の中には、「願い」と同居している「過去のできなかった記憶」があるからです。

潜在意識の90%は、これまでに刻まれた「ない」の記憶。
そこに「ある」を上書きしようとしても、
「いやいや、無理でしょ」と内側から打ち消される。

だから、先に必要なのは、「書き出す」ことです。

ペンシルバニア大学のペネベイカー博士は、
45年かけてこれを研究しました。

  ・1日15分、4日間、不安を書き出すだけで
  ・不安が40-60%減少
  ・免疫力が向上
  ・問題解決能力が改善

頭の中に置いておくと「ぐるぐる」する不安は、
紙の上に出した瞬間に、力を失います。

書き出したものは、あなたの中から、消えるのです。
```

## 右ページ(P.5・ワーク)

```
【今すぐできるワーク】

紙とペンを、お手元にご用意ください。
タイマーを15分にセット。

書くお題は、たった1つ:

「お金 / 人間関係 / 健康 / 夢で、
 叶わない・できない、と感じていること、すべて」

【ルール】
🌸 文章にしなくていい(箇条書きOK)
🌸 「ひどいこと」を書いても大丈夫
🌸 後で見直さなくていい(終わったら破ってOK)
🌸 15分間、ペンを止めない

書き終わった後、
あなたの中の「ぐるぐる」が、軽くなっているはずです。

これが、「願う」の前にやるべき準備運動です。
ここから、「ある」が、入る場所ができます。
```
