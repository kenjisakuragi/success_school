# 📊 サブスク KPI・ダッシュボード設計

> **位置づけ:** サブスク「叶える私」研究科の経営判断を、感覚ではなく数字で行うための監視体制
> **対応する仕組み化項目:** 1億円仕組み化15項目の **#11「顧客満足度をスコア化し解約リスクを検知する」** そのもの
> **作成日:** 2026-05-16

---

# 🎯 監視すべきKPI 10指標

## A. 売上・成長指標(月次)

### 1. MRR(月次経常収益)
- **定義:** 月額会員数 × 単価
- **目標推移:** 100名(¥500K) → 300名(¥1.5M) → 500名(¥2.5M)
- **チェック頻度:** 月次
- **アラート:** 前月比 -5%以下

### 2. ネット会員数増減
- **定義:** 当月新規入会 - 当月解約
- **目標:** 毎月+10名以上
- **チェック頻度:** 週次
- **アラート:** 2週連続マイナス

### 3. LTV(顧客生涯価値)
- **定義:** 平均継続月数 × 月額単価
- **目標:** 18ヶ月以上(¥90,000以上/人)
- **チェック頻度:** 四半期
- **アラート:** LTV 12ヶ月割れ

## B. エンゲージメント指標(週次)

### 4. AI音声配信 開封率
- **定義:** LINE音声配信のタップ率
- **目標:** 70%以上
- **チェック頻度:** 週次
- **アラート:** 60%割れ

### 5. AI音声 再生完了率
- **定義:** 音声を最後まで聞いた率(LINE分析)
- **目標:** 80%以上(平均)
- **チェック頻度:** 月次
- **アラート:** 70%割れ

### 6. LIVE参加率
- **定義:** 月2回LIVE(新月/満月)の出席率
- **目標:** 40%以上(録画視聴含めれば70%以上)
- **チェック頻度:** 月次
- **アラート:** 30%割れ

### 7. コミュニティ発言数
- **定義:** LINE/Discordでの会員発言数(月間)
- **目標:** 平均1人あたり月3回以上
- **チェック頻度:** 月次
- **アラート:** 月1回未満が30%超

## C. 満足度・解約予兆指標(リアルタイム)

### ★8. NPS(Net Promoter Score)
- **定義:** 「友人に勧めたいか?」0-10点評価
- **質問頻度:** 月1回・1問だけアンケート
- **目標:** NPS +40以上(高評価ゾーン)
- **計算:** (推奨者9-10点%) - (批判者0-6点%)
- **アラート:** NPS +20割れ

### ★9. 解約予兆スコア(AI自動計算)
- **入力データ:**
  - 直近30日のLIVE欠席回数
  - 直近30日のコミュニティ発言ゼロ
  - 直近30日のAI音声未開封率
  - 直近のNPS低下
- **AI判定:** Claude/ChatGPT APIで自動スコアリング(0-100)
- **アラート:** 70点以上で「離脱リスク高」フラグ
- **対応:** 卒業生メンターから個別お声がけ

### 10. 実際の解約率(月次)
- **定義:** 当月解約者数 / 前月末会員数
- **目標:** 月3%以下(年36%以下)
- **チェック頻度:** 月次
- **アラート:** 5%超え

# 🚨 解約予兆シグナル詳細

## レベル1:黄信号(自動対応)

| シグナル | 検知 | 自動アクション |
|---|---|---|
| LIVE 2回連続欠席 | システム | LINE個別メッセージ「お元気ですか」 |
| AI音声 7日連続未開封 | システム | LINEで「ご無沙汰しています」音声配信 |
| ワーク未提出 2ヶ月 | システム | 学長声AIでやさしい声かけ |
| LINE発言ゼロ 30日 | システム | メンターへ「巡回お願い」通知 |

## レベル2:橙信号(メンター対応)

| シグナル | アクション |
|---|---|
| 解約予兆スコア 70点超え | 卒業生メンターが個別LINE 5分 |
| NPS 6点以下回答 | メンターから「お話聞かせて」相談DM |
| ログイン60日なし | メンター電話(本人希望者のみ) |

## レベル3:赤信号(学長対応)

| シグナル | アクション |
|---|---|
| 2年以上の継続会員からNPS批判 | **学長から直接メッセージ動画**(年数回のみ・例外対応) |
| メンター・コアメンバーからの離脱予兆 | 学長から1on1 30分申し出 |

# 📅 月次レビュー会(45分)

## 開催日:毎月第1月曜 14:00-14:45

### アジェンダ

| 時間 | 項目 | 担当 |
|---|---|---|
| 5分 | 先月数字の確認(MRR、会員数、解約率) | 運営担当 |
| 10分 | KPI 10指標の現状値レビュー | 運営担当 |
| 10分 | 黄/橙/赤シグナル該当者リスト確認 | 全員 |
| 10分 | 当月の特別イベント・新試み計画 | 学長 |
| 5分 | 次回までのアクション3つ確定 | 全員 |
| 5分 | 「先月よかったこと」シェア | 全員 |

- 運営担当(サポート委託先)

# 🛠️ ダッシュボードツール(Notion推奨)

## 構成案

```
📊 サブスク経営ダッシュボード(Notion)
├─ 📈 KPI数字(今月)
│   ├─ MRR / 会員数 / 解約率 / NPS
│   └─ グラフ:月次推移(過去12ヶ月)
│
├─ 🚨 アラートリスト
│   ├─ 黄信号該当者(自動更新)
│   ├─ 橙信号該当者(メンター対応中)
│   └─ 赤信号該当者(学長対応中)
│
├─ 📋 会員データベース
│   ├─ 個人ページ(名前・入会日・誕生月・興味)
│   ├─ アクション履歴(LIVE参加・発言・NPS)
│   └─ 解約予兆スコア(自動計算)
│
├─ 📅 月次運営カレンダー
│   ├─ AI音声配信スケジュール
│   ├─ LIVE開催日
│   └─ 季節節目イベント
│
└─ 📝 月次レビュー記録
    └─ 過去24ヶ月分のアクション・成果
```

# 🔄 KPIと1億円仕組み化15項目の対応

| KPI | 該当する仕組み化項目 |
|---|---|
| MRR / 会員数 | #2 コンテンツ資産化、#3 自動流入 |
| LIVE参加率 / 発言数 | #4 オンボーディング自動化 |
| NPS / 解約予兆スコア | **#11 顧客満足度スコア化** ★直接対応 |
| 解約率 / LTV | #12 リピート・紹介仕組み |
| AI音声開封率 | #8 AIレビュー体制 |

→ サブスク事業は1億円仕組み化15項目の**少なくとも5項目を同時に進める強力レバー**
