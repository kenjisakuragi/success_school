# 🌸 サブスク「叶える私」研究科 — 満足度設計書

> **位置づけ:** 月¥5,000サブスクの満足度を、学長工数を上げずに高い水準で維持するための設計書
> **対象:** 50-60代女性・引き寄せ層(夢実現大学卒業生 + 直接加入者)
> **作成日:** 2026-05-16
> **コアコンセプト:** 「いつ来てもいい、でも来たら必ず満たされる」

---

# 🎯 設計の3原則

1. **個別感はAIで演出、人の温もりはLIVEで集中提供**
2. **「自分のために続ける」が主目的、家族波及は副産物**
3. **学長の月工数4時間を死守。これを超えるなら設計を変える**

---

# 💎 満足度12の仕掛け(優先度順)

## A. 「個別感」を演出する仕掛け(AI主体)

### ★1. AIボイス・毎朝の声かけ
- **頻度:** 月20日(平日)
- **時間:** 朝6:00 LINE自動配信
- **内容例:**「○○さん、おはようございます。今日のあなたの言葉は『私はすでに、求めていたものを手にしている』です。今日も、ご自分を満たしてあげてくださいね」
- **AI使用:** ElevenLabsで学長声をクローン、スクリプトテンプレート月1回更新
- **学長工数:** 月20分(スクリプト確認のみ)

### ★2. 24/7 AIチャット相談ボット
- **位置づけ:** 「いつでも話を聞いてくれる学長」体験
- **トレーニング:** 学長の書籍3冊+セミナー全録画+ワーク回答例で学習
- **使用ツール:** Claude API / ChatGPT API
- **学長工数:** 初期構築後、月1時間(品質監修)

### 3. 誕生月特別配信
- **頻度:** 誕生月のみ
- **内容:** 学長声AIで個別動画(3分)+ 願いの設計シート1枚
- **学長工数:** 月10分(テンプレート確認)

### 4. 入会記念日メッセージ
- **タイミング:** 1年・3年・5年の節目
- **内容:** 学長手書きカード(印刷・郵送はサービス代行)
- **コスト:** ¥500/件
- **学長工数:** 年1回テンプレ作成のみ

### 5. AIワーク添削
- **対象:** 月1回提出される「願いの言葉化シート」
- **AI:** 学長口調でフィードバック生成
- **学長工数:** 月1時間(サンプル監修)

## B. 「特別感」を作る仕掛け(LIVE主体)

### ★6. 新月願い設定LIVE
- **頻度:** 月1回(新月の翌日推奨)
- **時間:** 60分(Zoom)
- **構成:** 学長メッセージ15分 + ワーク30分 + Q&A 15分
- **録画:** 当日中にアーカイブ公開(欠席者対応)
- **学長工数:** 当日60分のみ

### ★7. 満月手放しLIVE
- **頻度:** 月1回(満月の翌日推奨)
- **時間:** 60分(Zoom)
- **構成:** 学長メッセージ15分 + 手放しワーク30分 + シェア15分
- **学長工数:** 当日60分のみ

### 8. 季節節目特別イベント
- **頻度:** 年4回(春分・夏至・秋分・冬至)
- **時間:** 2時間(オンラインリトリート風)
- **特典:** 季節限定ワークブック(AI生成)+ 仲間との深い対話
- **学長工数:** 各回2時間 × 4回 = 年8時間 = 月割0.7時間

### 9. 年次「叶えた私」発表会
- **頻度:** 年1回(12月)
- **時間:** 3時間オンライン総会
- **位置づけ:** 1年の叶ったことを発表しあう、サブスクの集大成イベント
- **学長工数:** 年3時間 = 月割0.25時間

## C. 「つながり」を濃くする仕掛け(コミュニティ)

### ★10. 同期コミュニティ運営
- **ツール:** LINEオープンチャット or Discord
- **学長関与:** 週1回 10分顔出し(月40分)
- **モデレーション:** 卒業生メンター制度で委譲
- **テーマ別チャンネル:** 「叶ったシェア」「言葉のシェア」「お茶会」「お悩み」

### 11. 卒業生メンター制度
- **対象:** サブスク2年継続の優秀メンバー
- **役割:** 新規会員のオンボーディング・週次お声がけ
- **報酬:** サブスク無料 + 月¥10,000謝礼
- **学長工数:** 月1時間(メンター指導)

### 12. 会員間ペア・マッチング機能
- **頻度:** 入会時 + 四半期毎にリシャッフル
- **マッチング:** 同年代・同地域・同テーマでAIマッチング
- **位置づけ:** 「一人ではない」感の決定打
- **学長工数:** ゼロ(AIで自動)

# 🔄 ライフサイクル設計(継続率最大化)

```
月1-3: ブートキャンプ期(密度高め)
  → 同期との繋がり構築、初期成果体験を作る

月4-12: 安定期(月1-2 LIVE + 音声配信)
  → 「自分のリズム」を確立
  → 季節節目イベントで束ねる

月13-24: 深化期(2年継続特典付与)
  → 卒業生メンター候補に
  → 「叶えた私」発表会で年次振り返り

月25+: コア会員期(VIP扱い)
  → メンター就任、報酬発生
  → 学長との1on1年1回特典
  → 法人化・他展開へのサポート
```

# 📊 工数 vs 満足度のバランス(設計の正当性)

## ✅ 工数を抑えられる根拠
- 学長LIVEは月2回のみ、それ以外はAI/コミュニティで回す
- 「学長と直接話したい」需要はAIチャット+年1回1on1で代替
- 個別対応は卒業生メンター制度で委譲

## ✅ 満足度を保てる根拠
- **パラソーシャル絆**:毎朝の学長声で「いつもそばに」感
- **特別感**:節目イベント年4回で「待ち遠しい」感
- **同期感**:活発なコミュニティで「一人じゃない」感
- **進化感**:ライフサイクル設計で「卒業ではなく深化」

## 🎯 想定NPS
- 業界平均(オンラインサロン):NPS +20〜30
- 本設計の想定:**NPS +40〜50**(高い満足度ゾーン)
