# AI半自動化レシピ — 認知的不協和をAIが実装する

> **目的:** 認知的不協和モデルの4ステップを、AIが自動で実行・維持できる形に落とし込む。
> **これがあるから「半自動で夢に近づく」が本物になる。**

---

## 🧩 全体アーキテクチャ

```
受講者(学生)
     ↕  LINE / マイページ
┌──────────────────────────────────┐
│  AI伴走システム(夢実現大学版)     │
│                                  │
│  [Step 1] AI夢ナビゲーター        │
│           ↓ 理想を鮮明にする      │
│  [Step 2] AIドーパミン強化       │
│           ↓ 達成可能感を演出      │
│  [Step 3] AI不協和トラッカー     │
│           ↓ 現実と理想のギャップ  │
│  [Step 4] AI自動行動コーチ       │
│           ↓ 摩擦を最小化          │
└──────────────────────────────────┘
     ↕  画像/音声/テキスト/通知
```

## Step 1: AI夢ナビゲーター — 鮮明イメージ&情報の自動生成

### 🎯 目的
受講者の脳に「理想の状態」をインストールする(=Step 1)。

### 🛠️ 機能

| 機能 | 内容 | 頻度 |
|---|---|---|
| **理想イメージ画像生成** | 受講者の言葉を元にAIが理想の1シーンを画像化 | 週1更新 |
| **理想の1日 ナラティブ** | 朝起きてから夜寝るまでの理想シナリオをAIが文章化 | 月1更新 |
| **音声化(聞き流し用)** | 上記ナラティブを音声化(BGM入り) | 月1更新 |
| **6軸ワーク補助** | 視覚/聴覚/嗅覚/触覚/感情/時系列の質問にAIが伴走 | オンデマンド |
| **情報レコメンド** | 似た夢を叶えた人の事例・関連情報を自動配信 | 1日1本 |

### 🔑 プロンプト設計の核(初期案)

```
あなたは50-70代女性に寄り添う、優しい夢実現ナビゲーターです。
受講者の夢: 「{wish}」
この夢が叶った瞬間の1シーンを、以下の6軸で具体的に描写してください。
- 視覚(何が見える)
- 聴覚(何が聞こえる)
- 嗅覚(何の香り)
- 触覚(何に触れている)
- 感情(どんな気持ち)
- 時系列(その日の流れ)
語り口は柔らかく、断定形(〜している)で。
```

## Step 2: AIドーパミン強化 — 「叶う感」を毎日演出

### 🎯 目的
脳が「理想は手に入る」と予期 → ドーパミン分泌(=Step 2)。

### 🛠️ 機能

| 機能 | 内容 | 頻度 |
|---|---|---|
| **進捗ハイライト** | 今日の小さな進歩をAIが見つけて言語化 | 毎晩 |
| **称賛コメント** | 受講者の行動・気づきにAIが励ましを返信 | 即時 |
| **「もうここまで来た」可視化** | スタート時点との差分グラフ | 週1 |
| **同期(ペア)の進歩共有** | 仲間の達成をAIがダイジェスト配信 | 週1 |

### 🔑 設計ポイント
- ドーパミンは「報酬の **予期** 」で出る → **未来形** の励ましが効く
- 「あなたなら叶えられる」より「もうすぐ叶う」の方が脳に効く

---

## Step 3: AI不協和トラッカー — ギャップを「快い緊張」に変える

### 🎯 目的
現実と理想のギャップを意識化し、認知的不協和を維持(=Step 3)。
**注意:** 不協和が「絶望」になるとシニア女性は離脱。「快い緊張」に保つ設計が肝。

### 🛠️ 機能

| 機能 | 内容 | 頻度 |
|---|---|---|
| **理想 vs 現状 ビジュアライズ** | 2枚の絵 or 写真を並べる | 週1 |
| **「あと◯歩」進捗バー** | 達成度を肯定的に表示 | 常時 |
| **やさしいリマインダー** | 「今日も理想に近づきましょう」LINE通知 | 毎朝 |
| **不協和の言語化** | 「今、◯◯が違うだけ」と差分を1文で表現 | 週1 |

### 🔑 設計ポイント
- **負の感情を増幅しない** — 「足りない」より「あと一歩」表現
- シニア女性に最適化された **やわらかい表現** をプロンプトで固定

---

## Step 4: AI自動行動コーチ — 摩擦を最小化

### 🎯 目的
ストレス回避で脳が動こうとした時、その行動の摩擦を最小化(=Step 4)。

### 🛠️ 機能

| 機能 | 内容 | 頻度 |
|---|---|---|
| **今日の小さな1歩** | AIが具体的な行動を1つ提案 | 毎日 |
| **if-then スクリプト** | 「◯◯が起きたら△△する」を自動生成 | 週1 |
| **行動代行・下書き** | 文章/SNS/メール/予約をAIが下書き | オンデマンド |
| **完了報告ボタン** | ワンタップで完了報告 → 自動称賛 | 毎日 |

### 🔑 設計ポイント
- **「2分以内でできる」レベル** に分解(摩擦最小)
- 完了報告は **タップ1回** で済む(認知負荷ゼロ)

## 📱 受講者体験(典型的な1日)

```
朝 7:00  📲 LINE「おはようございます。今日も理想に一歩近づきましょう」
              → 理想の1日ナラティブ音声(2分)
朝 9:00  📲 「今日の小さな1歩」提案(2分以内でできること)
昼12:00  📲 関連情報1本(あなたの夢を叶えた人のエピソード)
夜21:00  📲 「今日の進歩はどうでしたか?」(ワンタップ報告)
              → AIが進歩を見つけて言語化・称賛
夜22:00  📲 進捗バー更新「あと◯歩」+ 同期の進歩ダイジェスト
```

→ **受講者の能動時間: 合計5〜10分/日。残りはAIが半自動で進める。**
