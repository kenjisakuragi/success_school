# Part A. 青木仁志(アチーブメント)による解説

## A-1. 『思考は現実化する』と青木社長の原点

- **書籍の背景:** 1937年の世界恐慌時代に出版。当時の世界的成功者500人以上を研究し、「いかにして経済的繁栄を作るか」を解き明かしたエビデンスに基づく成功哲学のバイブル
- **人生を変えた出会い:** 青木社長は23歳(1978年)の時、多額の負債を抱え絶望的な状況の中でこの本に出会った。青木社長の人生を変えた3冊の本のうちの1つ(他は「バイブル」「選択理論心理学」)
- **自身の成功体験:** 学歴もお金もない状態から、本書の原則をすがる思いで実行。フルコミッション営業でのトップセールス、マネージャーを経て独立し、現在では社員220名、企業価値100億円を超える人材教育企業を作り上げた

## A-2. 成功と失敗を分ける「最大の決定要因」

成功するか否かは、**育った環境や学歴では決まらない**

- **富の正体:** 富を得るということは「社会に価値を創造すること」
- **成功者の条件:** T型フォードを作ったヘンリー・フォードのように、「多くの人が求めるものを作り出し、人々の望みを叶えられる能力を持っていること」が、成功と繁栄の必須条件

## A-3. なぜ1億人が成功できないのか?(「自己啓発は怪しい」の正体)

全世界で1億部売れても全員が成功しない理由は、非常にシンプルで **「実行していないから」**

- **能力開発の5段階:** 「知る」「分かる」「行う」「できる」「分かち合う」。富が創造されるのは、最後の「分かち合う」レベルに達した時だけ
- **「習慣の壁」に負ける人々:** 多くの人は本を読んで「知る」「分かる」だけで満足。「分かる」と「行う」の間には「習慣の壁」があり、人間は楽な方に流れてしまう生き物
- **他責思考:** 自分が行動できずに上手くいかない事実を正当化するために、「あの本は大したことない」「自己啓発は怪しい」と本や他人のせいにしているのが実態。批判ばかりする不実行者が失敗者となり、実行者は必ず成功者になる

## A-4. 思考を現実化させる「成功の具体的ステップ」(7項目)

成功するためには、「左手には求める姿、右手には日々の選択」を持ち、目的達成に効果的な行動を選択し続ける必要がある

1. **燃えるような願望を持つ:** 自分がどうなりたいか、何を成し遂げたいのか、内側に明確で鮮明な「燃えるような願望」をありありと描く
2. **期限と目標の決定:** 「何を」「いつまでに」実現するかを明確に決める
3. **代償の先払い:** 目標を手に入れるために、自分がどんな代価(代償)を先払いするかを決める
4. **綿密な行動計画:** 目標達成のための、具体的で綿密な計画を立てる
5. **潜在意識への刷り込み:** 決めた計画書を「朝6回、夜6回」声に出して読み、自分の潜在意識に深く刷り込む
6. **達成するまで実行し続ける:** 「できる」「やる」と決めて迷わず実行し、成功するまで絶対に諦めない
7. **資源の統合(思考のパワー):** 自分にない能力は他者の力を借り、資本や人脈などあらゆる資源を願望実現のために統合する

## A-5. 青木社長のまとめ

ナポレオン・ヒルの「成功哲学」と「選択理論心理学」を掛け合わせ、人と共に目標を達成していくための技術 **「アチーブメントテクノロジー(達成の技術)」** として体系化し、世の中に広めている。

> 「人の人生は、その人の考え方以上のものにも、以下のものにもなりません。言い訳をせず『求める姿』と『日々の行動』を一致させ、最後までやり抜くことこそが成功哲学の本質。」

# Part B. 書籍『思考は現実化する』エッセンス

## B-1. 成功と失敗を分ける「真理」

多くの人がこの本を読んでも成功できない最大の理由は、**「知っている」と「行っている」の間にある「習慣の壁」を越えられないから**

- **能力開発の5段階:** 知る → 分かる → **行う** → できる → 分かち合う。富が生まれるのは「分かち合う」段階だが、大半は「知る」だけで満足
- **富の正体:** 富とは、社会に価値を創造した対価。「多くの人が求めるものを生み出し、他者の望みを叶える能力」こそが成功の本質
- **不実行者の言い訳:** 上手くいかない理由を環境や時代のせいにするのは、単なる「ヘリ屈」。批判者は失敗し、実行者だけが成功を手にする

## B-2. 思考を現実化させる「究極の9原則」

成功者が共通して実践している9つのメカニズム:

1. **明確な目標と代償の決定:** 何を、いつまでに達成するかを決め、そのために「何を捨てるか(時間、娯楽、睡眠など)」を明確にする
2. **燃えるような熱意:** 社会の役に立つという真理に基づいた、強烈な願望を持つ
3. **マスターマインド:** 同じ目標に向かう2人以上の協力グループを作り、知恵を相乗効果(1+1=5や6)で高める
4. **逆境の活用:** 挫折は失敗ではなく「成功のための階段」。大きな成功は、一時的な敗北のすぐ先に隠れている
5. **問題の細分化:** 困難に直面したときは、一気に解決しようとせず、細かく分けて1つずつ攻略する
6. **報酬以上の働き(プラスアルファの魔法):** 受け取っている給料や報酬以上のサービスを提供することで、結果的により大きな豊かさが循環する
7. **資金管理による心の余裕:** 貧困への不安を消すために貯金をし、精神的な安定(余裕)を確保する
8. **直感と決断:** 内なる声や直感を信じ、「即断即決」するスピード感を持つ
9. **性的エネルギーの転換:** 人間最大の駆動力であるエネルギーを、娯楽ではなく「仕事の創造性」へと昇華させる

## B-3. 今日から始める「具体的アクション」

思考を脳に定着させ、現実を動かすためのルーティン:

- **目標の言語化と音読:** 目標と期限、払うべき代償を紙に書く。それを「朝起きた直後」と「夜寝る直前」の1日2回、各6回ずつ声に出して読み、潜在意識に叩き込む
- **30分間のイメージング:** すでに目標を達成した自分を、ありありと30分間想像する
- **10回ルール:** 新しいことに挑戦する際、少なくとも10回連続で失敗しても諦めないと決め、行動を継続する
- **奉仕の精神:** まずは自分から他者に与えること。成功者の共通項は「礼儀とサービス精神」

## B-4. 結論

「思考は現実化する」とは、単なるポジティブシンキングではない。**「明確な願望」を「綿密な計画」に落とし込み、「代償」を払いながら「習慣」になるまで実行し続ける技術**のこと。

知識を詰め込む時間は最小限にし、まずは「10分間の読書」や「目標の音読」を習慣化することから、現実は動き始める。

# Part C. 認知的不協和モデル × ナポレオン・ヒル 接続表

# Part D. 夢実現大学カリキュラムへの取り込み方針

## D-1. 採用する古典要素(Top 5)

1. **燃えるような願望の言語化**(Wish + 期限 + 代償の三点セット)
2. **朝6回・夜6回の音読**(潜在意識刷り込みプロトコル)
3. **マスターマインド**(本大学では「同期生のペア制度・ゼミ」として実装)
4. **代償の先払い**(「何を捨てるか」をWOOPの障害セクションと統合)
5. **能力開発の5段階**(プログラム評価軸として採用)

## D-2. 注意して扱う要素

- **「性的エネルギーの転換」(原則9):** 50-70代女性に対しては表現を慎重に。エネルギー全般の昇華という抽象表現で扱う
- **「貧困への不安・貯金」(原則7):** スピ好き女性には合わない可能性。「心の余裕の確保」と一般化
- **「奉仕の精神」:** スピ女性層には親和性が高いので強調可能

## D-3. AI伴走への接続

- **朝6回・夜6回の音読** → AIが目覚まし時刻に音読台本を音声配信。完了タップで記録
- **30分イメージング** → AIが導入ナレーション+BGM音声を生成、毎週更新
- **代償の言語化** → AIが対話で「何を捨てる?」を聞き出し、ワークシート化
- **マスターマインド** → AIが同期の進捗ダイジェストを毎週配信
