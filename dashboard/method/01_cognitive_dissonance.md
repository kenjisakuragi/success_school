## 1. 学長の経験則(本人発言・原文)

2026-05-11 取材:

> 「私が夢実現にもっとも重要なテクニックは『認知的不協和』です。
> 脳に自分の理想の状態をインストールして、脳からドーパミンを出すことができれば、
> 理想の状態から遠ざかることがストレスになるから、半自動で理想の状態になっていくというものです。
> そのためには、鮮明にイメージする必要があるし、情報が必要というわけです。」

👆 **この一節がカリキュラム全体の中央軸。** 全ワーク・全AI設計はこの仕組みを実装するために存在する。

## 2. 4ステップ連鎖モデル

学長の言葉を、再現可能なメソッドに分解する。

```
[Step 1] 理想状態を脳にインストール
           ↓ 鮮明イメージ + 情報
[Step 2] 脳がドーパミンを分泌
           ↓ 「理想は手に入る」という快の予期
[Step 3] 現実と理想のギャップ = 認知的不協和
           ↓ 脳がストレスを感じる
[Step 4] 脳がストレス回避のため、自動で理想側へ行動
           ↓
  🎯 半自動で夢に近づく
```

### 各ステップの中身

| Step | 何が起きるか | 必要な要素 | AIが代行できる部分 |
|---|---|---|---|
| 1 | 理想状態のインストール | **鮮明なイメージ** + **情報** | 画像生成・物語生成・ペルソナ補強 |
| 2 | ドーパミン分泌 | 報酬の予期(達成可能感) | 進捗の可視化・励まし・小さな成功体験の演出 |
| 3 | 認知的不協和の発生 | 現実との対比 | 現状とゴールの差分提示・リマインダー |
| 4 | 自動行動 | ストレス回避動機 | 行動の選択肢提示・摩擦の最小化 |

## 3. 脳科学的な裏付け(補強材料・要監修)

本理論の科学的根拠を以下の概念群で補強する。

| 概念 | 関連 | 出典候補 |
|---|---|---|
| **認知的不協和** (Cognitive Dissonance) | レオン・フェスティンガー(1957) | 心理学の古典 |
| **網様体賦活系**(RAS) | 「意識した情報が引き寄せられる」生理学的説明 | 神経科学 |
| **ドーパミン報酬予測** | 報酬を予期した時点で分泌される脳科学 | ロバート・サポルスキー他 |
| **メンタル・コントラスト**(Mental Contrasting) | 理想と現実の対比が行動を生む | ガブリエル・エッティンゲン |
| **WOOP法** | Wish / Outcome / Obstacle / Plan の実装 | 上記研究の応用 |
| **イメージング(視覚化)** | 五感想起の効果 | スポーツ心理学・コーチング |

## 4. 「鮮明なイメージ」の中身を分解する

学長は「鮮明にイメージする必要がある」と明言。ここをワーク化する。

### 4-1. 鮮明イメージの6軸

| 軸 | 質問 | ワークでの問い |
|---|---|---|
| 👁️ 視覚 | 何が見える? | 部屋・服装・周囲の人 |
| 👂 聴覚 | 何が聞こえる? | 会話・音楽・環境音 |
| 👃 嗅覚 | 何の香りがする? | 場所のにおい |
| 🤝 触覚 | 何に触れている? | 手触り・温度 |
| ❤️ 感情 | どんな気持ちでいる? | 喜び・誇り・安心 |
| 🎬 時系列 | 朝起きて夜寝るまで何をしている? | 1日の流れ |

### 4-2. AI半自動化のレシピ(詳細は `03_ai_integration.md`)

- **AI画像生成**:理想の1日のシーンを画像化(毎週更新)
- **AIナラティブ生成**:理想の朝〜夜の物語を文章化、毎朝LINEで配信
- **AI音声化**:本人の声 or BGM入りで聞き流せる音声を生成

## 5. 「情報」の中身を分解する

学長は「情報が必要」と明言。これも分解する。

### 5-1. なぜ情報が必要か(仮説)

- 理想状態に **既に居る人** がやっている習慣を知る → 模倣可能性が見える
- 理想状態への **道筋** を知る → 「届きそう」という現実感が生まれる
- **不協和を維持** するための日々の刺激 → 忘却を防ぐ

### 5-2. 情報の種類

| 種類 | 目的 | 例 |
|---|---|---|
| 事例情報 | 「自分にもできる」感 | 同じ属性の人の成功談 |
| 環境情報 | 五感の強化 | 場所・モノ・人の写真 |
| 方法情報 | 道筋の可視化 | 手順・ノウハウ |
| 進捗情報 | 不協和の維持 | 「現状」と「理想」のギャップ表示 |

### 5-3. AI半自動化のレシピ

- **毎日の情報配信**:AIが受講者の夢に応じた情報を1日1本、自動でLINE配信
- **進捗ダッシュボード**:AIが現状と理想のギャップを可視化(不協和を維持)
- **事例レコメンド**:AIが「あなたに似た人の成功事例」を週次でピックアップ

## 6. なぜ「半自動」なのか — 意志力との決別

従来の自己啓発は **「強い意志」「努力」「習慣化」** に頼ってきた。
しかし、シニア女性(欲深くない・優しい)にこれは負担。

**認知的不協和モデルは、脳の仕組みを利用して「努力なしで動けるようにする」点が本質。**

| 従来 | 本メソッド |
|---|---|
| 意志で頑張る | 脳が自動で動く |
| 続かないと挫折 | 続かなくても脳が引き戻す |
| 行動 → 結果 | インストール → 自動行動 → 結果 |
