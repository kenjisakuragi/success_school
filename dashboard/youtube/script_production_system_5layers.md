# 🧠 半永久・高品質台本生産システム — 5層アーキテクチャ

> **コア仮説:** 「ソースの質」と「切り口の鮮度」で品質の90%が決まる
> **作成日:** 2026-05-16

# 5層構造

- Layer 1: ソース収集(偊人原書/学長体験/顧客ペイン/脳科学/競合)
- Layer 2: 20切り口テンプレ生成
- Layer 3: 4段階台本生成(初稿→批判→スコアリング→承認)
- Layer 4: 3ループ学習(パフォーマンス/コメント/競合)
- Layer 5: メタ学習(プロンプト自動改善/ソース拡張/IP蓄積)

詳細は 口頭指定で設計済み。Notion DBで実装。

# 品質スコアリング(100点満点・75点以上で合格)

- 構造スコア(20)
- CTA配置スコア(15)
- 感情喚起スコア(20)
- 学長物語整合性(15)
- SEOキーワード密度(10)
- 著作権安全度(20)
