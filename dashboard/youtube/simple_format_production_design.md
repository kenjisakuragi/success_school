# 🎯 コンセプト

**「動かない動画」で勝つ**

スピチャンネル、とりわけ「眠れる」「ながら聴き」ジャンルでは、視聴者は画面を見ていない。
結果、センターピンは以下の順番:

1. **ナレーションの聴きやすさ**(センターピン主軸)
2. **テロップの読みやすさ**(視覚補助)
3. 背景画像(可仮)
4. BGM(雰囲気)
5. 動き(不要)

## 詳細スペック

### 背景胖像画
- **サイズ:** 画面全面(テロップザブトン部分はその上に重ねる)
- **加工:** 厳粛な色ずけ(セピア調 or 低彩度グレー)
- **明さ:** テロップザブトンそけても背景胖像画が見える明るさ
- **ソース:** Wikipedia Commons(PD) / パブリックドメイン画像 / AI生成(ミドジャーニー「○○風」)

### ザブトン(テロップ背景帯)
- **色:** 黒 80%半透明 (`rgba(0,0,0,0.8)`)
- **位置:** 画面下1/3
- **高さ:** 220-280px(1080p基準)
- **角丸:** 8-12px
- **下のマージン:** 80px
- **スタイル代替案:**
  - 深ネイビー 80%透明 + ゴールド枠線
  - 朝焼け色 90%透明 + 白テキスト(動画画面と区別明確)

### テロップ
- **フォント:** ヒラギノ角ゴ ProN W6 または 源ノ角ゴシック Bold
- **サイズ:** 60-72pt(1080p、画面高の6%)
- **色:** 白(メイン) + ゴールド(キーワード強調)
- **文字量:** 1画面あたり 15-20文字
- **行間:** 1.6-1.8
- **出現/消示:** フェードイン 0.3秒 / フェードアウト 0.4秒
- **タイミング:** 音声と同期

### ナレーション(センターピン)
- **読み上げツール:** ElevenLabs(学長声クローン)
- **読み上げ速度:** 0.85x(やや遅め)
- **間のテンポ:** 句点で 0.7秒、改行で 1.2秒、段落で 2秒

### BGM
- **ジャンル:** 432Hzヒーリングミュージック / アンビエント
- **音量:** 音声の15-20%(-20dB)
- **ソース:** YouTube Audio Library(無料) / DOVA-SYNDROME

# 🧪 PoC 2週間検証プラン

## 仮説
**「胖像画+ザブトン+音声+テロップだけで、視聴維持率50%以上を達成できる」

## Week 1: 準備・制作
- Day 1: Canvaザブトンテンプレ3パターン作成(学長 1h + VA 3h)
- Day 2: 胖像画10枚ダウンロード+加工(VA 3h)
- Day 3: Vrew設定+1本目試作(VA 3h)
- Day 4: 学長レビュー → 修正(学長 30m)
- Day 5-7: 残り9本制作(VA 15h)

## Week 2: アップロード・測定
- Day 8-10: 10本を順次予約投稿(2日に1本)
- Day 11-14: KPI測定

## PoC成功基準

| 指標 | 合格ライン |
|---|---|
| **視聴維持率** | 50%以上(13分動画なら6.5分以上) |
| **CTR** | 3%以上 |
| **1本あたり制作時間** | 30分以下(VA工数) |
| **ネガコメ「映像が地味」** | 5%以下 |
| **学長満足度** | この方式で運用継続したい |

## クリアした場合
⚡ 本格量産開始、月33本体制へ移行

# 📝 記録:学長の戦略的判断

## 「シンプル化」で得られるもの
1. 制作コスト 30%削減
2. 制作時間 64%削減
3. 同コストで生産量倍增可能
4. 著作権リスク減少(胖像画PD主軸)
5. 「動画やり直し」コストも低い(台本調整で指針改善)

## 「シンプル化」で夫うもの
ただし、それを超えるリターンがある:
1. チャンネルの視聴者に「人気」を出しにくい可能性
2. ただし、ターゲット層(50-60代女性スピ層)は「そもそも動きを望んでいない」ため、ダメージは小さい

## この判断は「手離れ哲学」と完全に一致
学長の事業哲学「手離れ」「仕組みで叶える」と、このシンプル化フォーマットは完全に一致している。
1億円仕組み化15項目の**#7 「自分にしかできない作業をゼロに」**を進める上での幾何級進捗。
