# 🎯 全体制作パイプライン

```
Step 1: トピック選定(月1回・学長月1h)
  ├─ 100タイトルバンクから月本数選択
  ├─ 月1回の検討会で決定
  └─ 3ヶ月先まで計画してストック入り

Step 2: 台本生成(週次・学長週月2-3h)
  ├─ Claude/GPT-4で一括下書き(VA作業)
  ├─ 5パターンテンプレで量産(テンプレ則別ファイル参照)
  └─ 学長はトップチェックのみ(本5分×10本 = 週月50分)

Step 3: 音声生成(週次・VA10h)
  ├─ ElevenLabsで一括生成
  ├─ 品質チェックのみ(学長月5分)
  └─ スクリプトトークスクリプト調整

Step 4: 動画組み立て(週次・VA20h)
  ├─ Vrew/Pictoryで自動編集
  ├─ Midjourney背景・Canvaサムネ
  └─ BGM、SE選定

Step 5: YouTubeアップロード(月次・VA10h)
  ├─ SEO説明文・タグ設定
  ├─ サムネA/B設定
  ├─ 予約投稿(週次3本×4週 = 月12本本編 + スリープ8本 + ショートトーク13本)
  └─ コメント同ボタン設定

Step 6: 振り返り(月次・学長月1-2h)
  ├─ ダッシュボード確認
  ├─ 品質・CTR・視聴維持率分析
  └─ 次月計画修正
```
