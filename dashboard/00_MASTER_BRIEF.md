# 🔴 確定事項(不変)

## 学長プロフィール
- 40代(1980年生まれ)、妻(共働き) + 2人娘(2歳・0歳)、会社勤め並走して多事業をスタートアップ
- 学歴:聖光学院中学 → 東大現役合格
- 聖光で「下から数えた方が早い」→高1で「自己暗示を思い出して本格化」→トップ3となり東大現役合格
- 原体験:**1991年・11歳でテレビでスピードスケートの橋本聖子選手のイメージトレーニング・自己暗示について語る番組を見て衰撃**
- **1992年アルベールビル五輪で橋本選手が1500m銅メダル獲得 → 「本当だった」と確信し、関連書を読み漁る**
- 使命:**多くの人を幸せに導く**
- 哲学:「自分でコントロールできる自由=幸せ」
- 他実績:副業で本業超え、書籍出版、理想の妻と結婚、不妊治療を乗り越えて2人娘、都内一等地マンション、妻と毎年ミシュラン・リッツ

## スクール・ブランド名
- **AIと叶える 夢実現大学**(本軸・50-70代スピ女性)
- **受験や子育て世代向けプログラム**(名称調整可)
- **50代独立学部**(将来)

## コアベネフィット
- **「半自動で夢に近づく」**
- 「努力ではなく、仕組みで叶える」

## コア理論
- **認知的不協和×AI半自動化**
- 4ステップ連鎖:インストール → ドーパミン → 不協和 → 自動行動
- 統合した古典:マーフィー / ナポレオン・ヒル / DaiGo / 引き寄せ

## スクール価格・収益設計
- **本科**:¥148,000(3ヶ月)
- **上位プラン**:¥198,000
- **継続会員**:¥3,300〜¥5,500/月
- **受験・子育てプログラム**:¥300,000/年
- **利益分配**:自社60% / JV先40%
