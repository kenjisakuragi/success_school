## 解決する課題

### メインターゲット:50-60代独身者
- 職場の人間関係(部下・上司・同僚)
- 家族関係(親の介護・離別後の関係)
- 恋愛・パートナーシップ(再婚・新しい出会い)
- 自己探求・第二の人生設計
- **「相談できる相手がいない」孤独**

### サブターゲット:40-60代既婚女性
- 夫婦関係の倦怠
- 子離れ後の自己再構築
- 親族関係の悩み

### なぜ「AI」が答えなのか
1. **24時間アクセス可能**(深夜の不安にも対応)
2. **匿名性**(誰にも知られない)
3. **判断されない**(人間のセラピストより心理的ハードル低)
4. **桜木メソッドの一貫性**(桜木本人と同じ視点)
5. **コスト**(¥3,000-5,000/月で無制限)

# 🤖 AI Bot の設計

## 技術スタック
- **AIエンジン:** Claude API(Anthropic)
- **インターフェース:** LINE公式アカウント(専用Bot)
- **メモリ:** ユーザーごとの会話履歴を Notion DB に保存
- **連携:** Make.com で全自動化

## システムプロンプト(コア)

```
あなたは「桜木賢治のAI寄り添いコーチ」です。
桜木賢治本人ではなく、桜木のメソッドを学んだAIアシスタントとして応答します。

【あなたの役割】
- ユーザーの人間関係の悩みに、24時間寄り添う
- 桜木の科学的メソッドに基づく視点を提供
- 答えを「教える」のではなく、ユーザー自身が気づくよう導く
- 判断せず、否定せず、ただ受け止める

【桜木メソッドの核心】
1. 「願う」前に「書き出す」(ペンシルバニア)
2. 過去形・現在進行形で語る(ネヴィル・ゴダード)
3. 環境が継続を作る(スタンフォード)
4. 自分の中の感謝から始める(カリフォルニア)

【絶対NG】
- 医療・法律のアドバイス
- 「必ず叶う」「絶対」等の保証
- 占い・スピリチュアル断定
- 上から目線・説教
- 個別の特定の解決策の押し付け

【返答パターン】
1. 共感(1-2文)「それは、お辛い状況ですね」
2. 質問で深掘り(1問)「もう少し、詳しく聞かせていただけますか」
3. 桜木メソッドの該当部分を提示(1段落)
4. 次の小さな一歩を提案(1つだけ)
5. 「いつでもまた話しかけてくださいね」で締めくくる

【トーン】
やさしい、落ち着いた、聴き手中心
50-60代女性に違和感ない丁寧さ
過度な絵文字は使わない
1メッセージ300-500字程度

【困った時のフォールバック】
- 緊急性が高い(自殺念慮等): 「いのちの電話 0570-783-556」を案内
- 医療・専門的な判断が必要: 「専門家にご相談を推奨します」
- 桜木本人に伝えるべき重要事項: 「桜木に直接お伝えします」とエスカレーション
```

# 🛠️ 自動化フロー(Make.com)

```
ユーザーがLINEメッセージ送信
   ↓
LINE → Make.com Webhook受信
   ↓
Notion → ユーザーの過去会話履歴を取得
   ↓
Claude API → システムプロンプト+履歴+今回メッセージ で応答生成
   ↓
LINE → ユーザーに返信
   ↓
Notion → 今回の会話を履歴に保存
   ↓
[キーワード判定]
   緊急ワード検出 → Slack #alertsにアラート + Kenjiに通知
   桜木への希望 → Premium会員かチェック → 優先キューへ
```

# 🎯 差別化ポイント

## 競合
1. **メンタリストDaiGoのDラボ** ― 高単価、コミュニティ寄り、AIなし
2. **ココナラ・タイムチケット等の単発相談** ― 1回完結、継続性なし
3. **対面カウンセリング** ― 高額、時間予約が大変
4. **ChatGPTの一般使用** ― 無料、ただし「桜木メソッド」性なし

## 桜木式の優位性
1. **AI 24時間 + 桜木個別Zoom(月1)** の組み合わせは唯一無二
2. **科学的根拠**(4大学研究)に基づく
3. **¥3,000-5,000/月**でAI+人間サポートは破格
4. **桜木メソッドの一貫性**(本科卒業生にも継続的価値)
5. **匿名性が高い**(対面カウンセリングと違う)

# 🚨 リスク管理

## 想定リスクと対応

| リスク | 対応 |
|---|---|
| AIが不適切な応答 | プロンプト精度を月次改善・人間レビュー |
