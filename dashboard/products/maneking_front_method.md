# 🌸 マネキングの設計(完全版)

## なぜ「マネキング」と名づけたか

- **マネク(招く)** + **-ing**(進行形)
- 「招き続けている、今この瞬間も」のニュアンス
- AIマニフェスティング のコア概念「マネク」を入口商品名に
- 「ing」で英語圏的・若々しさ・トレンド感
- 「マネキ猫」とも音が似ていて、日本人にとって縁起良い

## メソッドの構造(超シンプル)

```
朝(3分):
  📱 AIから「3年後のあなた」のメッセージが届く
  📝 ノートに、それへの返事を書く

夜(3分):
  📝 「今日、未来の私に、近かった瞬間」を1つ書く
  📱 AIから「おやすみのメッセージ」が届く

― これだけ。
  毎日6分、誰でもできる。
  21日で何かが変わる。
  90日で現実が動く。
```

## なぜシンプルが効くか

- 50-60代女性の朝晩のルーティンに自然に組み込める
- 「やらない理由」が消える(忙しくても6分)
- 「やったかどうか」が記録に残る(ノートが財産化)
- AIとの関係が、毎日積み重なる(継続率UP)

