# 🎬 ストーリーの核心(サミット用)

## 90秒で語れる「桜木の物語」

```
私は40代の会社員です。
顔出しはせず、声だけでお話しています。

11歳の夜、テレビで橋本聖子選手のイメージトレーニング話を見て、
「自分にもできる」と感じた光を、30年消さなかった。

聖光学院で「下から数えた方が早い」成績だった私が、
高1で「思い出した」あの方法で、東大現役合格。

30代でバーンアウトして、すべてを失いかけた時、
もう一度「思い出した」ことで、今、妻と娘2人と幸せに暮らしています。

東大の知性と、日系企業で20年のキャリアと、引き寄せ30年の検証。
これを統合して、私は今、「科学的引き寄せ」を体系化しました。

ハーバード、スタンフォード、カリフォルニア、ペンシルバニア。
世界トップ4大学の研究が、すべて同じことを言っています。

スピリチュアルではなく、神経科学。
「願えば叶う」ではなく、「設計すれば叶う」。

50代60代から、人生は、設計できます。
今日は、その全体像を、お伝えします。

最後まで、お付き合いください。
```

# 🚨 リスクと対応

| リスク | 対応 |
|---|---|
| サミット枠が取れない | 大熊さんと早期確認、他登壇機会も並行検討 |
| 顔出しが必須と判明 | 「声+静止画+テロップ」プレゼン形式を提案、または代替アバター |

| 桜木スライドが完成しない | 既存セミナースライドv2を流用可能(2026-05-21時点で完成済) |
| 本業(TBS)との調整 | 平日夜 or 土日開催を希望、調整不可なら録画登壇 |
