# 🔑 不労化のポイント「5つの」原則

1. **一度作ったら、永遠に売る状態にする** — Kindle、Udemy、録画コースはそれが可能
2. **YouTube/SEOと連携させる** — 一度作った動画が、永遠に見込み客を生む
3. **価格を二重底上げ** — ¥30Kコースが ¥50K、¥70K と頭上げしても、不労を保ちながら収益増加
4. **VAに委譲できる工程をそうしない** — 受講生CS、メッセージ送信、データ集計
5. **録画画質より「コンテンツの振り宛て」重視** — スマホで見ても関わろう見やすさを計語
