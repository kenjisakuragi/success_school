# 🌷 引き寄せ層プログラム運営時の留意点

- [ ] **『自分の幸せ主軸を崩さない』** — セッション進行中「子供が」「夫が」という話が出てきたら、やさしく「あなた自身はどう感じていますか」と返す
- [ ] **家族への波及は『Session 12』で『副産物』として一言言及のみ** — 中途で是して語らない
- [ ] **『努力』『成功』『稼ぐ』を多用しない** — 「整える」「叶える」「響かせる」「満たす」を採用
- [ ] **マーフィー博士・クーエ博士の引用を毎セッション配置** — 王道古典として信頼形成
- [ ] **WOOPやIf-Thenなど心理学技法は『科学的補強』として位置づける** — スピと科学の橋渡し
- [ ] **『同志』という呼び方を採用** — 『生徒』『受講生』より対等で、引き寄せ層に響く
- [ ] **季節の節目を運営に取り入れる** — 春分・秋分・新月・満月など。スピ親和性が高い
- [ ] **オンラインでも『場』の感覚を演出** — お香・お茶・キャンドル等を各自用意してもらう
- [ ] **同志コミュニティのモデレーション** — 否定的・批判的な投稿はやさしく介入
