## ⚡ コア哲学

- **「これを今すぐやるかどうかで、3ヶ月後の売上が大きく変わる」**
- 工数を増やさず、仕組みで売上を伸ばす
- 1億円規模に到達するには、属人性ゼロ化が前提
- 「20原則」「集客先行論」と並ぶ、三位一体の十代哲学

## 📋 15項目全体(オリジナル全文)

### ＜集客＞
- [ ] **1.** 自分が発信しなくても、問い合わせが来る
- [ ] **2.** コンテンツを資産化し、継続流入する仕組み
- [ ] **3.** SNS・SEO・広告のいずれかを自動で流入させる導線

### ＜セールス＞
- [ ] **4.** 受注後のオンボーディングをほぼ自動化する
- [ ] **5.** クロージングをスクリプト化。例外案件に対応
- [ ] **6.** 提案・見積もりをテンプレ化し、誰でもできる

### ＜納品・制作＞
- [ ] **7.** 「自分にしかできない作業」をゼロに近づける
- [ ] **8.** 品物のレビューを他者やAIができる体制にする
- [ ] **9.** 業務フローをマニュアル化。AIとテンプレで標準化

### ＜顧客管理・フォロー＞
- [ ] **10.** ステップメール・CRMで関係維持を自動化
- [ ] **11.** 顧客満足度をスコア化し解約リスクを検知する
- [ ] **12.** リピート・紹介が仕組みから生まれる状態に

### ＜価格設計＞
- [ ] **13.** 工数ではなく「成果」で単価を決める
- [ ] **14.** 稼働を増やさずに、売上の上限を上げる
- [ ] **15.** 成果連動型の価格で単価の天井を取り除く

## 🎯 「1億円」という数字に到達するために

### 現在の澍在キャパシティ
- 夢実現大学 年間売上見込み: ¥1,515万(セミナー+本科+上位+サブスク、年4期)
- シニアAIスクール 年間売上見込み: 倉定¥300万(35名·20,000…4期×75人)
- 合計: 約¥1,800万

### 1億円へのギャップ埋め路線

```
現在      ¥1,800万   ├─────────────────── 1×
中間地点 ¥5,000万   ├─────────────────── ×2.8
1億円  ¥10,000万  └─────────────────── ×5.6
```

**ギャップを埋める主要仕組み:**
1. **AI伴走Botサブスク** — 1,000名×¥5,000×12ヶ月 = ¥6,000万/年(粗利率90%+)
2. **認定講師制度** — 並列事業3期同時開催で本科売上×3
3. **B2B・自治体契約** — ¥300-500万/件×10-20件 = ¥3,000-1億円
4. **Kindle書籍三三千部** — 3冗×5,000部×¥800 = ¥1,200万
5. **JV網拡張** — 5JV先×¥1,000万 = ¥5,000万

**これらを実現するための15項目仕組み。それが本チェックリストの使い道。**
