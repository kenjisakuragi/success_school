# 🎐 文言・トーンガイド(重要)

## 採用する言葉
- 「叶える」「響かせる」「満たす」「整える」「育てる」
- 「あなた自身のために」(主目的) / 「家族への波及」(副産物)
- 「100年前の知恵」「現代の脳科学」
- 「あなたのせいでは、ありません」(共感・救済型)

## 避ける言葉
- 「努力」「成功」「稼ぐ」(男性的・実利的)
- 「成り上がる」「勝ち取る」「転をする」(競争的)
- 「あなたを変える」(あなたはそのままでよい、取り戻す)

## ナレーション口調
- やさしい、落ち着いた、聮き主中心
- 読み上げ速度0.85xり(やや遅め)
- 句点で0.7秒、改行で1.2秒の間
- 「ですね」「んです」「ものです」
