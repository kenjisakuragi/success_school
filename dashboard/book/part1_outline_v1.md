4. **本書の立場**:スピリチュアル要素は一切採用しない。検証可能なメカニズムだけで「引き寄せ」を再構築する
5. **読者への安心**:「だから怪しい本ではない。心理学の標準的知見しか使わない」

## 第4章 書くだけで達成率42%向上 ― Matthews研究とPennebaker

**ボリューム:** 約5,000字
**目的:** Scripting(書く)の効果を、最も強いエビデンスで証明

**論点:**
1. **Matthews (2015) Dominican University 研究** ― 目標を書き出した群が未記入群より達成率42%高(149名RCT)
2. **Pennebaker (1986〜) 表出筆記法** ― 30年で200以上の追試。心理的健康・免疫機能の向上を実証
3. **King (2001) ベストポッシブルセルフ法** ― 4週間書き続けた群が幸福度・楽観性で持続効果
4. **Gollwitzer (1999) 実装意図(Implementation Intention)** ― 「いつ・どこで・どう」を書くと実行率2〜3倍。94研究のメタ分析で確立
5. **なぜ「書く」が効くのか** ― 言語化が漠然とした願望を検証可能な目標に変換し、脳の Default Mode Network から実行系に切り替える
6. **本書のScripting法の予告** ― 第11章で「未来からの手紙」プロトコルを詳説

**既存流用:** `kindle_01_manuscript_part2.md` Scripting実証パートを流用
