# 🎯 ポジショニング・リスク検証 — 「振り切る」仮説

> **作成日:** 2026-05-14
> **検証仮説:** 「保守層の拒絶反応を気にせず『自己暗示』で振り切る方が、事業のアップサイドは大きい」

---

## 結論(先出し)

**仮説は正しい。振り切るべき。**
ただし「振り切り方」を間違えると逆効果。「科学的に振り切る」が正解。

期待値計算: **振り切り = 中庸の3倍以上の事業サイズ**

---

## 1. 拒絶層の正体 — 実際にどんな反論が来るか

| 反論タイプ | 言葉 | これを言う人は顧客になるか? |
|---|---|---|
| 🔴 洗脳警戒型 | 「子どもに暗示をかけるのは洗脳だ」 | 元々NO |
| 🔴 努力崇拝型 | 「努力と誠実さで受かるのが正道」 | 元々NO |
| 🔴 スピ警戒型 | 「やっぱりスピチュアルだ」 | 元々NO |
| 🔴 企業姑息型 | 「薬機法・景表法に触れる可能性」 | 顧客ではない(規制側) |
| 🟡 中道型 | 「自己暗示も大事だが努力も…」 | 購買者にはならない(中途半端) |
| 🟢 期待型 | 「自己暗示で受かるなら知りたい！」 | **コア顧客** |

**鍵となる事実:** 赤転警戒型は **元々顧客にならない**。ボリュームをひろげるために、今いない顧客を気にして、いない顧客を逃すことの意味のなさ。

## 2. 振り切るべき6つの理由

### 理由① 明確な敵を作ると、明確な味方ができる
- 「努力崇拝 vs 仕組み崇拝」の構図をつくると、「認知的不協和×AI」に共感する層が **「我々の仲間」と認知して信者化する**
- 他者との明確な違い = ブランドの輪郭

### 理由② 議論を呼ぶ = 拡散する
- 中立なコンテンツはシェアされない
- 「えっ、自己暗示で東大?」と思わせるためと「SNS拡散」が生まれる
- Amazonも「越境したタイトル」しか Top10 に入らない

### 理由③ マーフィー市場はすでに確立している
- 『眪りながら成功する』は世界で数千万部
- 『思考は現実化する』も数千万部
- **拒絶層が市場を壊していたら、こんなに売れていない**
- 「自己暗示」は大衆認知されている(警戒された言葉ではない)

### 理由④ 学長の権威性が反論をブロック
- **東大現役合格者が「自己暗示で受かった」と言う」**
- 反論しようとする人は「じゃああなたは受かったの?」と言われるリスク
- 体験者の語りは議論を打ち勝つ

### 理由⑤ 鉄則⑦「見込み客の行列」に振り切りが必須
- 中道のコンテンツに行列はできない
- 「ここでしか語られていない」が行列を作る

### 理由⑥ クリスチャンセンの「ボーリング」を避ける必要
- どんな名著も言われる「退屈で、中途半端」が最悪
- 振り切る = シグナルを送る = 選んだ顧客に届く

## 5. 「正しい振り切り方」5原則

### 原則① 科学性を超して振り切る
- 事都合よく「是許説」で振り切らない
- クーエ(1857)·マーフィー·セリグマン·現代脳科学 を全部記載
- **「掲載は反論をブロックする武装」**

### 原則② 「努力不要」とは言わない
- **努力の「量」とは言わず、「質」を変えると言う**
- 「努力が報われる脳をつくる」と言う
- 不誠実な印象を避ける

### 原則③ 学長の自己実証を全面に出す
- 「私は東大に現役で受かりました」
- 「マーフィーに出会っ1981年からの45年、これで生きてきました」
- **体験者の語りを反論できる人はいない**

### 原則④ 倒すべき「仲間郣揄」を明示する
- 「ただの思い込み」と「設計された思い込み」を対比
- 「努力主義」と「仕組み主義」を対比
- **明確な敵 = 危険な加担者ではない**(「拒絶するダメな考え方」)

### 原則⑤ 倒さないものを明記
- 努力を倒さない
- 誠実さを倒さない
- 子供の意思を倒さない
- 「親が子をコントロールしろ」とは言わない
- **伝えるのは「子が自分で叶える脳を作る設計法」**

## 6. 想定問答集(メディア・受講者向け)

| Q | A |
|---|---|
| 自己暗示って洗脳では? | 洗脳は他者がやるもの。自己暗示はあなたがあなたにやるもの。**主体と規模が違う**。 |
| 努力不要ということ? | 努力の「量」ではなく「質」を変える話です。努力が報われる脳をつくる。 |
| 子に使うのはよくないのでは? | 本書は **子に使う本ではなく、子が自分で使えるよう親が支える本**です。 |
| 本当に受かるの? | 私が1991年にそうして受かりました。他の実例も本書中で紹介しています。 |
| スピリチュアル? | スピリチュアルと一緒にされてきたため評価されていないだけで、これは「脳科学」です。RAS・ドーパミン報酬予測・認知的不協和で説明できます。 |

## 7. 取りうるリスクと対策

| リスク | 発生確率 | 対策 |
|---|---|---|
| 出版社が「教育系に不適切」と拒否 | 低 | 始めから低価格KDP自費出版を主軸に |
| SNS烎上 | 極低 | 学長の言葉遣い(努力否定しない)で防ぐ |
| 「薬機法・景表法」違反 | 低 | 「合格できる」ではなく「脳の使い方」として語る |
| 「東大」を使うことへの批判 | 低 | 個人実証として使う｛×「受かる保証」表現は避ける |
| 学長の評判リスク | 中 | 長期では **言うべきことを言う人** としてブランド化 |

**重要:** リスクはあるが **十分管理可能**。

## 9. 勧められない振り切りパターン(警戒)

- ❌ 「努力は不要」とは言わない
- ❌ 「誘社は間違っている」とは言わない
- ❌ 「『必ず受かる』と保証」はしない(景表法リスク)
- ❌ スピリチュアル要素をそのまま振り切らない
- ❌ ターゲットを挑発しない(「今やってることはダメ」とは言わない)
