## 1. 「リクルート参入可否」の判定軸

リクルートが参入する市場の5条件:
- ライフイベント(人生の重要決断)
- 高単価(¥100万～¥1,000万)
- 検索意図明確
- 広告予算ある業界
- マッチング型で手数料モデル可能

リクルートが **手を出しにくい** 領域の特徴:
- 個別性が高すぎる(それぞれ不同)
- 専門知識が深すぎる(医療・法律・教育)
- サポーターが分散している
- センシティブ領域(信頼がブランドより専門家依存)
- 規制極厳しい業種
- 一件あたりのサービス期間が長い

## 4. 🏆 TOP 3 推奨事業 — 詳細設計

### 【推蔷①1】中学受験×親のメンタル管理×AI伴走

**仮名称:** 『親が壊れない中学受験』 / 『東大卒の父が教える 受験脳のつくり方』

| 項目 | 設計 |
|---|---|
| **ターゲット** | 首都圏中学受験生の親(40代中心) |
| **主訴求** | 「子より、親をインストールし直せば、受験は受かる」 |
| **サービス** | 12ヶ月伴走プログラム(認知的不協和を親子両方に適用) |
| **単価** | ¥300,000(年間)+ ¥10,000/月(継続会員) |
| **集客先行** | 書籍『東大卒の父が教える、親が壊れない中学受験』 → 出版社エンジン |
| **リクルート参入難度** | 高(塔やスタディと利益相反、「親の心」は専門外) |
| **推定年間・受講能力** | 100家庭×¥30万 = ¥3,000万/年 + 継続会員 |
| **鉄則適合** | ①②③④⑤⑥⑦⑧⑨⑪⑬⑮⑯⑱⑳ クリア |
| **学長の権威性** | 東大現役合格 → 反論不可能の実証者 |

**これが最強である理由:**
- 学長の「東大現役合格」の権威性がそのまま有効
- 中学受験の親は「子より自分のメンタルがやばい」という本音を多くが抱える
- 講座や塔も「子どもに教える」ばかり、**「親の伴走」はガラアき**
- 認知的不協和メソッドがそのまま適用できる(合格の鮮明イメージング)
- リクルートにとっては塔マッチングの方が償けるので、リクルート未参入
- LTV高(ともに6年・上の子/下の子で複数期)

### 【推蔷②2】不妊治療・姊活チーム伴走×AI

**仮名称:** 『AIと叶える姊活』 / 『2人で乗り越える不妊治療』

| 項目 | 設計 |
|---|---|
| **ターゲット** | 不妊治療中の夫婦(30代中心) |
| **主訴求** | 「医療だけでは足りない。メンタルと夫婦関係の伴走を、乗り越えた夫婦から」 |
| **サービス** | 6ヶ月プログラム(夫婦セット) + AIコーチBot |
| **単価** | ¥500,000(ペア価格) |
| **集客先行** | 書籍『不妊治療で壊れそうになった妻と、それを支えた多人生』 |
| **リクルート参入難度** | 極高(医療規制・感情労働・個別性) |
| **推定年間・受講能力** | 50夫婦×¥50万 = ¥2,500万/年 |
| **鉄則適合** | すべてクリア(「頭を下げられて売る」極致) |
| **学長の権威性** | 乗り越えた本人+妻の両方が語れる世界に一人 |

**これが強い理由:**
- 学長の実体験が 「他者と交換不可能な語り口」 を許さない
- 不妊治療中の夫婦は「他人に話せない」関係上、AI伴走は最適ソリューション
- 不妊治療市場は拡大中だが、**メンタルケアはデッドクロス**
- クリニックは医療そのものに集中していて、**姊活伴走はガラアき**

## 6. 実行上の注意点

### ブランド分離の原則
- 各ブランドは独立したLP・LINE・書籍を持つ
- 共通メソッドIPは講師(学長)とAIシステムに含まれる
- ターゲット間のコミュニティを混ㄨるない(選択して参加可能)

### 学長ボトルネックの回避
- 各ブランドで **講師育成** を必須(公認コーチ制度)
- 学長は 【主講義 + メソッドアップデート + 1on1(高単価層)】のみ
- AI伴走 + コーチ + 同期コミュニティで 「手離れの良さ」 を設計

### 市場サイズ検証
- 事前プロジェクトとして、**各ブランド立ち上げ前に「無料PDF + LINE」で200名集める**(集客先行原則)
- 200名集まれば市場あり → 本杩3ヶ月プログラムをスタート
- 200名以下ならピボット or 中止
