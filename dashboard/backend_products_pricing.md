## 0. 設計コアルール

### 5つの判断基準

| 軸 | ルール |
|---|---|
| 1️⃣ 粗利率 | **最低75%** を保証(販促代・決済手数料込み) |
| 2️⃣ 学長時間価値 | **1時間あたり¥50,000以上** の収益を生む商品だけ採用 |
| 3️⃣ レバレッジ | デジタル資産・コミュニティ・AI伴走で原価を極小化 |
| 4️⃣ 満足度 | **期待値を超える「サプライズ要素」** を各レベルで設計 |
| 5️⃣ 鉄則遵守 | 個別カスタマイズ拡大は原則NG、上流に限定 |

### 詳細設計・各LV

#### 📙 LV0 書籍 (¥1,200)
- **提供**: Kindle書籍 + 30日プログラム付録
- **学長工数**: 初期執筆200h(一点物・以降是ゼロ)

- **粗利見込**: 人生生涯¥500万(印税+集客貢献)

#### 🆕 LV1 無料ウェビナー(¥0)
- **提供**: 60分オンデマンド動画「認知的不協和とAI×多実現」
- **学長工数**: 初期を4h・以降ゼロ
- **表りの目的**: 価値提供
- **裏の目的**: LV2 or LV3へのコンバージョン(目標4-7%)
- **サプライズ**: 動画内に受講生のビフォアフターストーリー

#### 🆕 LV2 ミニコース 7日間 (¥9,800)
- **提供**: 毎日LINE配信 + AI診断 + ワークシートPDF + 動画3本 + AI伴走Bot(7日限定)
- **学長工数**: 初期作り込みで実績同一、以降はでゼロ
- **スケール**: 月500名販売も可能 = **月¥490万**(学長工数ゼロ)

- **サプライズ**: 8日目に「あなただけのセルフイメージレポート」をAI生成して贈呈

## 5. やってはいけないパターン(利益率・満足度両方を下げるボケ)

| NGパターン | 理由 |
|---|---|
| 個別カスタマイズを拡大 | 鉄則⑨不反、学長ボトルネック化 |
| 1on1を安価で提供(¥10,000以下) | 学長時給 < ¥50,000/h になる |
| LV2を凄い値下げ | 適正価格を下げると「安いから雑」の印象 |
| 個人面談の出品 | 議論はコミュニティでやる |
| 詳細個別会出品 | コーチに任せる |
| 初期に低価格バンドル販売 | 適正価格を難しくする |
