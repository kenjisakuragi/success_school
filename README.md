# 願望実現の技術 / MindLab

> **「願望は技術で叶える」**

Kenji(@mindlab_jp)の新規事業「願望実現の技術 / MindLab」のプロジェクトリポジトリ。
マーフィー、ナポレオン・ヒルの正統後継者として、成功哲学 × AI × 東大実証を軸に、潜在意識を活用した願望実現メソッドを展開する。

---

## 0. 迷ったらこれを読む

**[CLAUDE.md](./CLAUDE.md)** が本事業の **憲法** です。
方針・トーン・禁じ手・優先順位の判断はすべてここに集約されています。
判断に迷ったら、まず CLAUDE.md §1 と §11-3 に戻ってください。

## 4. 運営原則(抜粋)

1. **CLAUDE.md §1 のコアメッセージから絶対に逸脱しない**
2. **§2 の禁じ手(波動・宇宙・引き寄せ等)を絶対に使わない**
3. **§8 の時間枠を死守**(週8h立ち上げ期 → 週4h安定期)
4. **ストック型優先、フロー型(都度対応)を増やさない**
5. **「これは週4時間で運営できるか?」を毎施策で自問**
6. **重要判断は `docs/DECISIONS.md` に都度ログ**

## 5. 動作モード(Claude Codeとのやり取り)

| モード | 用途 |

| 【執筆モード】 | YouTube台本、X投稿、Kindle原稿、メルマガ等のコンテンツ生成 |
| 【設計モード】 | 商品・ファネル・カリキュラム設計 |

| 【判断モード】 | 意思決定の壁打ち、選択肢の評価 |
| 【実装モード】 | 自動化スクリプト、Bot構築、ダッシュボード作成 |
| 【批評モード】 | Kenjiのアイデア・既存コンテンツへの率直なフィードバック |

明示がない場合、Claude Code側で判断しモード宣言してから動く。
