### 2026-05-11 — JV共同事業のブランド名「AIと叶える 夢実現大学」を確定

- **決定事項**:JV共同事業の正式ブランド名を「AIと叶える 夢実現大学」とする
- **対象顧客**:40〜60代女性スピリチュアル層(既存「らくらくAI副業キャンパス」と重複領域あり、ただし商品設計で棲み分け予定)
- **JV体制**:
  - JV先:40〜60代女性スピリチュアル層に圧倒的リーチを持つパートナー(既存「らくらくAI副業キャンパス」と同一)
  - JV先が顔として立つ(全SNS・LP・動画・教材の話者はJV先)
  - Kenjiはメソッド・カリキュラム・AI自動化の **黒子提供** のみ
  - レベニューシェア:50:50想定(契約書で確定)
  - Kenji稼働:月2〜4時間(メソッド更新時のみ)
- **背景**:
  - 既存「らくらくAI副業キャンパス」(3ヶ月500万円達成)で、同JV先との協業モデルが実証された
  - スピリチュアル層は「副業スキル」だけでなく「人生・夢」のテーマにも強い購買意欲がある
  - Kenji側のコアメソッド(不可逆ビジョン法)は、スピ層に翻訳すれば爆発的に刺さる素材
  - JV事業として展開すれば、Kenjiのメインブランドを汚染せずに、第2の収益源を確保できる
- **既存資産との関係**:
  - 「らくらくAI副業キャンパス」:副業・AIスキル(横軸)
  - 「AIと叶える 夢実現大学」:人生・夢実現(縦軸)
  - 同JV先・同顧客層に対し、横軸と縦軸でクロスセル可能
- **メインブランドとの近接性リスク**:
  - 「願望実現の技術」(Kenji名義)と「夢実現大学」(JV)は概念領域が近い
  - 顧客層を完全に分けて運営することで、コンテンツ・コピー・SNSの混線を回避する必要あり
  - **対策**:四半期に1回、両ブランドのLP・SNS・教材を Claude Code に監査させ、相互言及・酷似コピーの検出を行う
- **見直し条件**:スクール始動から3ヶ月後の月次レビュー時
- **記録者**:Claude Code(Kenjiの指示による、2026-05-11)
