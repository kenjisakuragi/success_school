# AIと叶える 夢実現大学(JV共同事業)

> **位置づけ**:JV共同事業の正式ブランド(CLAUDE.md §4-2)。
> **想定対象**:40〜60代女性スピリチュアル層。既存「らくらくAI副業キャンパス」と同JV先・同顧客基盤を活用。
> **役割分担**:JV先が顔、Kenjiは黒子(メソッド・AI自動化)。レベニューシェア 50:50想定。

---

## 0. 絶対遵守事項(CLAUDE.md §4-2)

- 本ブランドのアウトプット(LP・SNS・教材・動画)で **Kenji・東大・TBS・MindLab・VIBE SHIP** に関する一切の言及を禁止
- メインブランド「願望実現の技術 / MindLab」とは **ブランド・チャネル・顧客接点を完全分離**
- スピ系語彙(波動・宇宙・引き寄せ等)は **JV先の判断で許容**(Kenji名義側の禁じ手はここでは適用しない)
- ただし「夢実現大学」のメソッド本体は、Kenji側の **不可逆ビジョン法** を翻訳して提供する(中身は同一、語り口を変える)
- 機密度の高い意思決定は `jv/decisions_jv.md` に記録(本ファイルには概要のみ)

## 1. ブランド概念(初期案・JV先と協議の上で確定)

### 1-1. ブランド名

**「AIと叶える 夢実現大学」**

- 「AIがあなたの夢を叶える時代がきた」

- 既存「らくらくAI副業キャンパス」:**AI × 副業スキル**(横軸)

- 「キャンパス」「大学」という教育機関モチーフを継承
- 親しみやすい・敷居の低い言葉選び
- スピ系語彙の混在も許容(JV先のスタイルを最大限尊重)

## 3. メソッドの翻訳方針

Kenji側の **不可逆ビジョン法(ギャップ・ドライブ法)** を本スクール用に翻訳する。
中身(5ステップ構造・認知科学的裏付け)は同一、**語り口だけ** をJV先の顧客層に合わせて変換する。

### 翻訳辞書(暫定)

| Kenji版(メイン) | 夢実現大学版(JV) |
|---|---|
| 不可逆ビジョン法 | 夢を叶える5つの魔法 / 夢実現プロトコル |
| ギャップ・ドライブ | 夢と現実のあいだ / 願いと今のあいだ |
| 認知的不協和理論 | 心と現実が引き合う仕組み / 引力の心理学 |
| 描く・定着・増幅・不協和・自然な行動 | 描く・育てる・近づける・動き出す・叶う |
| AIコーチング | AI先生・AI伴走・夢叶えBot |
| アイデンティティ変容 | 「叶った私」になる |

※ 上記は **暫定案**。JV先のブランド感覚と協議の上で最終確定する。
※ メイン側で「禁じ手」だった「叶う」「引き寄せ」「魔法」等は、JV側では **積極的に使用可** とする(顧客層への親和性のため)。
