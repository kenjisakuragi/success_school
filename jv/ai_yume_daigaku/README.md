## 1. ブランド概念

### 1-1. ブランド名

**「AIと叶える 夢実現大学」**

### 1-2. メインメッセージ案

- 「AIがあなたの夢を叶える時代がきた」
- 「もう一度、夢を見ていい。今度はAIが伴走する」
- 「夢実現は、もう一人で頑張る時代じゃない」

### 1-3. ポジショニング(連携時代版)

- 既存「らくらくAI副業キャンパス」:**AI × 副業スキル**(横軸)
- 「AIと叶える 夢実現大学」:**AI × 夢・人生**(縦軸・スピ親和)
- 「願望実現の技術 / MindLab(Kenji名義メイン)」:**AI × 願望実現 × 認知科学**(縦軸・エビデンスベース)

3ブランドを 同一の経営者(Kenji+JV先)が運営していることを **公知** とし、入口の異なる3つのアプローチを提供する立て付け。

### 1-4. JV先のブランド資産との一貫性

- 「キャンパス」「大学」という教育機関モチーフを継承
- 親しみやすい・敷居の低い言葉選び
- スピ系語彙の混在も許容(JV先のスタイルを最大限尊重)

## 3. メソッドの翻訳方針

Kenji側の **不可逆ビジョン法(ギャップ・ドライブ法)** を本スクール用に翻訳する。
中身(5ステップ構造・認知科学的裏付け)は同一、**語り口だけ** をJV先の顧客層に合わせて変換する。

### 翻訳辞書(暫定・JV先と協議の上で確定)

| Kenji版(メイン) | 夢実現大学版(JV) |
|---|---|
| 不可逆ビジョン法 | 夢を叶える5つの魔法 / 夢実現プロトコル |
| ギャップ・ドライブ | 夢と現実のあいだ / 願いと今のあいだ |
| 認知的不協和理論 | 心と現実が引き合う仕組み / 引力の心理学 |
| 描く・定着・増幅・不協和・自然な行動 | 描く・育てる・近づける・動き出す・叶う |
| AIコーチング | AI先生・AI伴走・夢叶えBot |
| アイデンティティ変容 | 「叶った私」になる |

※ メイン側で「禁じ手」だった「叶う」「引き寄せ」「魔法」等は、JV側では **積極的に使用可**。
※ ただし **Kenji名義発言部分** ではスピ系語彙を使わない。例:対談動画でKenjiが話すパートでは「認知的不協和」と表現し、JV先は「心と現実が引き合う仕組み」と翻訳する。
