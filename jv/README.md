## 機密分離の絶対ルール(CLAUDE.md §4-2)

- **Kenjiの名前を公にしない**(契約書で明文化)
- メインブランドと **ブランド・チャネル・顧客接点を完全分離**
- Claude Code は JV関連の出力時、Kenji名義(Kenji・東大・TBS・MindLab・VIBE SHIP)の言及を絶対に含めない

- スピ系語彙(波動・宇宙・引き寄せ等)は **JV先の判断で許容**(メイン側の禁じ手はJV側に適用しない)
