# COMPETITORS.md — 競合分析

CLAUDE.md §1-2 のポジショニング戦略を裏付ける、主要競合・隣接プレイヤーの分析。
**結論**:「成功哲学系譜 × 男性発信者 × 東大実証 × AI統合」の4点同時保有はガラ空き市場。ここに本ブランドを置く。

---

## 0. 市場マップ(俯瞰)

```
                        男性発信者
                            │
            メンタリストDaiGo  │  Kenji(MindLab)←ガラ空き
             樺沢紫苑       │  ナポレオン・ヒル系譜
   科学・心理学系 ─────────┼───────── 成功哲学・潜在意識系
             岡田斗司夫     │  本田健
                            │  奥平亜美衣 / Happy / Abraham-Hicks
                        女性発信者
                            │
                       スピリチュアル系
```

**気づき**

- スピリチュアル系の女性発信者市場は飽和(本田健、奥平亜美衣、Happy、Abraham-Hicks)
- 科学・心理学系の男性発信者は強い(DaiGo、樺沢)が「願望実現」は扱わない
- **成功哲学系譜の現代的男性発信者** はマーフィー・ヒル没後ほぼ空白
- そこにAIと東大実証を重ねたポジションは唯一無二

## 1. 主要競合プロファイル

### 1-1. 本田健

| 項目 | 内容 |
|---|---|
| ポジション | お金と幸せ・人生哲学(スピ寄り、富裕層憧憬) |
| 主要商品 | 書籍(『ユダヤ人大富豪の教え』等)、セミナー、コミュニティ |
| 価格帯 | 書籍 1,500円 / セミナー 数万〜数十万円 |
| 強み | ベストセラー多数、テレビ出演、海外展開 |
| 弱み | 抽象論が多く、再現性のあるメソッドに乏しい |

**Kenjiが取るべき差別化**:本田健は「お金」が入口、Kenjiは「願望実現の技術」。本田は物語、Kenjiは技術。

**学ぶべき点**

- 書籍を入口に大規模ファネルを構築する流れ
- 海外翻訳展開の戦略性

**避けるべき点**

- スピ寄りの語彙(「ご縁」「魂」「ハートで」等)
- 富裕層への憧憬を煽る構造

## 3. Kenjiが取るべき差別化ポジション(再確認)

1. **男性発信者**(スピ系飽和市場の対角)
2. **東大合格による実証データ**(再現性の根拠)
3. **AI統合による民主化**(マーフィー・ヒルの時代には不可能だった伴走の自動化)
4. **認知的不協和理論という学術的裏付け**(スピリチュアル系との明確な分離)
5. **TBS人事労務管理職という社会的信用**(法人研修の入口)

これら **5点の同時保有が参入障壁**。1点では模倣可能だが、5点同時は他に存在しない。

### 3-1. JV全面連携時代における差別化の再定義(2026-05-11 v1.3)

JV事業「AIと叶える 夢実現大学」との全面連携(CLAUDE.md §4-2 / `docs/DECISIONS.md`)により、メインブランドは **「スピリチュアル系との完全分離」を構造的には維持できなくなった**。
ただし、**「メインブランドの語り口・トーン・引用源・著者表現」では §2-2 を厳守し続ける** ことで、エビデンスベース純度を「ブランド内部の運用」として死守する。

実質的な差別化ポジションは:

> 「Kenji名義のメインブランドは、認知科学とエビデンスを軸にした **深層の知的層向け** 入口」
> 「JV事業は、より広い間口で同じメソッドを別の語り口で届ける **浅層の親しみやすい** 入口」

派生ペルソナ(経営者・難関資格・燃え尽き高学歴層)への防衛策は `docs/INTEGRATION_STRATEGY.md` §5 を参照。

## 5. 避けるべき罠

| 罠 | 理由 |
|---|---|
| スピ層を取り込もうとして語彙を緩める | メインブランドが汚染される(JV系統で扱う) |
| エビデンス過剰で物語性を失う | DaiGoの後追いになる |
| 量を増やして品質を落とす | マーフィー・ヒルの正統後継者の品格を毀損 |
| 短期的な煽りで売上を作る | 5年後のブランド資産を毀損 |
| 競合バトル・引用RT | 上品さを失う、Kenjiの軸ではない |
