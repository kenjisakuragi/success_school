# PERSONAS.md — ペルソナ詳細プロファイル + 翻訳辞書

CLAUDE.md §3 の拡張。3つのコアペルソナに、**同じコアメソッド(不可逆ビジョン法)を翻訳して届ける** ための運用辞書。

> **重要原則**:メソッドの中身は1つ。語り口だけを各ペルソナに最適化する。
> 「同じ薬を、違う器で出す」のがMindLabのコンテンツ運用。

---

## 0. ペルソナ設計の哲学

- ペルソナは **「年齢・性別・職業」では切らない**
- **「人生のステージ × 自己肯定感の状態」** で切る
- 3つのコアペルソナ + 4つの派生ペルソナ(横展開時に使用)
- すべての悩みは「**自分の可能性を信じられない**」に収斂する

---

## 1. コアペルソナ① — 若者(15〜25歳)

### 1-1. プロファイル

| 項目 | 内容 |
|---|---|
| 年齢 | 15〜25歳(高校生〜大学生・若手社会人) |
| 自己肯定感 | 「自分には無理かも」が口癖 |
| 経済状況 | 親依存 or 初任給(可処分所得は低い) |
| デバイス | スマホ中心、X / YouTube / TikTok |
| 情報接触 | ショート動画、X、友人経由 |
| 商品の入口 | LV0(YouTube無料)→ LV1(Kindle 1,500円) |

### 1-2. 苦しみの本質

- 受験・進路・将来への漠然とした不安
- 「自分には特別な才能がない」という確信
- 親や周囲の期待と自分の願望のズレ
- 努力しても結果が出ない経験の蓄積
- SNSで同世代の成功者を見て自己嫌悪

### 1-3. 典型的な1日

朝、二度寝のあと急いで身支度。電車でX・TikTokを眺めながら通学・通勤。授業や仕事で「自分は他の人より劣っている」気分を強化される一日。夜、寝る前に「なんとかしたい」と思い、自己啓発系の動画を見るが、翌朝には忘れている。**「努力しなきゃ」と「努力できない自分」の往復**で疲弊している。

### 1-4. 悩みの言語表現サンプル(本人の口語)

- 「どうせ自分なんて無理」
- 「やる気が出ない」
- 「親はわかってくれない」
- 「同級生はすごいのに、自分だけ」
- 「目標とか、見つからない」
- 「努力しようとしても、続かない」
- 「受験勉強、本当にこのまま行けるのか」

### 1-5. 響く言葉・響かない言葉

| 響く | 響かない |
|---|---|
| 「東大に合格したのは、勉強じゃなかった」 | 「自己実現」 |
| 「やる気じゃなくて、設計の問題」 | 「波動を整えよう」 |
| 「あなたが悪いんじゃない、方法が違うだけ」 | 「努力は美しい」 |
| 「脳の仕組みを使えば、勝手に動ける」 | 「夢を信じよう」 |

### 1-6. 入口商品

- **無料**:YouTube「東大に合格したとき、勉強していなかった」「やる気が出ないのは才能の問題ではない」
- **LV1**:Kindle『願望実現の技術』
- **LV2への階段**:受験合格・進路選択を切り口にしたランディングページ

## 2. コアペルソナ② — 30〜40代母親

### 2-1. プロファイル

| 項目 | 内容 |
|---|---|
| 年齢 | 30〜45歳、子ども(乳幼児〜小学校低学年)あり |
| 自己肯定感 | 「自分の人生はもう終わった」と感じている |
| 経済状況 | 共働き or 専業主婦(可処分時間は極小) |
| デバイス | スマホ中心(夜の数十分が唯一の自分時間) |
| 情報接触 | Instagram、note、LINE、ママ友コミュニティ |
| 商品の入口 | LV0(YouTube・note無料)→ LV1(Kindle・ワークブック) |

### 2-2. 苦しみの本質

- 子育てに追われ、自分の名前で呼ばれなくなった喪失感
- 結婚・出産前に持っていた夢の埋葬
- 夫への依存と自立への渇望のあいだの葛藤
- 「私はもう手遅れ」という諦め
- 母として失格、妻として中途半端、自分として空っぽという三重苦

### 2-3. 典型的な1日

朝5時起き、子の世話、朝食、保育園送迎、仕事(時短)、お迎え、夕食、寝かしつけ。寝かしつけ後の22時、ようやく訪れる「自分の時間」。スマホで誰かの素敵な暮らしを見て、自分との落差に落ち込む。**「私もこうなりたかった」と「もう無理だ」が同居する**夜の30分が、唯一の意識ある時間。

### 2-4. 悩みの言語表現サンプル(本人の口語)

- 「私の人生って、これでいいんだろうか」
- 「自分のために使える時間がない」
- 「夢なんて、子どもがいたら無理」
- 「夫は私の気持ちをわかってくれない」
- 「キラキラした人たちが羨ましい」
- 「今からじゃ遅いかな」
- 「ちゃんとした母親になれてない」

### 2-5. 響く言葉・響かない言葉

| 響く | 響かない |
|---|---|
| 「子育てしながらでも、夢は設計できる」 | 「自分の時間を作ろう」(無責任に聞こえる) |
| 「過去の私自身もそうでした」(共感) | 「頑張ればできる」(もう頑張っている) |
| 「1日5分の脳の使い方で、半年後が変わる」 | 「人生を変えよう」(壮大すぎる) |
| 「あなたを取り戻す技術」 | 「自己肯定感を上げよう」(できないから困っている) |

### 2-6. 入口商品

- **無料**:note「子育て中に夢を諦めかけたあなたへ」「私が東大に合格したとき、勉強していなかった」をYouTubeでも展開
- **LV1**:ワークブックPDF(寝かしつけ後の15分で書ける設計)
- **LV2への階段**:「子育てしながら自分の夢を叶える」ランディングページ

## 3. コアペルソナ③ — 50代以降

### 3-1. プロファイル

| 項目 | 内容 |
|---|---|
| 年齢 | 50〜70歳前後 |
| 自己肯定感 | 「もう人生の主戦場を終えた」感覚 |
| 経済状況 | 安定(退職金・年金見込み)、可処分所得は中〜高 |
| デバイス | スマホ + PC、Facebook / YouTube / 書籍 |
| 情報接触 | YouTube、Kindle、メルマガ、書店 |
| 商品の入口 | LV1(Kindle・書籍)→ LV2(オンラインプログラム) |

### 3-2. 苦しみの本質

- 定年・役職定年・子の独立による「役割の喪失」
- 「自分は何のために生きているのか」という存在意義の揺らぎ
- 健康・親の介護への不安
- やり残した夢(本当にやりたかったこと)への未練
- 残り時間への焦り

### 3-3. 典型的な1日

通勤の習慣がなくなり、朝起きてもやることが明確でない日々。図書館や書店、散歩、たまにSNS。**「まだ何かできるはず」と「もう遅いかもしれない」のあいだ**を行き来する。健康診断の結果を気にしながら、夜は早めに就寝。

### 3-4. 悩みの言語表現サンプル(本人の口語)

- 「人生100年時代と言われても、ピンと来ない」
- 「若い頃にやり残したことがある」
- 「もう一花咲かせたい」
- 「孫の世代に、何か残したい」
- 「年齢を言い訳にしている自分がいる」
- 「健康と気力があるうちに、本当にやりたいことを」

### 3-5. 響く言葉・響かない言葉

| 響く | 響かない |
|---|---|
| 「50代こそ、願望実現の黄金期」 | 「若い人たちと一緒に」 |
| 「人生後半戦の設計図」 | 「キラキラ起業」 |
| 「マーフィー、ヒルが言わなかった先」 | 「AIを使いこなそう」(技術アレルギー) |
| 「東大合格より、難しい挑戦が今ここに」 | 「夢を叶えよう」(漠然と響かない) |

### 3-6. 入口商品

- **無料**:Kindle(書店で手に取られる権威)→ LINE登録
- **LV1**:書籍『願望実現の技術』
- **LV2への階段**:「人生後半戦の願望実現」ランディングページ

## 4. 翻訳辞書 — 同じ概念を3ペルソナ向けにどう表現するか

| メソッド要素 | 若者向け | 30〜40代母親向け | 50代以降向け |
|---|---|---|---|
| 願望を描く | 「未来の自分を脳に焼き付ける」 | 「忘れていた夢を、紙に取り戻す」 | 「やり残した夢に、輪郭を与える」 |
| 定着させる | 「毎日30秒、未来を思い出す」 | 「寝かしつけ後の5分、自分に戻る」 | 「朝のコーヒー時間に、未来を確かめる」 |
| ギャップを増幅 | 「今の自分と、未来の自分の差を意識する」 | 「あなたが本当にいたい場所と、今いる場所の差」 | 「残された時間で、何ができるかを直視する」 |
| 認知的不協和 | 「脳が落ち着かなくなる仕組み」 | 「気づいたら動いている、という状態」 | 「内なる違和感を、行動エネルギーに変える」 |
| 行動の自動化 | 「やる気じゃなく、習慣で動く」 | 「子育ての隙間に、夢への一歩が自然に入る」 | 「日常の中に、未来への布石を埋め込む」 |
| 努力(自然な行動への変容) | 「努力じゃなくて、止まれないだけ」 | 「頑張らずに、続いてしまう」 | 「自然と手が動いている、という感覚」 |
| 不可逆ビジョン | 「もう戻れない未来図」 | 「もう諦められない自分像」 | 「人生の最後に必ず実現させる図」 |
| AI伴走 | 「24時間相談できるコーチ」 | 「夜中でも話を聞いてくれる存在」 | 「あなたの考えを整理してくれる相棒」 |

## 5. 派生ペルソナ(横展開時に使用)

メインの3ペルソナが安定したあと、以下の派生ペルソナに展開する。コアメソッドは同一、語り口だけ調整。

### 5-1. 経営者・起業家

- 苦しみ:売上の踊り場、ビジョンの濁り、孤独
- 入口:法人研修(LV4)/ オンラインプログラム(LV2)
- 翻訳キーワード:「経営者のための認知科学」「ビジョン設計が経営戦略」

### 5-2. 難関資格挑戦者(司法試験・公認会計士・医師国家試験等)

- 苦しみ:長期戦の中だるみ、合格イメージの欠如、不合格の恐怖
- 入口:Kindle・note(検索流入)
- 翻訳キーワード:「東大合格者が使った、不可逆な合格設計」

### 5-3. 燃え尽き高学歴ビジネスパーソン

- 苦しみ:キャリアの行き詰まり、何のために働いているかの喪失
- 入口:YouTube・X・note
- 翻訳キーワード:「学歴で勝った人が、次に勝つ方法」

### 5-4. シニア層(JV共同事業の主要顧客)

- ※ JV系統の主要ペルソナ。Kenji名義では発信しない(§4-2分離原則)
- 苦しみ:健康不安、孫世代への遺産、第二の人生の方向性
- 入口:JV先のブランドから(別チャネル)
- 翻訳キーワード:スピ系の語彙を用いた翻訳が必要(JV先の言語で展開)

## 6. ペルソナ別 KPI 配分目安

| ペルソナ | LV0 リーチ比率 | LV2 購入比率 | LV3 継続比率 |
|---|---|---|---|
| 若者 | 35% | 15% | 10% |
| 30〜40代母親 | 30% | 35% | 30% |
| 50代以降 | 25% | 40% | 55% |
| 派生(経営者・資格・高学歴) | 10% | 10% | 5% |

**示唆**:LV0は若者で広がりやすいが、LV2/LV3の収益は母親層・50代以降が中心になる見込み。コンテンツは若者向けに広く、商品設計は母親・50代に深く。
