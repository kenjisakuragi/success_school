# DECISIONS.md — 重要意思決定ログ

> **このログの役割**:事業運営上の重要判断(ブランド戦略・商品設計・JV関係・価格・撤退判断等)をすべて時系列で記録する。後日「なぜこう決めたか」を辿れることが、ブレない経営の前提。

---

## ログ運用ルール

1. **追加するタイミング**:重要判断のたびに、Kenjiが指示するか Claude Code が提案する
2. **書く順序**:**新しいものを上**に追加(逆時系列)
3. **書式**:下記テンプレートに準拠
4. **粒度の目安**:「3ヶ月後に経緯を聞かれて答えに困りそうな判断」はすべて記録
5. **改訂**:既存の決定を覆す場合は、新しいエントリを追加し、旧エントリは残す(削除しない)
6. **JV関連**:JV系統に関する判断は機密度が高いため、必要に応じて `jv/DECISIONS_JV.md` に分離(原則は本ファイル)

---

## テンプレート

```markdown
### YYYY-MM-DD — [タイトル]

- **決定事項**:何を決めたか(1〜2行)
- **背景**:なぜ判断が必要になったか
- **代替案**:検討した他の選択肢(2〜3個)
- **採用理由**:なぜこの案にしたか(CLAUDE.md §11-3 のフォールバック順序と照らす)
- **影響範囲**:この決定が影響する商品・チャネル・スケジュール
- **見直し条件**:この決定をいつ・どんな条件で再検討するか
- **記録者**:Kenji / Claude Code
```

### 2026-05-11 — JV共同事業のブランド名「AIと叶える 夢実現大学」を確定

- **🚨 Claude Code への運営注意**:

- **指摘事項(Kenjiに伝達済み)**:

### 2026-05-11 — Kindle第1作のタイトル戦略確定(メインタイトルに「東大」フックを入れない)

- **決定事項**:Kindle第1作のメインタイトルは『願望実現の技術』とし、「東大」は **メインタイトルに含めない**。帯コピー(上部・赤帯)で「東大合格者が無自覚に実践していた / 認知科学に基づく成功哲学の正統進化」と訴求し、サブタイトルは「── マーフィー、ナポレオン・ヒルの先へ」で締める
- **背景**:Kenjiから「東大式とかフックを付けるべきか」の判断打診。書籍タイトルは一度確定すると不可逆性が極めて高く、シリーズ全体のブランド軌道を決定づけるため、執筆着手前に決める必要があった
- **代替案**:
  - (A) メインは『願望実現の技術』のまま、帯で東大訴求 ← **採用**
  - (B) サブタイトル「── 東大合格者が無自覚に使っていた、認知科学に基づく成功哲学」で一体化
  - (C) 『東大式 願望実現の技術』(フック前置)
  - (D) 『東大に合格したのは、勉強じゃなかった』物語型タイトル
- **採用理由**(CLAUDE.md §11-3 フォールバック順序に沿って):
  1. コアメッセージ「願望は技術で叶える」の純度を最も保つのは案A(タイトル単体が思想そのもの)
  2. ペルソナ②③(母親・50代)が「自分とは無縁」と離脱するリスクを最小化(`docs/PERSONAS.md`の主要収益層)
  3. シリーズ展開で「東大式」を冠し続ける足枷を回避(第2作以降の自由度確保)
  4. 「東大式◯◯」テクニック系自己啓発クラスターに飲み込まれず、**成功哲学系譜のポジション**(`docs/COMPETITORS.md`のガラ空き象限)を堅守
  5. 「東大」の信頼資産は **帯・著者プロフィール・序章・YouTube・LP** で集中投下し、ファネル全体で何度でも露出
- **影響範囲**:
  - Kindle第1作の表紙・帯デザイン発注
  - 全ファネル(YouTubeサムネ、Xプロフィール、note・LP)での「東大」の使い方の指針(タイトルではなく文脈で語る)
  - 第2作以降の命名規則(『◯◯の技術』『◯◯の設計』といった抽象名詞ベースのシリーズ化を検討)
  - `docs/PRODUCTS.md` §3-1 を更新
- **見直し条件**:Kindle第1作出版3ヶ月後(M5想定)、販売動向・読者レビューを見て、第2作のサブタイトル戦略を再検討
