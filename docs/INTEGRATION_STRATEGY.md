# INTEGRATION_STRATEGY.md — メインブランド × JV事業 連携運用戦略

> **位置づけ**:CLAUDE.md §4-2 / §4-3 / §4-4 の運用詳細。両ブランドの全面連携(2026-05-11確定)を、メインブランドの希釈を最小化しつつ集客効率を最大化するための実装書。
> **対象ブランド**:
> - メイン:「願望実現の技術 / MindLab」(Kenji名義)
> - JV:「AIと叶える 夢実現大学」(JV先名義、Kenjiは公的にメソッド提供者として登場)
> - 既存:「らくらくAI副業キャンパス」(JV先名義、AI×副業スキル軸)

## 1. 連携の前提と禁則

### 1-1. 連携でできるようになったこと

- Kenjiが両ブランド(+ らくらくAI副業キャンパス)を運営していることを公にする
- メイン → JV、JV → メイン の双方向送客
- 共催ウェビナー、対談動画、共著本(将来)
- 既存「らくらくAI副業キャンパス」を含めた3点間クロスセル

### 1-2. 連携しても変わらない禁則

- **Kenji名義の出力では CLAUDE.md §2-2 を厳守**(波動・宇宙・引き寄せ等の語彙は使わない)
- **メインブランドの「成功哲学 × 男性 × エビデンスベース」のトーンを緩めない**
- 派生ペルソナ(経営者・難関資格・燃え尽き高学歴層)向けには、JV送客を **控える**
- 「楽して」「努力ゼロ」「念じれば叶う」系の煽りは、メイン・JV両方で禁止

## 5. 派生ペルソナ防衛策(離反リスク最小化)

派生ペルソナ(経営者・難関資格・燃え尽き高学歴層)は「スピ系を避けたい」感度が極めて高い。
連携を公知化するメインブランドのリスクは、ほぼこの層に集中する。

### 5-1. メインブランド側での防衛策

- **Kindle・YouTube・noteで、認知科学・行動経済学の引用密度を意図的に高める**(派生ペルソナへの "鎧" になる)
- **「スピ系を批判する」のではなく「異なるアプローチがある」と冷静に位置づける**
- **派生ペルソナ向けコンテンツでは、JV送客の案内を入れない**(動画概要欄・LP・メルマガで)
- **法人研修(LV4)では、Kenji名義のメインブランドのみを提示**(JVは法人文脈で出さない)

### 5-2. シグナル監視

- YouTube・Xコメントで「スピ系」「胡散臭い」「がっかり」等のキーワード頻度を月次で集計(Claude Codeに監査依頼)
- LV2購入率 / Kindle販売 / YouTube登録の前月比下落を、JVローンチ前後で対比
- 兆候が出たら、5-1の防衛策を強化
